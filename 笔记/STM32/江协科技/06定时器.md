# 06 定时器

> 本笔记整合教程 6-1 至 6-8，按“定时、输出、输入、编码器”组织，便于复习和查阅。

## 1. 定时器总览

STM32 定时器通过计数器 CNT 对时钟或外部脉冲计数，再根据 ARR、CCR 产生更新、比较或捕获事件。

| 类型 | 常见定时器 | 主要能力 |
| --- | --- | --- |
| 基本定时器 | TIM6、TIM7 | 基本定时、更新事件、触发 DAC |
| 通用定时器 | TIM2~TIM5 | 定时中断、外部时钟、输出比较、PWM、输入捕获、编码器 |
| 高级定时器 | TIM1、TIM8 | 通用能力、互补 PWM、死区和刹车功能 |

```text
TIM 时钟 → PSC 预分频 → CNT 计数 → ARR 溢出 → 更新事件
```

## 2. 6-1 TIM定时中断

```text
CK_CNT = CK_TIM / (PSC + 1)
T_update = ((PSC + 1) × (ARR + 1)) / CK_TIM
```

- `PSC` 决定计数器多久加 1。
- `ARR` 决定计数多少次产生一次更新事件。
- `PSC`、`ARR` 都要注意“实际值减 1”。

```c
PSC = 7200 - 1;   // 72MHz 下计数频率 10kHz
ARR = 10000 - 1;  // 更新周期 1s
```

配置流程：开启 TIM 时钟，配置 PSC/ARR，清除更新标志，开启更新中断，配置 NVIC，启动 TIM。在 `TIMx_IRQHandler` 中判断更新标志、执行短任务并清除挂起标志。

## 3. 6-2 定时器外部时钟

定时器可以使用外部脉冲作为计数时钟，常用于统计脉冲数量、测转速或对传感器输出计数。

```text
外部引脚 → 输入滤波/极性处理 → CNT
```

配置时选择外部时钟模式和有效边沿，配置 GPIO、PSC、ARR，然后用 `TIM_GetCounter(TIMx)` 读取计数值。读取差值时要处理计数器溢出和回绕。

## 4. 6-3 TIM输出比较

输出比较模块持续比较 `CNT` 和 `CCR`：

```text
CNT == CCR → 比较事件 → 按配置翻转、置位或清零输出
```

`CCR` 决定比较事件发生的位置。更新事件关注 `CNT` 溢出，比较事件关注 `CNT == CCR`。输出比较可用于产生方波和精确的电平时序，也是 PWM 的基础。

## 5. 6-4 PWM应用

```text
PWM频率 = CK_TIM / ((PSC + 1) × (ARR + 1))
占空比 ≈ CCR / (ARR + 1)
```

配置流程：开启 TIM/GPIO 时钟，将 PWM 引脚配置为复用推挽输出，设置 PSC/ARR 确定频率，配置输出比较通道和 PWM 模式，设置 `CCR` 确定占空比，启动定时器和通道。

```c
TIM_OC3Init(TIM2, &TIM_OCInitStructure);
TIM_OC3PreloadConfig(TIM2, TIM_OCPreload_Enable);
TIM_SetCompare3(TIM2, compare_value);
```

- LED 呼吸灯：逐渐改变 `CCR`，改变亮度。
- 舵机：通常约 50Hz，通过改变高电平脉宽控制角度。
- 直流电机：改变占空比，调节平均电压和转速。

## 6. 6-5 TIM输入捕获

输入捕获在指定边沿到来时，把当前 `CNT` 自动保存到 `CCR`：

```text
输入边沿 → 捕获 CNT → 保存到 CCR → 读取捕获值
```

两次捕获值的差可得到边沿之间的时间：

```text
时间间隔 = 捕获值差 / 计数频率
```

需要配置输入通道、边沿、输入滤波/分频和定时器计数频率。如果信号间隔超过一次计数器溢出周期，还要统计溢出次数。

## 7. 6-6 输入捕获测频率和占空比

相邻两个上升沿的捕获差为 `ΔCCR` 时：

```text
周期 = ΔCCR / f_capture
频率 = f_capture / ΔCCR
```

PWMI 模式通常使用两个关联通道：一个捕获周期，另一个捕获高电平时间：

```text
占空比 = 高电平时间 / 周期
```

两个通道必须使用相同的计数基准，计数器溢出也必须纳入计算。

## 8. 6-7 TIM编码器接口

增量式编码器输出 A、B 两路相位相差约 90° 的方波。TIM 编码器接口可硬件判断相位先后并自动控制 `CNT` 加减。

```text
A/B 两相 → TI1/TI2 → 编码器模式 → CNT 自动递增或递减
```

A 相超前 B 相和 B 相超前 A 相对应相反方向。使用两相都计数时常见为 4 倍频模式。

```c
TIM_EncoderInterfaceConfig(
    TIM3,
    TIM_EncoderMode_TI12,
    TIM_ICPolarity_Rising,
    TIM_ICPolarity_Rising
);
```

## 9. 6-8 编码器接口测速

固定采样周期内读取编码器计数增量：

```text
记录 CNT → 等待固定时间 → 再读 CNT → 计算 ΔCNT → 换算转速
```

若编码器每转脉冲数为 `PPR`，采用 4 倍频时：

```text
每转计数数 = 4 × PPR
转/秒 = ΔCNT / 采样时间 / 每转计数数
转/分 = 转/秒 × 60
```

反转或跨过 0 时，`CNT` 会回绕，计算 `ΔCNT` 时必须结合计数器位宽处理。

## 10. 统一易错点

- `PSC`、`ARR` 是“系数减 1”。
- 先确认具体 TIM 的真实输入时钟，再计算周期。
- 定时器中断需要同时配置 TIM 中断、NVIC 和中断服务函数。
- 中断服务函数要清除对应挂起标志，并保持短小。
- PWM 占空比由 `CCR` 和 `ARR` 共同决定。
- 输入捕获和编码器测速都要处理计数器溢出或回绕。
