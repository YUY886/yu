# 07 ADC（章索引）

> [!info] 这一章在讲什么
> 前 6 章所有外设都在处理 **0 和 1**。第 7 章第一次让单片机去**量一个连续的量**——引脚上的模拟电压。
>
> 核心只有一句话：**把引脚上连续变化的模拟电压，变成内存里 0~4095 的一个数字变量。** 7-1 讲这件事的硬件原理，7-2 用两个实验把它跑通。
>

## 本章速查

### 关键参数（STM32F103，课件 Slide 86 口径）

| 参数 | 值 |
| --- | --- |
| 类型 | **12 位逐次逼近型（SAR）** |
| 输入电压范围 | **0 ~ 3.3 V** |
| 转换结果范围 | **0 ~ 4095** |
| 分辨率 | 12 位 = 4096 个档位，1 LSB = `3.3 V / 4096 ≈ 0.806 mV` |
| 转换时间 | 课件口径 **1 µs**（ADCCLK=14 MHz + 采样 1.5 周期） |
| 输入通道 | **18 个** = 16 外部 + 2 内部（温度传感器、V_REFINT） |
| 转换单元 | **规则组**（16 序列 / 1 个数据寄存器）+ **注入组**（4 序列 / 4 个数据寄存器） |
| F103C8T6 实际资源 | **ADC1、ADC2，10 个外部输入通道**（无 ADC3，外部通道只有 0~9） |
| ADCCLK 来源 | PCLK2 分频，可选 `Div2 / Div4 / Div6 / Div8` |

### 全章公式速查

| 场景 | 公式 |
| --- | --- |
| 总转换时间 | `T_CONV = 采样时间 + 12.5 个 ADC 周期` |
| 1 LSB（1 个数码代表多少电压） | `1 LSB = V_ref / 4096` |
| 电压换算 | `V = 读数 / 4095 × 3.3`（官方源码写法） |
| 电压换算（按档位数） | `V = 读数 / 4096 × 3.3`（两者差 < 1 LSB，见 7-2 第 4.1 节） |
| 读数反推 | `读数 = 4096 × V_in / V_ref` |
| 官方工程实际转换时间 | `(55.5 + 12.5) / 12 MHz ≈ 5.67 µs` |

> [!tip] 记公式的窍门
> **分母是档位数。** 12 位 → 4096 个档位（0~4095），所以 1 LSB 用 4096 除；而官方源码算电压时用 4095 除，是把「最大读数对应满量程」的约定。两者差不到 1 LSB，**关键是别在同一份工程里混用**。

## 全章统一易错点

- [ ] ADC 引脚忘了配 `GPIO_Mode_AIN`（模拟输入）→ 引脚上的模拟电压被数字施密特触发器整形，读数无意义。
- [ ] 忘了 `RCC_ADCCLKConfig()` → 用了默认的 `Div2`（36 MHz），ADC 超速工作。
- [ ] `ADC_Cmd(ADC1, ENABLE)` 忘了，或写在 `ADC_ResetCalibration()` 之后 → 违反「校准前 ADC 须关电超过两个 ADC 时钟周期」。
- [ ] 校准的两个 `while` 等待漏写 → 校准未完成就转换，前几个读数不准。
- [ ] 把校准写进 `AD_GetValue()` → 每次转换都重跑校准，白白变慢；校准只需上电后做一次。
- [ ] 序列位置 `Rank` 写成 `0` → 非法值（从 1 开始）。
- [ ] 以为「12 位 = 最大读数 4096」→ 最大读数是 **4095**。
- [ ] 多通道时忘了「每次转换前重配通道」→ 四次读回来全是同一个通道。
- [ ] 想用扫描模式读多通道却不开 DMA → 规则组只有 1 个数据寄存器，**只能读到最后一个通道**。
- [ ] 非扫描模式下把 `ADC_NbrOfChannel` 写大于 1 → 注释写明「在非扫描模式下，只能是1」。
- [ ] 电压换算忘了 `(float)` 强制转换 → 整数除法，结果恒为 0。
- [ ] VDDA / VSSA 没接好 → 读数整体偏移或乱跳，且不报任何错。
- [ ] 拿课件 Slide 90 的通道表当 C8T6 的表 → C8T6 没有 ADC3，外部通道只有 0~9。

## 知识地图

```text
                      ┌─ 7-1 ADC 模数转换器（理论）
                      │    传感器 → 连续电压 → 【采样·保持·量化·编码】 → 0~4095
                      │    规则组 / 注入组 · 四种转换模式 · ADCCLK · 数据对齐 · 校准
  模拟世界 ── AO ─────┤
                      └─ 7-2 AD 单通道与 AD 多通道（应用）
                           单通道：序列配一次，读通道 0
                           多通道：序列每次重配，轮流读通道 0~3
                                     │
                                     └──► 规则组只有 1 个数据寄存器怎么办？
                                          本集答案：读一个走一个
                                          第 8 章答案：扫描模式 + DMA 自动搬运
```

- **7-1 是理论集**，把 ADC 的硬件结构、参数、寄存器行为讲透；本集没有独立实验，代码在 7-1 工程里。
- **7-2 是应用集**，两个实验共用同一套 `AD_Init`，差别只在序列配置的位置。
- **7-2 是第 8 章 DMA 的引子**：正因为「规则组只有 1 个数据寄存器」，多通道才需要每次手动重配、读一个走一个；8-2 用 DMA 把这个搬运过程自动化。
