# 01-2 STM32 简介

> [!abstract] 这一集只解决一个问题
> **我手上这块 STM32F103C8T6，到底是个什么东西？**
>
> 答：它是「**ARM 设计的 Cortex-M3 内核** + **ST 设计的一堆外设**」封装在 48 个引脚里的芯片；引脚表告诉你每根脚能干什么（主功能 / 复用 / 重定义），BOOT 表告诉它上电后从哪里开始取指令。
>
> 这一集**没有一行代码**，但后面 14 章全部建立在这里的词汇表上。
>

## 1 STM32 是什么

三句话概括：

- **STM32 是 ST（意法半导体）公司的一系列 32 位微控制器（MCU）**，基于 **ARM Cortex-M 内核**。
- 它不是「一颗芯片」，而是**一个大家族**：F0/F1/F3/F4/F7/H7/L0/L1/L4…… 本课程只用 **F1 系列的 STM32F103C8T6**。
- 一颗 STM32 = **内核（Core）+ 存储器（Flash / SRAM）+ 总线 + 外设（Peripheral）**，全部集成在一个封装里。

### 1.1 内核是 ARM 的，外设是 ST 的

这是本集**最重要的一句话**，也是初学最容易搞混的地方：

| | 谁设计的 | 里面有什么 | 你写代码时关心的 |
| --- | --- | --- | --- |
| **内核**（Cortex-M3） | **ARM 公司**（只卖设计授权，自己不生产芯片） | CPU、NVIC 中断控制器、SysTick、总线接口 | 中断优先级分组、`__WFI()`、内核寄存器 |
| **外设** | **ST 公司** | GPIO、USART、TIM、I2C、SPI、ADC、RCC…… | 库函数 `xxx_Init()`、外设时钟、引脚 |

```text
     ┌──────────────────────────────────────────────────────────┐
     │                  STM32F103C8T6 芯片                       │
     │                                                          │
     │   ┌────────────────────┐        ┌─────────────────────┐  │
     │   │  ARM Cortex-M3 内核 │◄──────►│  ST 设计的外设       │  │
     │   │  （ARM 公司设计）    │  总线   │  （ST 公司设计）     │  │
     │   │  CPU / NVIC /      │        │  GPIO TIM USART     │  │
     │   │  SysTick / 调试接口 │        │  I2C SPI ADC RCC…   │  │
     │   └────────────────────┘        └─────────────────────┘  │
     └──────────────────────────────────────────────────────────┘
```

> [!tip] 为什么要分清
> 因为**查资料的地方不一样**：
> - **内核**的事情查 ARM 的 *Cortex-M3 技术参考手册*，或者 ST 的 **《Cortex-M3 编程手册》（PM0056）**——比如 `NVIC_PriorityGroupConfig()` 为什么要分组。
> - **外设**的事情查 ST 的 **《STM32F10xxx 参考手册》（RM0008）** 和 **《数据手册》（Datasheet）**——比如某个引脚的复用功能是什么。
>
> 另外，ARM 授权内核给很多厂商（ST、NXP、GD、兆易创新……），所以你会看到「内核一样、外设不同」的各种芯片；**这也是为什么 STM32 的代码思路能迁移到别的 Cortex-M 芯片上**。

### 1.2 三种「手册」分别查什么

| 手册 | 英文 / 编号 | 查什么 |
| --- | --- | --- |
| 数据手册 | Datasheet | **引脚定义、封装尺寸、电气参数**（电压、电流、温度）→ 本集讲的引脚表就是它 |
| 参考手册 | Reference Manual（RM0008） | **每个外设的寄存器与功能框图** → 后面所有章节的原理 |
| 编程手册 | Programming Manual（PM0056） | **内核相关**：NVIC、SysTick、指令集 → 中断优先级分组 |

## 2 命名规则逐段拆解

型号 `STM32F103C8T6` 一共 6 个信息段，**每一段都对应一个具体参数**：

```text
        STM32   F      103      C        8        T         6
          │     │       │       │        │        │         │
          │     │       │       │        │        │         └─ 温度范围
          │     │       │       │        │        └─────────── 封装
          │     │       │       │        └──────────────────── Flash 容量
          │     │       │       └───────────────────────────── 引脚数
          │     │       └───────────────────────────────────── 子系列
          │     └───────────────────────────────────────────── 产品系列
          └─────────────────────────────────────────────────── 品牌 + 内核
```

### 2.1 逐段对照表

| 段 | 本例取值 | 含义 | 其他常见取值 |
| --- | --- | --- | --- |
| ① 品牌 + 内核 | `STM32` | ST 的 **32 位** MCU，内核为 **ARM Cortex-M** | — |
| ② 产品系列 | `F` | **F = 基础型 / 通用型**（Foundation） | `L` = 低功耗，`H` = 高性能，`G` = 主流型，`W` = 无线 |
| ③ 子系列 | `103` | **增强型**，F1 系列里最常用的一档 | `101` 基本型、`102` USB 型、`105/107` 互联型 |
| ④ 引脚数 | `C` | **C = 48 脚** | `T` = 36，`R` = 64，`V` = 100，`Z` = 144，`I` = 176 |
| ⑤ Flash 容量 | `8` | **8 = 64 KB Flash** | `4` = 16 KB，`6` = 32 KB，`B` = 128 KB，`C` = 256 KB，`D` = 384 KB，`E` = 512 KB，`F` = 768 KB，`G` = 1 MB |
| ⑥ 封装 | `T` | **T = LQFP**（四方扁平引脚封装） | `H` = BGA，`U` = QFN / VFQFPN，`Y` = WLCSP |
| ⑦ 温度范围 | `6` | **6 = 工业级 −40 ~ 85 ℃** | `7` = −40 ~ 105 ℃ |

> [!tip] 只记本课程用到的这一串
> `STM32F103C8T6` = **增强型 F1 · 48 脚 · 64 KB Flash · LQFP 封装 · 工业级 −40~85 ℃ · Cortex-M3 内核 · 最高 72 MHz**。
>
> 注意型号里**只有 Flash 容量，没有 SRAM 容量**——SRAM 要查数据手册（C8 是 20 KB）。

### 2.2 容易踩的型号陷阱

- **`C6T6` / `C8T6` / `CBT6`**：封装、引脚完全一样，**只有 Flash 容量不同**（32 KB / 64 KB / 128 KB）。所以网上给 CBT6 的例程通常能直接烧进 C8T6（只要不超出 64 KB）；反过来则可能溢出。
- **`C8T6` 和 `C8T6A` / `C8T6B`**：后缀字母是**芯片版本（revision）**，ST 会不断修正硅片问题。多数情况下代码通用。
- **买到「C8T6 实测 128 KB Flash」**：市场上有 C8T6 实际是 CBT6 打磨/同晶圆的情况，属于坊间常见现象，**不要依赖未标称的容量**。
- **`F103` ≠ `F407`**：内核从 Cortex-M3 变 M4，主频、外设、寄存器全部不同，例程不通用。

## 3 芯片内部资源框图

把封装撬开，里面是这样一张图（只画本课程会用到的部分）：

```text
                       ┌──────────────────────────────┐
                       │      ARM Cortex-M3 内核       │
                       │   （72 MHz 最高主频）          │
                       │   NVIC · SysTick · 调试接口   │
                       └───────────────┬──────────────┘
                                       │
                            ┌──────────┴──────────┐
                            │    AHB 总线（高速）   │
                            └──────────┬──────────┘
             ┌───────────────┬─────────┼─────────┬───────────────┐
             │               │         │         │               │
      ┌──────┴─────┐  ┌──────┴───┐  ┌──┴───┐  ┌──┴────┐   ┌──────┴─────┐
      │ 64KB Flash │  │ 20KB SRAM│  │ DMA  │  │ 复位  │   │  桥接 AHB   │
      │ （程序）    │  │ （变量）  │  │      │  │ 时钟  │   │  → APB      │
      └────────────┘  └──────────┘  └──────┘  │ RCC   │   └──┬──────┬───┘
                                             └───────┘      │      │
                                                    ┌───────┴┐  ┌──┴────────┐
                                                    │ APB2   │  │  APB1     │
                                                    │ 72 MHz │  │  36 MHz   │
                                                    └───┬────┘  └─────┬─────┘
        GPIOA GPIOB · AFIO · EXTI · ADC1/ADC2 ·        │             │
        USART1 · SPI1 · TIM1（高级）                     │             │
                                                        │      TIM2/3/4（通用）
                                                        │      USART2/3 · I2C1/2
                                                        │      SPI2 · BKP · PWR
                                                        │      IWDG/WWDG · RTC
```

### 3.1 各块说明

| 模块 | 内容 | 本课程在哪用到 |
| --- | --- | --- |
| **内核** | Cortex-M3，最高 72 MHz，含 NVIC、SysTick | 第 5 章中断、第 6 章定时器（NVIC） |
| **Flash** | 64 KB，存**程序**（掉电不丢） | 第 15 章 FLASH 读写 |
| **SRAM** | 20 KB，存**运行时的变量**（掉电丢失） | 全程；数组开太大就会不够 |
| **总线** | **AHB**（高速）+ **APB2**（高速外设）+ **APB1**（低速外设） | 决定外设挂在哪条线上、开哪个时钟 |
| **外设** | GPIO、TIM、USART、I2C、SPI、ADC、RCC、AFIO、EXTI…… | 第 3 章起逐章学习 |
| **DMA** | 不经过 CPU 搬运数据 | 第 8 章 |
| **RCC** | 复位与时钟控制，**给所有外设发时钟** | 从第 3 章起，每个外设初始化第一步都是它 |
| **AFIO** | 复用功能 IO 与重映射 | 引脚重定义、EXTI 引脚选择（第 3、5、10、11 章） |

> [!warning] 两条与「总线」有关、后面天天用的结论
> 1. **外设挂在哪条总线上，就要用哪个函数开时钟**：APB2 上的 GPIO/AFIO/USART1/SPI1/ADC1/TIM1 用 `RCC_APB2PeriphClockCmd()`；APB1 上的 TIM2~4、USART2/3、I2C、SPI2、PWR、BKP 用 `RCC_APB1PeriphClockCmd()`。**开错总线，外设一动不动。**
> 2. **APB1 是 36 MHz，APB2 是 72 MHz**，但只有 APB1 上的**定时器**例外——当 APB 预分频系数 ≠ 1 时，定时器时钟是 APB 时钟的 **2 倍**，所以 TIM2 拿到的是 **72 MHz**。这就是第 6 章定时公式里 `CK_PSC = 72 MHz` 的来源（详见 [[江协STM32 06-1 TIM定时中断]]）。

### 3.2 STM32F103C8T6 关键参数

| 项目 | 参数 |
| --- | --- |
| 内核 / 主频 | ARM Cortex-M3 / 最高 72 MHz |
| Flash / SRAM | 64 KB / 20 KB |
| 封装 / 引脚 | LQFP48 / **48 个引脚** |
| 供电电压 | **2.0 ~ 3.6 V**，典型 **3.3 V** |
| IO 电平 | 3.3 V（部分引脚 FT，可容忍 5V 输入） |
| 工作温度 | −40 ~ 85 ℃（型号末位 `6`） |
| 通用 IO | **37 个** |
| 定时器 | 高级 **TIM1**；通用 **TIM2 / TIM3 / TIM4**；另加 SysTick、独立/窗口看门狗 |
| 通信接口 | USART ×3、SPI ×2、I2C ×2、**USB 2.0 全速 ×1、CAN ×1** |
| ADC | **2 个 12 位 ADC**，最多 10 个外部通道 |
| 其他 | 内部 8 MHz RC 振荡器、RTC、DMA ×7 通道、CRC |

> [!note] 参数口径
> 「SPI 2 个 / I2C 2 个」「ADC 2 个、最多 10 个外部通道」是**芯片级**参数，与网上一些「3 个 I2C、2 个 UART、16 个 ADC 通道」的说法不同——后者混入了其他型号或封装。**以 ST 官方数据手册为准**，本页对不一致处已在 `## 待核对` 中列出。

## 4 引脚定义

48 个引脚按**功能类型**分成七大类。看引脚表时，先分类，再看每个引脚的「主功能 / 默认复用 / 重定义」。

### 4.1 按功能类型分类

| 类型 | 引脚 | 作用 | 使用注意 |
| --- | --- | --- | --- |
| **电源 / 地** | `VDD`（×2）、`VSS`（×2）、`VDDA`、`VSSA`、`VBAT` | 数字电源、模拟电源、备用电池 | `VDDA/VSSA` 给 ADC 单独供电，**必须接**，否则 ADC 不准；`VBAT` 接纽扣电池给 RTC/BKP 供电 |
| **晶振** | `OSC_IN / OSC_OUT`（PD0/PD1）、`OSC32_IN / OSC32_OUT`（PC14/PC15） | 8 MHz 主晶振、32.768 kHz RTC 晶振 | 最小系统板上已经焊好 8 MHz 晶振；PC14/PC15 接 RTC 晶振后**不能再做普通 IO** |
| **复位** | `NRST` | 低电平复位，内部带上拉 | 板上一般有复位按键；`NRST` 引脚是**输入**，可外接复位电路 |
| **下载 / 调试** | `PA13`（SWDIO）、`PA14`（SWCLK）、`PA15`（JTDI）、`PB3`（JTDO）、`PB4`（JTRST） | SWD 或 JTAG 调试接口 | **PA13/PA14 复位后就被调试口占用**，想当普通 IO 必须先关调试功能；我们只用 SWD，所以 `PA15/PB3/PB4` 可以释放出来用 |
| **启动配置** | `BOOT0`、`BOOT1`（即 `PB2`） | 决定上电从哪里取指令 | `BOOT0` 是**专用引脚**，最小系统板上做了跳线；`BOOT1` 借用 `PB2` |
| **GPIO** | `PA0~PA15`、`PB0~PB15`、`PC13~PC15` | 通用输入输出 | 上电默认是**浮空输入**，用之前必须 `GPIO_Init()` 配置 |
| **外设复用引脚** | 上述 GPIO 的一部分 | 被片上外设「借用」 | 需要同时开**外设时钟**和 **AFIO 时钟**（启用复用/重映射时） |

### 4.3 主功能 / 默认复用功能 / 重定义功能

这是本集第二个核心概念。同一根引脚可以有**三重身份**，按「要不要额外配置」分层：

| 层次 | 怎么生效 | 举例 | 代码上做什么 |
| --- | --- | --- | --- |
| **主功能** | 复位后的默认身份，不动它就是它 | `PA0` = 通用 IO / 外部中断 / 唤醒 | `GPIO_Init()` 配成输入或输出 |
| **默认复用功能** | 使能对应外设 + 把引脚配成**复用模式**（`GPIO_Mode_AF_PP` 等） | `PA9` = `USART1_TX` | 开 USART1 时钟 + 开 GPIOA 时钟 + `GPIO_Mode_AF_PP` |
| **重定义功能**（Remap） | 还要**额外开 AFIO 时钟**并调用 `GPIO_PinRemapConfig()` | `USART1` 重映射到 `PB6/PB7` | 再多两步：`RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE)` + `GPIO_PinRemapConfig()` |

```text
   引脚 PA9
   ├── 主功能            GPIO / 外部中断
   ├── 默认复用功能       USART1_TX        ← 使能 USART1 + 引脚设为复用推挽输出
   └── 重定义功能         （USART1 可以整体搬到 PB6/PB7）
```

第三个身份带来的两个后果，务必记住：

1. **重定义往往要牺牲别的引脚**。一个外设搬到新引脚后，老引脚一般就空出来了，但新引脚原本的功能会被顶掉。例如 `USART1` 搬到 `PB6/PB7`，`PB6/PB7` 上的 `I2C1` 就不能用了。
2. **重映射由 AFIO 管**。所以只要用到复用/重映射，**AFIO 时钟必须开**——这是第 10、11 章接 MPU6050 和 W25Q64 时最常漏的一步。

> [!tip] 一句话记忆
> **主功能不用配；复用功能要配引脚模式；重定义功能还要加 AFIO + Remap 函数。** 越往下一层，要开的时钟越多。

### 4.4 常用外设的默认引脚与重映射

按「外设 → 默认引脚 → 是否可重映射」整理（`N/A` 表示该外设在这颗芯片上不可重映射）：

| 外设 | 功能 | 默认引脚 | 重映射 |
| --- | --- | --- | --- |
| **USART1** | TX / RX | `PA9` / `PA10` | 可 → `PB6` / `PB7` |
| **USART2** | TX / RX | `PA2` / `PA3` | 可 |
| **USART3** | TX / RX | `PB10` / `PB11` | 可 |
| **I2C1** | SCL / SDA | `PB6` / `PB7` | 可 → `PB8` / `PB9` |
| **I2C2** | SCL / SDA | `PB10` / `PB11` | N/A |
| **SPI1** | SCK / MISO / MOSI / NSS | `PA5` / `PA6` / `PA7` / `PA4` | 可 → `PB3` / `PB4` / `PB5` / `PA15` |
| **SPI2** | SCK / MISO / MOSI / NSS | `PB13` / `PB14` / `PB15` / `PB12` | N/A |
| **TIM1**（高级） | CH1~CH4 | `PA8` / `PA9` / `PA10` / `PA11` | 可 |
| **TIM2**（通用） | CH1~CH4 | `PA0` / `PA1` / `PA2` / `PA3` | 部分可 |
| **TIM3**（通用） | CH1~CH4 | `PA6` / `PA7` / `PB0` / `PB1` | 部分可 |
| **TIM4**（通用） | CH1~CH4 | `PB6` / `PB7` / `PB8` / `PB9` | N/A |
| **ADC1 / ADC2** | 通道 0~9 | `PA0~PA7`（通道 0~7）、`PB0` / `PB1`（通道 8、9） | N/A（模拟输入不可重映射） |
| **EXTI** | 外部中断线 0~15 | 由 AFIO 选择映射到 `PAx` / `PBx` / `PCx` 中的**任意一个** | 通过 `GPIO_EXTILineConfig()` 选择 |

> [!warning] 冲突排查顺序
> 现象是「代码没错，就是没反应」时，按顺序查：
> ① 外设时钟开了吗（APB1 还是 APB2）？② 复用/重映射时 **AFIO 时钟**开了吗？③ 引脚被别的外设占着吗（比如 `PA13/PA14` 被 SWD 占、`PC14/PC15` 被 RTC 晶振占、`PB2` 被 `BOOT1` 占）？④ 重映射函数调对了吗？

## 5 5V 容忍能力（FT 标记）

STM32 **整个芯片是 3.3V 供电**，IO 的高电平就是 3.3V。但数据手册的引脚表里，很多引脚后面跟着一个 **`FT`** 标记：

| | 带 **FT**（Five-volt Tolerant，5V 容忍） | 不带 FT |
| --- | --- | --- |
| 能接入的电压 | 数字输入可以到 **5V** | 只能到 **3.3V**（实际以手册绝对最大额定值为准） |
| 引脚表里的写法 | `I/O FT` / `I/O FTf` | `I/O` |
| 典型引脚 | `PA8~PA15`、`PB2~PB15` 等 | `PA0~PA7`、`PB0/PB1`、`PC13~PC15` 等 |
| 用途 | 直接接收 5V 逻辑器件的输出 | 只能接 3.3V 器件，或先做电平转换 / 分压 |

> [!warning] 三个必须知道的细节
> 1. **FT 说的是「输入」能容忍 5V，不代表输出是 5V**。FT 引脚输出高电平仍然是 3.3V，驱动 5V 器件仍可能识别不到高电平。
> 2. **同一引脚做模拟输入（ADC）时不受 FT 保护**。模拟通道的输入范围受 `VDDA` 限制，接超过 3.3V 的模拟信号会损坏 ADC。
> 3. **不是所有 GPIO 都是 FT**。传 5V 信号给 STM32 之前，**先查手册确认这根脚有没有 FT**；没把握就用分压电阻或电平转换模块，别赌。

### 5.1 FT 引脚清单（STM32F103C8T6）

| 端口 | FT（可容忍 5V 输入） | 非 FT（仅 3.3V） |
| --- | --- | --- |
| GPIOA | `PA8`、`PA9`、`PA10`、`PA11`、`PA12`、`PA13`、`PA14`、`PA15` | `PA0` ~ `PA7` |
| GPIOB | `PB2` ~ `PB15` | `PB0`、`PB1` |
| GPIOC | 无 | `PC13`、`PC14`、`PC15` |
| 专用 | `BOOT0` | `NRST`（复位输入）、`OSC_IN`、`OSC_OUT` |

> [!note] 怎么确认某根脚是不是 FT
> 打开 **ST 官方数据手册的 "Pinouts and pin description" 章节**，在引脚表里找那一行的 **I/O structure** 列：写着 `I/O FT` 就是 5V 容忍，只写 `I/O` 就不是。**这是唯一权威来源**，本表仅作速查，个别引脚的 FT 标记请以手册为准（见 `## 待核对`）。

## 6 最小系统板

**最小系统板**（核心板）= 让芯片能跑起来的**最低限度外围电路**，把芯片焊在板子上，四周用排针引出。

### 6.1 板上有什么

| 电路 | 器件 | 作用 |
| --- | --- | --- |
| **主控芯片** | STM32F103C8T6（LQFP48） | 主角 |
| **主晶振电路** | 8 MHz 无源晶振 + 两个起振电容 | 给芯片外部高速时钟（HSE），倍频到 **72 MHz** |
| **RTC 晶振** | 32.768 kHz 晶振（部分板子可选焊） | 给 RTC 提供低速时钟 |
| **复位电路** | 复位按键 + 上拉/电容 | 按下即把 `NRST` 拉低，芯片重启 |
| **启动选择** | `BOOT0`、`BOOT1` 跳线帽 / 焊点 | 选择启动模式（见第 7 节） |
| **电源电路** | 3.3V 稳压（LDO）+ 指示灯 | 把 USB 的 5V 转成芯片要的 3.3V |
| **下载接口** | 4 针 SWD 排针（3V3 / SWDIO / SWCLK / GND） | 接 STLINK |
| **用户 LED** | 板载 LED（通常接 `PC13`） | 最经典的「点灯」对象，不用外接模块 |
| **USB 接口** | Micro-USB / Type-C | 供电；部分板子可做 USB 通信 |

### 6.2 供电方式

```text
  电脑 USB ──► Micro-USB 口 ──► 板上 3.3V LDO ──► VDD（芯片）
  STLINK  ──► SWD 排针的 3V3 脚 ─────────────────► VDD（芯片）

  ⚠️ 两种方式二选一，不要同时接
```

- 最小系统板的 **USB 口只是供电 + USB 外设**，**不是下载口**（下载走 SWD，用 STLINK）。个别板子上有板载下载器，那属于不同设计，接线前先看清楚。
- 板上一般有 **3.3V 和 5V 输出排针**，可以给面包板上的模块供电。**5V 排针输出的是 USB 的 5V**，给 5V 模块供电没问题，但**不要拿它去接非 FT 的 IO**。

## 7 BOOT0 / BOOT1 与启动模式

STM32 上电或复位后，会先去**一段固定地址**取第一条指令（更准确地说，是从 `0x0000 0000` 起的存储空间取复位向量，而这块空间由启动模式决定映射到谁）。`BOOT0` 和 `BOOT1` 两脚就是这个映射的开关。

### 7.1 启动模式表

| 启动模式 | `BOOT1`（`PB2`） | `BOOT0` | 映射的存储区 | 用途 |
| --- | --- | --- | --- | --- |
| **主闪存存储器**（Main Flash） | `x`（任意） | **`0`** | 片内 **64 KB Flash** | **正常运行模式**。下载的程序存在这里，上电就跑它 |
| **系统存储器**（System Memory） | **`0`** | **`1`** | ST 出厂固化的 **BootLoader** | **串口下载（ISP）**：通过 `USART1` 把程序写进 Flash，用于没有下载器时 |
| **内置 SRAM** | **`1`** | **`1`** | 片内 **20 KB SRAM** | **调试用**：程序跑在 RAM 里，掉电即失，可反复快速下载 |

```text
   BOOT0 = 0 ─────────────────────────► 从 Flash 启动（正常跑程序）
   BOOT0 = 1 ┬─ BOOT1 = 0 ─────────────► 从系统存储器启动（串口 ISP 下载）
             └─ BOOT1 = 1 ─────────────► 从内置 SRAM 启动（调试）
```

> [!warning] 三个必知事项
> 1. **`BOOT1` 就是 `PB2`**。把它当启动配置用了，就**不能同时拿 `PB2` 做普通 GPIO / 外部中断**——这是引脚复用的经典冲突。
> 2. **正常开发时 `BOOT0 = 0`（跳线帽接地）**。用 STLINK 通过 SWD 下载时不需要改 BOOT，SWD 有自己的通道。
> 3. **改完 BOOT 必须复位**（按一下复位键或重新上电），芯片在复位那一刻才读取 `BOOT` 引脚，运行中改它没有意义。

## 8 常用外设与课程章节对照

把这一集认识的「芯片里有什么」和第 1-1 集的课程章节对上：

| 外设 | 是什么 | 课程章节 | 备注 |
| --- | --- | --- | --- |
| **RCC** | 复位与时钟控制 | 第 2 章起全程使用 | 每个外设初始化的第一步 |
| **GPIO** | 通用输入输出 | 第 3 章 | 最基础，也是后面所有外设的载体 |
| **AFIO** | 复用功能 IO / 重映射 / EXTI 引脚选择 | 第 3、5、10、11 章 | **最常被忘记开时钟**的一个 |
| **EXTI + NVIC** | 外部中断 + 中断控制器 | 第 5 章 | NVIC 属于**内核**，EXTI 属于**外设** |
| **TIM** | 定时器（TIM1 高级，TIM2~4 通用） | 第 6 章 | 定时中断、PWM、输入捕获、编码器接口 |
| **ADC** | 12 位模数转换 | 第 7 章 | 需要 `VDDA/VSSA` 供电 |
| **DMA** | 直接存储器存取 | 第 8 章 | 不经过 CPU 搬数据 |
| **USART** | 串口（UART 同步/异步） | 第 9 章 | `PA9/PA10`，配合 USB 转串口模块 |
| **I2C** | 双线总线 | 第 10 章 | 接 MPU6050，默认 `PB6/PB7` |
| **SPI** | 四线总线 | 第 11 章 | 接 W25Q64，默认 `PA5/PA6/PA7` |
| **BKP / RTC** | 备份寄存器 / 实时时钟 | 第 12 章 | 靠 `VBAT` 保持 |
| **PWR** | 电源控制（睡眠 / 停机 / 待机） | 第 13 章 | 低功耗 |
| **IWDG / WWDG** | 独立 / 窗口看门狗 | 第 14 章 | 程序跑飞时自动复位 |
| **FLASH** | 片内 Flash 读写 | 第 15 章 | 相当于一个小的「硬盘」 |

> [!tip] 一张图记住优先级
> **RCC（时钟）→ GPIO（引脚）→ AFIO（复用）→ 具体外设**。任何外设初始化卡住，先回到这个顺序自查。

## 9 易错点

- [ ] 以为「ARM 造了 STM32」→ ARM 只设计**内核**，外设、封装、型号都是 **ST** 的。
- [ ] 把型号里的 `C` 当成 Flash 容量 → `C` 是**引脚数（48）**，Flash 容量是**第 5 位 `8`（64 KB）**。
- [ ] 想当然认为 C8T6 有 128 KB Flash → 标称只有 **64 KB**（SRAM 20 KB）。
- [ ] 把「复用功能」当成默认就能用 → 必须把引脚配成**复用模式**（`GPIO_Mode_AF_PP` / `GPIO_Mode_IPU` 等）。
- [ ] 用重映射却忘了开 **AFIO 时钟** → 引脚死活不切换，这是最高频的坑。
- [ ] 把 5V 信号直接接到 `PA0`、`PB0` 这类**非 FT** 引脚 → 3.3V 芯片可能被拉坏。
- [ ] 以为 FT 引脚输出也是 5V → 输出永远是 3.3V，FT 只保护**输入**。
- [ ] 拿 `PA13/PA14` 当普通 IO → 它们复位后是 **SWD 调试口**，改了就连不上下载器（要先用 `GPIO_PinRemapConfig()` 关掉 JTAG/SWD 再改）。
- [ ] 拿 `PC14/PC15` 当普通 IO → 板上焊了 RTC 晶振的话它们已被占用。
- [ ] 拿 `PB2` 当普通 IO → 它同时是 **`BOOT1`**。
- [ ] 开错时钟总线 → APB1 上的外设（TIM2~4、USART2/3、I2C、SPI2、PWR、BKP）必须用 `RCC_APB1PeriphClockCmd()`。
- [ ] 用 5V 给芯片的 `VDD` 供电 → STM32F103 供电范围是 **2.0~3.6V**，板上 LDO 的作用就是把 USB 的 5V 转成 3.3V。
- [ ] 忘记接 `VDDA/VSSA` → ADC 读数不准甚至不工作。
- [ ] 改了 `BOOT0` 却没复位 → 启动模式不会生效。
- [ ] 拿 USB 线和 STLINK 同时供电 → 双路供电，有风险。

## 10 自测

1. `STM32F103C8T6` 这个型号里，`C`、`8`、`T`、`6` 分别代表什么？
2. 「Cortex-M3 内核」和「STM32 的外设」分别是谁设计的？这对查资料有什么影响？
3. `PA9` 上的 `USART1_TX` 属于主功能、默认复用功能还是重定义功能？如果想把它改到 `PB6`，代码上要多做哪两件事？
4. 一个 5V 输出的传感器，信号线能不能直接接 `PA0`？接 `PA9` 呢？为什么？
5. 上电后想从系统存储器（串口 ISP 下载）启动，`BOOT0` 和 `BOOT1` 分别应该是什么电平？下载完想正常运行程序又要怎么改？

> [!success]- 参考答案
> 1. `C` = **引脚数 48**；`8` = **Flash 64 KB**；`T` = **封装 LQFP**；`6` = **温度范围 −40 ~ 85 ℃**。
> 2. **内核由 ARM 公司设计**（ARM 只授权设计，不生产），**外设由 ST 公司设计**。所以：内核相关的问题查 ARM/ST 的 *Cortex-M3 编程手册（PM0056）*；外设与引脚的问题查 ST 的 *参考手册（RM0008）/ 数据手册*。
> 3. 属于**默认复用功能**——`PA9` 是 `USART1_TX` 的默认引脚，只要使能 USART1 并把引脚配成复用推挽输出即可，不需要 AFIO。改到 `PB6` 属于**重定义功能**，要额外做两件事：① `RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE)` 开 **AFIO 时钟**；② 调用 `GPIO_PinRemapConfig()` 打开 USART1 重映射。
> 4. 接 `PA0` **不行**：`PA0` 不带 FT，只能承受 3.3V，5V 输入可能损坏引脚（而且 `PA0` 常做 ADC 输入，更要注意）。接 `PA9` **可以**：`PA9` 带 FT 标记，数据手册允许 5V 数字输入。**但前提是查过手册确认该脚为 FT，且它当模拟输入用时不受 FT 保护。**
> 5. 系统存储器启动要 **`BOOT0 = 1`、`BOOT1 = 0`**；改完后**必须复位**才生效。正常运行程序时改回 **`BOOT0 = 0`**（`BOOT1` 任意），再复位一次。
