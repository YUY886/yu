# 01-1 课程简介

> [!abstract] 这一集只解决一个问题
> **这门课要教我什么？我需要准备什么？**
>
> 答：用 **STM32F103C8T6 最小系统板**，跟着 **15 章、50 个分 P** 的顺序，从 GPIO 开始一路做到定时器、ADC、串口、I2C、SPI……每集都是「讲原理 → 现场写标准库代码 → 上板验证」，学完能独立看懂并写出常见外设的标准库驱动。
>
> 章索引 [[江协STM32 01 STM32简介（章索引）]] ｜ 下一集 [[江协STM32 01-2 STM32简介]]

## 1 课程定位：这门课到底教什么

一句话：**这门课教的是「怎么用标准库把 STM32 的外设配起来」，不是教 C 语言，也不是教电路设计。**

它的定位可以拆成三条：

- **面向零基础入门**：讲师在开头就说明，即使完全没接触过单片机也能跟下来；前提是 C 语言和数字电路基础（见第 5 节）。
- **标准库路线**：用的是 ST 官方的 **标准外设库（Standard Peripheral Library）**，而不是 HAL 库或寄存器直接编程。原因是标准库代码短、结构清晰、贴近寄存器，**最适合理解外设到底在干什么**。
- **手把手现场写代码**：每一集的结构基本固定——先画框图讲原理，再打开 Keil 从头敲代码，然后下载到板子上看现象。不预设你已经会什么。

> [!tip] 关于「标准库已经过时」这个顾虑
> ST 官方确实已经不再主推标准库，新项目多用 HAL。但**学习阶段标准库更好**：一行 `GPIO_Init()` 背后是什么寄存器、什么位，看得清清楚楚。学会了标准库，回头看 HAL 只是多一层封装；反过来先学 HAL，很容易变成「只会调 API，不知道为什么」。

## 2 课程结构：15 章，50 个分 P

课程是一条**从简单到复杂的外设主线**，章节顺序基本等于「学单片机的合理顺序」：

```text
第 1 章  课程简介 / STM32简介        ← 你在这里，只有 2 集，纯理论
第 2 章  软件安装 / 新建工程          ← 把工具链搭起来
第 3 章  GPIO 输出与输入              ← 第一个能点亮 LED 的外设
第 4 章  OLED 调试工具与显示屏        ← 后面所有集都靠它看数据
第 5 章  EXTI 外部中断                ← 中断、NVIC、中断服务函数
第 6 章  TIM 定时器                   ← 全课程最重的一章，8 集
第 7 章  ADC 模数转换器
第 8 章  DMA 直接存储器存取
第 9 章  USART 串口
第 10 章 I2C 通信 / MPU6050
第 11 章 SPI 通信 / W25Q64
第 12 章 Unix 时间戳 / BKP / RTC
第 13 章 PWR 电源控制
第 14 章 WDG 看门狗
第 15 章 FLASH 闪存                   ← 最后一集是综合项目
```

三条结构上的观察，比死记章号有用：

| 阶段 | 章节 | 特征 |
| --- | --- | --- |
| **打地基** | 1 ~ 4 | 工具链 + GPIO + OLED。**OLED 是后面所有章节的「眼睛」**，第 4 章之后每集都在用它显示变量 |
| **核心能力** | 5 ~ 9 | 中断、定时器、ADC、DMA、串口。这五章是嵌入式开发真正天天用的东西，也是后面模块类章节的依赖 |
| **外设总线与系统** | 10 ~ 15 | I2C/SPI 总线接真实芯片，RTC、电源、看门狗、Flash 属于单片机「自管理」部分 |

- **第 6 章占 8 集、约 5 小时**，是全课程投入最大的一章。学不动的时候知道「这是最重的一章」本身就有用。
- **第 15 章最后一集是综合项目**，把前面学的东西串起来用一次。

> [!note] 关于总集数
> 课程主页目录显示分 P 到 P49（第 15 章最后一集），与「15 章、约 50 集」的说法一致。具体分 P 编号请以 B 站视频目录为准。
> 课件（`STM32入门教程.pptx`）前 13 页就是本章内容（第 5~13 页依次为：STM32 简介、ARM、STM32F103C8T6 参数、片上资源/外设、命名规则、系统结构、引脚定义、启动配置、最小系统电路），**课件里没有出现「50 集」这个数字**；「15 章」可由课件章节结构核出（简介→软件安装→新建工程→GPIO→OLED→EXTI→TIM→ADC→DMA→USART→I2C→SPI→Unix 时间戳/BKP/RTC→PWR→WDG→FLASH，共 207 页），「50 集」仍以 B 站分 P 目录为准。

## 3 需要准备的硬件

### 3.1 必备三件套

| 硬件 | 说明 | 备注 |
| --- | --- | --- |
| **STM32F103C8T6 最小系统板** | 课程的主角，蓝色那种「核心板」 | 板载 8 MHz 晶振、复位按键、电源指示灯、BOOT 跳线、SWD 调试接口 |
| **STLINK 下载器** | 负责把电脑里的程序烧进芯片，也负责调试 | 接的是 **SWD 接口**（SWDIO / SWCLK / GND / 3.3V），用到 PA13、PA14 |
| **面包板 + 杜邦线** | 免焊接线，把模块和开发板连起来 | 建议公对母、母对母各备一把 |

### 3.2 各章节要用的模块

课程不是「一块板子走到底」，几乎每章都会接一两个模块。按章节整理：

| 章节 | 用到的模块 / 器件 |
| --- | --- |
| 3 章 GPIO | LED、按键 |
| 4 章 调试 | **OLED 显示屏（I2C）** |
| 5 章 中断 | 按键（配合外部中断） |
| 6 章 定时器 | 旋转编码器、舵机、直流电机（配 TB6612 之类的电机驱动）、LED |
| 7 章 ADC | 光敏电阻 / 热敏电阻 / 电位器等模拟传感器 |
| 8 章 DMA | 复用 ADC 通道，无新增模块 |
| 9 章 串口 | USB 转串口模块（CH340 等） |
| 10 章 I2C | **MPU6050**（六轴姿态传感器） |
| 11 章 SPI | **W25Q64**（SPI Flash 存储芯片） |
| 12~15 章 | 基本复用已有模块，最后一章做综合项目 |

> [!tip] 可以整套买
> 这些模块通常有打包好的「STM32 入门套件」。**不必一次买齐**——第 4 章的 OLED 可以提前买（后面每章都要用），其余按章节进度买即可。

### 3.3 供电要特别注意

最小系统板一般通过**下载器的 3.3V 或板上的 Micro-USB / Type-C 口**取电，两种方式二选一即可，**不要同时接**。

> [!warning] 3.3V 芯片，别直接接 5V
> STM32 的 IO 是 **3.3V 电平**。只有数据手册里标了 **FT（Five-volt Tolerant，5V 容忍）** 的引脚才能直接接 5V 输入。舵机、电机、部分传感器模块是 5V 供电的，**信号线和电源线都要分清**：模块可以用 5V 供电，但它的信号输出必须确认是 3.3V 电平，否则中间要加电平转换。详见 [[江协STM32 01-2 STM32简介]] 的引脚定义一节。

## 5 学习建议与前置知识

### 5.1 前置知识

| 前置 | 需要到什么程度 | 为什么 |
| --- | --- | --- |
| **C 语言** | 能看懂并写出函数、数组、`if/for/while` | 全部代码都是 C |
| C 语言进阶 | **指针、结构体、位运算、宏定义** | 标准库的 `GPIO_InitTypeDef` 是结构体；`GPIO_Pin_0` 是宏；库函数大量用指针传参。**位运算不熟，第 3 章 GPIO 就会卡住** |
| **数字电路基础** | 知道高低电平、上拉/下拉、推挽/开漏是什么 | 讲 GPIO 模式和电路连接时要用 |
| 51 单片机 / Arduino | 有更好，没有也行 | 中断、定时器这些概念可以迁移过来，但**不要求** |

「位运算」具体要会这几个：按位与、按位或、按位取反、左移、右移。因为标准库里到处是 `GPIO_Pin_0 | GPIO_Pin_1` 这种按位或的组合写法，看得懂这一行，才看得懂 GPIO 初始化。

### 5.2 学习建议

- **先看视频，别边看边敲。** 第一遍专心听原理，理解了再回头写代码。
- **代码要自己手敲，不要复制粘贴。** 手敲的过程会强迫你注意每一个参数名和分号，复制粘贴会跳过这一步。
- **每集学完必须上板验证现象。** 只看懂不算学会，代码跑不出预期现象才是真正的学习时刻。
- **配合本套 Obsidian 笔记复习**：视频负责「跟着做」，笔记负责「回头查」。
- **卡住时先查数据手册，再问人。** 第 1-2 集讲的引脚定义、第 6 章讲的寄存器行为，答案都在手册里。

### 5.3 代码长什么样

这门课的代码有固定的骨架，先看一眼心里有数（这一段是示意，正式的第一个工程在第 3 章）：

```c
#include "stm32f10x.h"   // 标准外设库的总头文件，所有外设都要包含它

int main(void)
{
	/* 初始化阶段：每个外设都要"开时钟 → 配结构体 → 调 Init 函数" */

	/* 主循环：程序永远不退出，在这里反复执行任务 */
	while (1)
	{
		// 用户代码：读输入、算结果、写输出
	}
}
```

三个固定套路，后面每一集都在重复：

- **`#include "stm32f10x.h"`** 几乎是每个 `.c` 文件的第一行。
- **外设使用三步曲**：`RCC_xxxPeriphClockCmd()` 开时钟 → 填 `xxx_InitTypeDef` 结构体 → 调 `xxx_Init()`。
- **`while (1)` 死循环**：单片机程序没有「运行结束」这一说。

## 6 学完之后能做什么

按课程目标，学完 15 章应该达到：

- **看得懂**：拿到一份 STM32 标准库工程，能顺着 `main()` 读懂它在干什么、用了哪些外设。
- **写得出**：给定一个外设和需求，能独立查手册 + 查库函数，把初始化代码写出来（而不是靠抄）。
- **接得上**：能自己把 OLED、传感器、电机驱动等模块接到 STM32 上，处理电平、供电和引脚冲突。
- **做得出一个小项目**：定时采集传感器数据 → OLED 显示 → 串口上传 → 按键或中断控制执行器，这类典型的单片机项目可以独立完成。
- **能迁移**：标准库的这套「时钟 + 结构体 + Init」思路，对 F4/F7 甚至别的厂商芯片同样适用，换芯片主要是查手册而不是重学。

> [!tip] 一个现实的期待
> 学完一门入门课不等于「精通 STM32」。这门课的价值是把**外设的使用方法和资料查阅习惯**建立起来——真正做项目时，工况、时序、干扰这些问题，仍然要靠手册和实测去解决。

## 7 易错点

- [ ] 以为要先精通 C 语言和电路才能开始 → **不必要**，会函数、数组、结构体、位运算就够起步。
- [ ] 一上来就买齐所有模块 → 建议先买最小系统板 + STLINK + 面包板 + OLED，其余按章节进度补。
- [ ] 用 USB 线和下载器同时给板子供电 → 双路供电可能损坏芯片或电脑 USB 口。
- [ ] 把 5V 模块的信号线直接接到非 FT 引脚 → 超出手册的电压范围，可能烧引脚。
- [ ] 只买 STLINK 却不知道它接的是 SWD 还是 JTAG → 最小系统板通常只引出 **SWD**（SWDIO / SWCLK），接线不要接错。
- [ ] 视频只看不写代码、不上板 → 效果约等于没学。
- [ ] 在第 1 章就折腾 Keil 环境 → 跟着第 2 章做，少踩一半坑。
- [ ] 用 HAL 库的教程去对标准库的课程 → 函数名完全不同，别混着学。

## 8 自测

1. 这门课用的是标准库、HAL 库还是寄存器直接编程？为什么入门阶段选它？
2. STM32F103C8T6 最小系统板上，STLINK 是通过哪两个引脚和芯片通信的？
3. 一个 5V 供电的传感器模块，信号输出是 5V，可以直接接到 PA0 吗？为什么？
4. 课程中为什么说第 4 章的 OLED 很重要？
5. 学这门课之前，C 语言里哪几个知识点是必须掌握的？

> [!success]- 参考答案
> 1. **标准库（标准外设库）**。因为它代码短、贴近寄存器，能看清「配了哪个寄存器的哪个位」，适合建立外设的底层认知；HAL 封装层数更多，入门时容易变成只记函数名。
> 2. **PA13（SWDIO）和 PA14（SWCLK）**，即 SWD 调试接口；另外还需要 GND 和 3.3V。
> 3. **不可以（除非确认 PA0 属于 FT 引脚且按手册允许）**。STM32 的 IO 是 3.3V 电平，5V 输入会超出允许范围。正确做法是加电平转换或电阻分压，或者换用带 FT 标记的引脚（并注意其限制）。
> 4. 因为从第 4 章开始，**OLED 是后面几乎所有章节的显示工具**——定时器计数值、ADC 采样值、串口收到的数据都靠它显示出来，没有它很多现象根本看不到。
> 5. **指针、结构体、位运算（`&` `|` `~` `<<` `>>`）、宏定义**，外加函数、数组和基本控制语句。
