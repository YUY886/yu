## 本章速查

### STM32F103C8T6 关键参数

| 项目 | 参数 | 说明 |
| --- | --- | --- |
| 内核 | ARM Cortex-M3 | **ARM 公司设计**，ST 只是用户 |
| 主频 | 72 MHz | 最大工作频率 |
| 程序存储器 | 64 KB Flash | 型号里的 `8` 就是它 |
| 数据存储器 | 20 KB SRAM | 型号字符里没有体现 |
| 封装 / 引脚 | LQFP48 / 48 脚 | 型号里的 `T`（封装）与 `C`（48 脚） |
| 供电 | 2.0 ~ 3.6 V，典型 3.3 V | 5V 引脚要串电阻或用 FT 引脚 |
| 工作温度 | −40 ~ 85 ℃ | 型号里的 `6` |

### 命名规则六段（`STM32 F 103 C 8 T 6`）

| 段 | 字符 | 含义 |
| --- | --- | --- |
| ① 品牌+内核 | `STM32` | ST 的 32 位 MCU，ARM Cortex-M 内核 |
| ② 系列 | `F` | F = 基础型 / 通用型（L = 低功耗，H = 高性能） |
| ③ 子系列 | `103` | 增强型，本课程用的就是这一档 |
| ④ 引脚数 | `C` | T = 36 脚，**C = 48 脚**，R = 64 脚，V = 100 脚，Z = 144 脚 |
| ⑤ Flash 容量 | `8` | 6 = 32 KB，**8 = 64 KB**，B = 128 KB，C = 256 KB，D = 384 KB，E = 512 KB |
| ⑥ 封装 | `T` | **T = LQFP**，H = BGA，U = QFN，Y = WLCSP |
| ⑦ 温度范围 | `6` | **6 = −40 ~ 85 ℃**，7 = −40 ~ 105 ℃ |

> [!tip] 记住一个等式
> `STM32F103C8T6` = **48 脚 · 64 KB Flash · LQFP 封装 · −40~85 ℃ 的 Cortex-M3 芯片**。买模块时型号对不上，引脚和容量就都对不上。

### 三种「引脚功能」的区别

| 说法 | 触发方式 | 典型例子 |
| --- | --- | --- |
| 主功能 | 复位后的默认身份，不动它就是它 | PA0 = GPIO / 外部中断 / 唤醒 |
| 默认复用功能 | 使能外设 + 把引脚配成复用模式，**不用动 AFIO** | PA9 = USART1_TX |
| 重定义功能（Remap） | 还要额外开 `AFIO` 时钟并写重映射寄存器 | USART1 重映射到 PB6/PB7 |

> [!warning] 只记一条就够用的规则
> **带 FT（Five-volt Tolerant）标记的引脚可以容忍 5V 输入，不带的只能 3.3V。** 引脚表里没写 FT 的，接 5V 传感器前先加电平转换或分压。
> 本芯片共 **15 个 FT 引脚**：`PA8~PA15`（8 个）+ `PB2`、`PB3`、`PB4`、`PB6`、`PB7`、`PB8`、`PB9`、`PB10~PB15`（7 个）。**注意 `PB0`、`PB1`、`PB5` 不是 FT。**
