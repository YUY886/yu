# 06-3 TIM 输出比较

> [!abstract] 这一集只解决一个问题
> **怎么让定时器不靠 CPU 插手，自己输出一个频率、占空比都可调的方波？**
>
> 答：把 `CNT` 和 `CCR` 一起送进**输出模式控制器（Output Mode Controller）**，比较结果直接决定参考信号 `OCxREF` 的高低，再经过**极性选择**和**输出使能**送到 `OCx` 引脚。这就是 **PWM（脉冲宽度调制）** 的硬件来源。
>
> 上一集 [[江协STM32 06-2 定时器外部时钟]] ｜ 章索引 [[江协STM32 06 TIM定时器（章索引）]] ｜ 下一集 [[江协STM32 06-4 PWM 应用]]

## 1 输出比较（OC）是什么

先把三个容易混的缩写分清：

| 缩写 | 英文全称 | 中文 | 含义 |
| --- | --- | --- | --- |
| **OC** | Output Compare | 输出比较 | 用比较结果去**控制引脚输出** |
| **IC** | Input Capture | 输入捕获 | 用边沿去**抓取 CNT 的值**（6-5 讲） |
| **CC** | Capture/Compare | 捕获/比较（单元） | 上面两个功能共用的硬件单元 |

核心机制一句话：

> **输出比较（OC）通过比较 CNT 与 CCR 寄存器值的关系，来对输出电平进行置 1、置 0 或翻转的操作，用于输出一定频率和占空比的 PWM 波形。**

- **CNT**：时基单元的计数器，硬件自己不停地自增，不需要我们管。
- **CCR**：捕获/比较寄存器（Capture/Compare Register），**这是我们自己写进去的一个比较值**。
- 两者持续比较 → 比较结果驱动输出电平不断跳变 → 得到 PWM。

> [!note] CCR 是「一个寄存器，两套用法」
> 这个捕获/比较寄存器是**输入捕获和输出比较公用**的：当使用输入捕获时，它就是**捕获寄存器**；当使用输出比较时，它就是**比较寄存器**。
> 这条性质直接决定了第 7 节里那个结论——**输入捕获和输出比较不能同时用**。

各定时器有多少个输出比较通道：

| 定时器类型 | 输出比较通道 | 说明 |
| --- | --- | --- |
| 高级定时器（TIM1 / TIM8） | **4 个** | 前 3 个通道额外拥有**死区生成**和**互补输出**功能 |
| 通用定时器（TIM2 ~ TIM5） | **4 个** | 本课程最常用，可同时输出 4 路 PWM |
| 基本定时器（TIM6 / TIM7） | **0 个** | **没有**输出比较功能 |

同一个定时器的四个通道：**各有各的 CCR 寄存器，但共用一个 CNT 计数器**。

- 共用一个 CNT ⇒ 四路 PWM 的**频率必然相同**（都取决于同一个时基单元）。
- 各有各的 CCR ⇒ 四路的**占空比可以各不相同**。

## 2 输出模式控制器：8 种模式

输出模式控制器（Output Mode Controller）的**输入是 CNT 与 CCR 的大小关系**，**输出是 `OCxREF` 的高低电平**。里面可以选择多种模式，具体选哪个由寄存器配置。

| 模式 | `OCxM` 编码 | 动作条件 | `OCxREF` 的行为 | 与计数方向的关系 | 用途 |
| --- | --- | --- | --- | --- | --- |
| **冻结 Frozen** | `000` | 无 | 保持上一个状态不变 | 无关 | 相当于 CNT 和 CCR 都失效，暂停波形、冻住当前电平 |
| **匹配时置有效电平** | `001` | `CNT = CCR` 那一刻 | 置为**有效电平** | 无关，两个方向都会匹配 | 一次性的单次动作，置完就不管了，不适合输出连续波形 |
| **匹配时置无效电平** | `010` | `CNT = CCR` 那一刻 | 置为**无效电平** | 无关，两个方向都会匹配 | 同上，一次性动作 |
| **匹配时电平翻转** | `011` | `CNT = CCR` 那一刻 | 电平**取反**（翻转） | 无关，两个方向都会匹配 | 可方便地输出**占空比恒为 50%** 的方波；**输出频率 = 更新频率 / 2** |
| **强制为无效电平** | `100` | 无 | 强制输出**无效电平** | 无关 | 运行中强制停波形并固定为低电平 |
| **强制为有效电平** | `101` | 无 | 强制输出**有效电平** | 无关 | 运行中强制停波形并固定为高电平 |
| **PWM 模式 1** | `110` | 持续比较 CNT 与 CCR | 见下方专表 | **有方向差异** | **主用模式**，输出频率、占空比都可调的 PWM |
| **PWM 模式 2** | `111` | 持续比较 CNT 与 CCR | 与模式 1 **大小关系相同，有效/无效相反** | **有方向差异** | **主用模式**，等于 PWM 模式 1 输出的取反 |

关于「有效电平 / 无效电平」：

> [!tip] 有效电平 ≈ 高电平，无效电平 ≈ 低电平
> 有效电平（Active Level）和无效电平（Inactive Level）本来是**高级定时器**里配合**关断、刹车**等功能使用的严谨说法。为了理解方便，本集可以直接认为：**置有效电平就是置高电平，置无效电平就是置低电平。**

PWM 模式 1 和 PWM 模式 2 的完整关系（**这张表要背下来**）：

| 模式 | 向上计数（UP） | 向下计数（DOWN） |
| --- | --- | --- |
| **PWM 模式 1** | `CNT < CCR` → 有效电平<br>`CNT ≥ CCR` → 无效电平 | `CNT > CCR` → **无效**电平<br>`CNT ≤ CCR` → **有效**电平 |
| **PWM 模式 2** | `CNT < CCR` → **无效**电平<br>`CNT ≥ CCR` → **有效**电平 | 大小关系与模式 1 相同，有效/无效**反过来** |

> [!warning] 三条容易记错的点
> 1. **向上计数**才是我们实际使用的方向，`PWM 模式 1 + 向上计数` 是标准搭配，先把这一行记牢。
> 2. 模式 1 与模式 2 的**大小比较关系完全一样**，区别只有**最终输出的高低电平反过来**——所以 PWM 模式 2 就是 PWM 模式 1 输出的取反。
> 3. 别把「模式里设的极性」和「后面 CCER 里设的极性」搞混：**同一个信号有两次设置极性的机会**（见下一节的电路），所以现实中**只用 PWM 模式 1 + 向上计数就够了**，需要反相就在后面那级改。

## 3 输出比较通道电路：从 CNT/CCR 到 OCx 引脚

以通用定时器通道 1（CH1）为例，信号的走向是：

```text
                                  ┌─► 主模式控制器 ──► TRGO（触发其他定时器 / DAC / ADC）
                                  │      （TRGO = Trigger Out）
┌──────────────┐    ┌──────────┐  │
│ CNT（计数器）│    │ 输出模式 │  │
│      ↕ 比较  ├───►│ 控制器   ├──┴─► OC1REF ──►[ 极性选择 ]──►[ 输出使能 ]──► OC1 引脚
│ CCR1（我们写）│    │ 8 种模式 │        （参考信号，reference）
└──────────────┘    └──────────┘            ↑                ↑
                          ↑                CCER 寄存器      输出使能位
                       ETRF 输入（一般不用）
```

逐段说明：

1. **比较**：左边是 CNT 计数器和 CCR1 捕获/比较寄存器，两者进行比较，当 `CNT > CCR1`、`CNT < CCR1` 或 `CNT = CCR1` 时，把结果送给输出模式控制器。
2. **输出模式控制器**：按上一节 8 种模式的逻辑，决定 `OC1REF` 什么时候高、什么时候低。`REF` 是 reference（参考信号）的缩写。
3. **`ETRF` 输入**：输出模式控制器上面还有一个 `ETRF` 输入，这是定时器的一个小功能，**一般不用**。
4. **`OC1REF` 的第二个去向**：`REF` 信号可以送到**主模式控制器**，被映射到主模式的 `TRGO` 输出上去（后续主从触发模式会用到）。不过 `REF` 最主要的去向还是下面这一路。
5. **极性选择（在 CCER 寄存器里）**：写 0 信号不翻转，进去什么样出来什么样；写 1 信号经过一个非门取反，高低电平反转。（**注意：极性选择在寄存器里是「写 1 才反相」，而后面编程时库函数的取值含义要按库函数的说明来，别把这两套记混。**）
6. **输出使能**：决定这个信号到底要不要输出到引脚。
7. **`OC1` 引脚**：这就是 CH1 通道对应的 GPIO 引脚，具体是哪个口要**查引脚定义表**。

> [!note] 别漏了「极性可以设两次」这件事
> 模式控制器里可以把信号看成一种极性，最后的 CCER 极性选择又可以把信号翻一次，中间还夹着一次取反。所以调波形时**先确认自己到底想要哪一级的极性**，否则会出现「占空比明明写对了，波形却是反的」。

### 3.1 本集提到的输出比较库函数

本集只介绍函数和**编程思路**，真正动手写 PWM 代码在 6-4。

| 函数 | 作用 |
| --- | --- |
| `TIM_OC1Init` ~ `TIM_OC4Init` | 配置 4 个输出比较单元（模式、极性、输出使能、CCR） |
| `TIM_OCStructInit` | 给输出比较结构体赋默认值（高级定时器专属成员也必须有值） |
| `TIM_ForcedOC1Config` ~ `TIM_ForcedOC4Config` | 配置**强制输出模式**，运行中要暂停波形并强制输出高/低电平时用 |
| `TIM_OC1PreloadConfig` ~ `TIM_OC4PreloadConfig` | 配置 CCR 的**预装载**功能（影子寄存器） |
| `TIM_SetCompare1` ~ `TIM_SetCompare4` | 单独修改 CCR 的值，**运行中改占空比就用它** |
| `TIM_CtrlPWMOutputs` | **仅高级定时器使用**，用于使能主输出，不调用则 PWM 无法正常输出 |

配置的 5 步思路：

```text
/* 6-3 只给思路，具体参数取值在 6-4 动手写 */
① RCC 开启时钟：把 TIM 外设和 GPIO 外设的时钟都打开
② 配置时基单元：时钟源选择 + PSC / ARR（这一部分和 6-1 完全一样）
③ 配置输出比较单元：TIM_OC1Init 填入 CCR 值、输出比较模式、极性、输出使能
④ 配置 GPIO：把 PWM 对应的引脚初始化为复用推挽输出（AF_PP）
⑤ 运行控制：TIM_Cmd 启动计数器，PWM 就从引脚输出了
```

> [!warning] 两个要点别踩
> - 这里**更新事件的中断申请我们不再需要了**（6-1 的第 ④⑤ 步可以不配），定时器只是安静地数数、输出波形。
> - GPIO 必须配成**复用推挽输出**：普通开漏/推挽输出的引脚控制权来自输出数据寄存器，只有复用模式下输出数据寄存器被断开、**控制权才交给片上外设**，定时器才能控制这个引脚。

## 4 高级定时器的额外部分：互补输出、死区与刹车

高级定时器（TIM1 / TIM8）在第 3 节那套通道电路的基础上，又对输出比较模块做了升级：

### 4.1 互补输出 OCx / OCxN

`TIMx_CH1 / CH2 / CH3` 由原来的**每路一个引脚**变成了**两个互补的输出引脚**：

| 引脚 | 说明 |
| --- | --- |
| `TIMx_CH1` / `CH2` / `CH3` | 原来的输出 |
| `TIMx_CH1N` / `CH2N` / `CH3N` | 互补输出（N = Negative，取反的那一路） |
| `TIMx_CH4` | 第 4 路**没有变化**，也没有互补引脚 |

一对互补的 PWM 波，正是驱动**三相无刷电机**所需：三相电机驱动电路需要**三个桥臂**，每个桥臂需要 **2 个大功率开关管**，总共 **6 个大功率开关管**——所以前三路引脚要变成互补输出，正好对应三路（三相电机只需要三路）。

四轴飞行器、电动车后轮、电钻里都能见到三相无刷电机。

### 4.2 死区生成 DTG

为了防止互补输出的 PWM 驱动桥臂时，在开关切换的瞬间因为器件不理想造成**短暂的直通（上下管同时导通）**，在互补输出前面加了一级**死区生成电路（图中标 DTG，由 DTG 寄存器控制）**：

```text
OCxREF ──►[ 死区生成电路 DTG ]──┬──► OCx（上路，略有延迟）
                                └──► OCxN（下路，延迟不同）
        在开关切换的瞬间插入一段「死区」时间，
        让桥臂的上下管全部关断，避免直通短路
```

### 4.3 刹车输入

**刹车输入（BKIN，Break In）** 的作用是给电机驱动提供安全保障：如果外部引脚 `BKIN` 产生了刹车信号，或者内部时钟失效产生了故障，控制电路就会**自动切断电机的输出**，防止意外发生。（时钟失效由时钟安全系统 CSS 检测并反映到输出控制器。）

> [!tip] 和推挽电路 / H 桥的关系
> 上面这套「互补输出 + 死区」本质就是在硬件层面安全地驱动**推挽电路**（上下两个开关管）和**H 桥**（两组推挽半桥，负载跨在中间）。H 桥换向时，上臂和下臂绝不能同时导通，否则等于电源直接短路——死区就是为此准备的。这一部分本课程暂时不涉及，**了解即可**。

## 5 PWM 简介：为什么数字引脚能输出模拟量

**PWM（Pulse Width Modulation，脉冲宽度调制）**：

> 在具有惯性的系统中，可以通过对一系列脉冲的宽度进行调制，来**等效地获得所需要的模拟参量**，常应用于电机控速等领域。

直观例子：数字口控制 LED 理论上只有「全亮」和「全灭」两种状态，但让 LED 不断点亮、熄灭，且**频率足够高**时，人眼（惯性系统）就看不到闪烁，而是看到一个**中等亮度**；调整点亮和熄灭的时间比例，就能得到不同的亮度级别。电机调速同理。

三个参数：

| 参数 | 公式 | 含义 |
| --- | --- | --- |
| **频率** | `f = 1 / Ts` | `Ts` 是一个高低电平变换周期的时间。频率越快，等效出来的模拟信号越平稳，但性能开销也越大 |
| **占空比** | `Duty = Ton / Ts` | `Ton` 是高电平时间。占空比越大，等效模拟电压越趋近高电平；越小越趋近低电平 |
| **分辨率** | `Reso = 占空比变化步距` | 占空比变化的精细程度，可以理解为「精度」 | 

## 6 PWM 参数计算：三个公式

PWM 的**一个周期始终对应计数器的一个溢出更新周期**，所以 PWM 的频率就等于计数器的更新频率：

```text
PWM 频率：   f_PWM = CK_PSC / (PSC + 1) / (ARR + 1)
PWM 占空比： Duty  = CCR / (ARR + 1)
PWM 分辨率： Reso  = 1 / (ARR + 1)
```

理解占空比这条的关键是「数到几才跳变」：

```text
CNT:  0  1  2 ... 29  30 ... 99  0  1 ...      （ARR = 99，一周期共 100 个数）
      └──── 有效电平 ────┘└─ 无效电平 ─┘
      0~29 共 30 个数      30~99
      CNT 加到 CCR(=30) 的那一瞬间就已经跳变，
      所以高电平时间是 30 个数，占空比 = 30 / 100 = 30%
```

CCR 的取值范围：**`0 ~ ARR + 1`**。

- `CCR = ARR + 1` 时占空比正好 **100%**；
- CCR 再大一些占空比始终是 100%，**没有意义**；
- 所以 **CCR 的变化范围取决于 ARR，ARR 越大，CCR 可取的范围越大，分辨率越高**。

算例（`CK_PSC = 72 MHz`）：要求 `f_PWM = 10 kHz`、分辨率 1%：

| 参数 | 取值 | 计算 |
| --- | --- | --- |
| `PSC` | `72 - 1` | 先分频到 1 MHz 计数节拍 |
| `ARR` | `100 - 1` | 100 个节拍一个周期 |
| `f_PWM` | `72 000 000 / (72 × 100) = 10 000 Hz = 10 kHz` | |
| `Reso` | `1 / 100 = 1%` | 占空比每次只能变 1% |
| `CCR` | 写 30 得到 30% 占空比 | `Duty = 30 / 100` |

> [!tip] 三个公式的调节分工
> **`PSC` + `ARR` 一起决定频率**（其中 `PSC` 决定计数节拍，`ARR` 决定一个周期有多少个节拍）；**`CCR` 单独决定占空比**；**`ARR` 还顺带决定分辨率**。所以调频率和调占空比是两条互不干扰的路，这也是 PWM 好用之处。

## 7 与 6-5 输入捕获的关系

- 输入捕获（IC）和输出比较（OC）**共用同一个 CCR 寄存器**，也**共用同一个引脚**。
- 因此**两者不能同时使用**：一个通道要么做输入捕获，要么做输出比较，配了这个就不能配那个。
- 后面 6-5 讲输入捕获时会看到，那时 CCR 的角色从「我们自己写的比较值」变成了「硬件抓下来的 CNT 快照」——**同一个寄存器，两种方向的数据流**。

## 易错点

- [ ] 把「有效电平」当成一个固定含义 → 它相对**极性**而言，默认极性下有效≈高、无效≈低。
- [ ] 记反 PWM 模式 1：**向上计数 `CNT < CCR` 是有效电平**，`CNT ≥ CCR` 才是无效电平（不是 `>` 和 `≤`）。
- [ ] 以为 PWM 模式 2 的比较关系不一样 → 关系完全一样，只是输出电平**反过来**。
- [ ] 用中央对齐等其他计数模式去套本集的 PWM 结论 → 本集只讲**向上计数**这一种搭配。
- [ ] 忘了 GPIO 要配成**复用推挽输出**（AF_PP）→ 引脚控制权还在输出数据寄存器手里，波形出不来。
- [ ] 想用 CCR 调频率 → CCR 只改**占空比**，改频率要动 `PSC` / `ARR`。
- [ ] 把 `CCR` 写成 `ARR + 2` 甚至更大 → 占空比恒为 100%，没有任何变化，还以为是代码坏了。
- [ ] 以为「匹配时置有效电平 / 置无效电平」两个模式能输出连续波形 → 它们是**一次性动作**，置完就不管事了。
- [ ] 高级定时器输出 PWM 时忘了 `TIM_CtrlPWMOutputs()` 使能主输出 → PWM 不能正常输出。
- [ ] 同一个通道既想输入捕获又想输出比较 → 共用 CCR 和引脚，**只能选一个**。
- [ ] 改完模式却忘了后面一级的极性选择 → 波形整体反相，白白排查半天。

2. PWM 模式 1 在**向上计数**和**向下计数**时，有效电平分别出现在什么区间？
3. 8 种输出模式里，哪几种**完全不管** CNT 与 CCR 的大小关系？
4. 想输出一个**占空比恒为 50%** 的方波，用哪种模式？它的输出频率和更新频率是什么关系？
5. 已知 `CK_PSC = 72 MHz`，要得到 `f_PWM = 10 kHz`、分辨率 1%：`PSC`、`ARR` 各写多少？想让占空比为 30%，`CCR` 写多少？

> [!success]- 参考答案
> 1. `CNT` 由**硬件计数器自己自增**，`CCR` 是**我们（软件）写进去的比较值**。比较结果送给**输出模式控制器**，由它决定参考信号 `OCxREF` 的高低，`OCxREF` 再经**极性选择（CCER）**和**输出使能**送到 `OCx` 引脚。
> 2. 向上计数：`CNT < CCR` 为有效电平，`CNT ≥ CCR` 为无效电平；向下计数：`CNT > CCR` 为无效电平，`CNT ≤ CCR` 为有效电平。（注意上下两个方向的判断符号是**反过来**的。）
> 3. **冻结**、**强制为无效电平**、**强制为有效电平** 这三种：冻结保持原状态，强制模式直接把 `OCxREF` 钉死在某个电平，CNT 和 CCR 都失效。
> 4. 用**匹配时电平翻转**模式。每匹配一次翻转一次，一个完整周期需要两次匹配，所以**输出频率 = 更新频率 / 2**，占空比天然恒为 50%。
> 5. `PSC = 72 - 1`（分频到 1 MHz），`ARR = 100 - 1`（100 个节拍 ⇒ 10 kHz、分辨率 1%）；`CCR = 30` ⇒ 占空比 `30 / 100 = 30%`。
