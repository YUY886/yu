# 08 DMA（章索引）

> [!info] 这一章在讲什么
> 第 6 章讲的是「让硬件替 CPU 数数」，第 7 章讲的是「让硬件替 CPU 采集」，第 8 章讲的是**「让硬件替 CPU 搬数据」**——这就是 DMA。

## 知识地图

一条主线，两个分支：

```text
                        ┌─ 8-1 原理：三大要素（外设地址 / 存储器地址 / 传输计数器）
  DMA1（7 个通道，AHB） ─┤           配置项（方向、自增、宽度、模式、优先级、中断）
                        │           触发方式（硬件请求 / 软件 M2M）、仲裁器
                        │
                        └─ 8-2 应用 ├─ 实验一 数据转运：SRAM → SRAM（M2M · 正常模式 · 8 位）
                                    └─ 实验二 AD 多通道：ADC1->DR → AD_Value[]（循环 · 16 位）
```

- **8-1 是地基**：DMA 的三大要素和配置项就那么几个，后面所有外设用 DMA 都是照这个骨架填参数。
- **8-2 是用法**：两个实验各代表一类场景——"没有外设、纯内存搬运"（M2M + 正常模式）和"外设连续产生数据"（硬件触发 + 循环模式）。
- **第 9 章串口会再用一次**：`USART1_TX` 走 `DMA1_Channel4`、`USART1_RX` 走 `DMA1_Channel5`，本章的请求映射表在那里直接用得上。

## 本章速查

| 项目 | 结论 |
| --- | --- |
| DMA 资源（F103C8T6） | **只有 DMA1，7 个通道**（课件 Slide 100）；没有 DMA2 |
| 三大要素 | 外设地址 `DMA_CPARx` / 存储器地址 `DMA_CMARx` / 传输计数器 `DMA_CNDTRx`（≤ 65535） |
| 常查的请求映射 | ADC1 → 通道 1；SPI1_TX → 通道 3；USART1_TX → 通道 4；USART1_RX → 通道 5 |
| 同一通道多个请求 | 进通道前是**逻辑或**，同一时刻只能使能一个 |
| 外设侧的额外开关 | 必须单独开外设自己的 DMA 请求位（`ADC_DMACmd()`、`USART_DMACmd()`） |
| 方向 | `DMA_DIR_PeripheralSRC`（外设 → 存储器）/ `DMA_DIR_PeripheralDST`（存储器 → 外设） |
| 地址自增 | 地址固定的一侧不自增（如 `ADC1->DR`）；数组那一侧自增，**步长 = 数据宽度（1 / 2 / 4）** |
| 数据宽度 | `Byte`（8）/ `HalfWord`（16）/ `Word`（32）；`DMA_BufferSize` 的单位是**数据个数** |
| 模式 | `DMA_Mode_Normal`（搬完就停）/ `DMA_Mode_Circular`（自动重装计数器与地址） |
| 触发方式 | 硬件请求（外设触发）/ 软件触发（`DMA_M2M_Enable`，EN 置 1 立刻开搬） |
| M2M 的限制 | **不能与循环模式同时使用**（参考手册 §13.3.3 明确） |
| 计数器 | 正常模式减到 0 后通道不再响应请求；要重装必须先关闭通道 |
| 优先级 | 软件 4 级（VeryHigh / High / Medium / Low）+ 硬件按通道号（编号小者优先） |
| 中断与标志 | 半传输 HT、传输完成 TC、传输错误 TE，各有独立使能位；`GL` 是总标志 |
| 8-2 引脚 | `PA0` 电位器、`PA1` 光敏、`PA2` 热敏、`PA3` 反射式红外（`ADC_Channel_0`~`_3`） |
| 8-2 使能顺序 | `DMA_Cmd` → `ADC_DMACmd` → `ADC_Cmd` → 校准 → `ADC_SoftwareStartConvCmd` |

## 本章统一易错点

- [ ] DMA 挂 **AHB**，时钟用 `RCC_AHBPeriphClockCmd(RCC_AHBPeriph_DMA1, ENABLE)`，不是 APB1 / APB2。
- [ ] F103C8T6 上没有 DMA2，只有 DMA1 的 7 个通道；写 DMA2 不报错但毫无反应。
- [ ] 只配 DMA、不开外设的 DMA 请求位（`ADC_DMACmd`）→ 一次都不搬。
- [ ] `DMA_BufferSize` 是**数据个数**不是字节数。
- [ ] 地址固定的一侧忘了关自增 → 读到/写到不存在的地址，直接传输错误。
- [ ] 想「存储器到存储器 + 循环模式」→ 参考手册明确不允许两者同时用。
- [ ] 正常模式搬完一次后忘了重装计数器 → 通道不再响应请求。
- [ ] 轮询 `DMA_FLAG_TCx` 后忘了清标志 → 下次判断直接通过，像"没搬就返回"。
- [ ] 多通道 AD 用 DMA 时，`DMA_BufferSize` 与 `ADC_NbrOfChannel` 必须一致，宽度必须和 ADC 结果宽度（16 位）匹配。
