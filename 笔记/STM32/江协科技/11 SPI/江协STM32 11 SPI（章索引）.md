# 11 SPI（章索引）

> [!info] 这一章在讲什么
> 第 10 章 I2C 是**半双工 + 地址寻址 + 开漏**；第 11 章 SPI 换了一套完全不同的思路：**全双工 + 片选寻址 + 推挽**，四根线，一主多从，靠一个 8 位移位寄存器「一进一出」地交换数据。
>
> 前两集（11-1、11-2）是**纯理论集**：11-1 讲协议本身，11-2 讲挂在协议上的那颗 Flash 芯片。后三集才是**动手集**：11-3 用 GPIO 把协议一位一位翻出来（软件 SPI），11-4 讲 STM32 自带的 SPI 外设，11-5 用外设重写一遍（硬件 SPI）。
>
> 上级：[[江协STM32 课程总索引]]

## 本章速查

### SPI 四种模式（`CPOL` × `CPHA`）

| 模式 | `CPOL` | 空闲时 SCK | `CPHA` | 库函数取值 |
| --- | --- | --- | --- | --- |
| 模式 0 | 0 | 低电平 | 0 | `SPI_CPOL_Low` + `SPI_CPHA_1Edge` |
| 模式 1 | 0 | 低电平 | 1 | `SPI_CPOL_Low` + `SPI_CPHA_2Edge` |
| 模式 2 | 1 | 高电平 | 0 | `SPI_CPOL_High` + `SPI_CPHA_1Edge` |
| 模式 3 | 1 | 高电平 | 1 | `SPI_CPOL_High` + `SPI_CPHA_2Edge` |

**本课程 W25Q64 用模式 0**（`11-1\MySPI.c` 第 100 行注释「使用 SPI 模式 0」）。

### 第 11 章引脚（SPI1 全部落在 PA4~PA7）

| 信号 | STM32 引脚 | 引脚定义表复用功能 | 软件 SPI 的 GPIO 模式 | 硬件 SPI 的 GPIO 模式 |
| --- | --- | --- | --- | --- |
| SS（片选） | **PA4** | `SPI1_NSS` | `GPIO_Mode_Out_PP` | `GPIO_Mode_Out_PP`（**仍由软件模拟**） |
| SCK（时钟） | **PA5** | `SPI1_SCK` | `GPIO_Mode_Out_PP` | `GPIO_Mode_AF_PP` |
| MISO | **PA6** | `SPI1_MISO` | `GPIO_Mode_IPU` | `GPIO_Mode_IPU` |
| MOSI | **PA7** | `SPI1_MOSI` | `GPIO_Mode_Out_PP` | `GPIO_Mode_AF_PP` |

F103C8T6 有 **SPI1、SPI2** 两个硬件 SPI 资源（课件 Slide 161）。SPI2 的一组引脚是 **PB13 / PB14 / PB15 + PB12 片选**（`引脚定义_xlsx原文.txt` 第 27~30 行：`SPI2_SCK` / `SPI2_MISO` / `SPI2_MOSI` / `SPI2_NSS`）。**本课程只用到 SPI1。**

### W25Q64 存储结构

| 层级 | 大小 | 换算 |
| --- | --- | --- |
| 页（Page） | 256 字节 | 写入的最小单位（一次连续写不超过一页） |
| 扇区（Sector） | 4 KB | **擦除的最小单位** |
| 块（Block） | 64 KB | — |
| 整片 | 8 MB（64 Mbit） | 24 位地址，范围 `0x000000`~`0x7FFFFF` |

### W25Q64 常用指令

| 指令 | 值 | 后面跟几个字节 |
| --- | --- | --- |
| 写使能 | `0x06` | 0 个 |
| 读状态寄存器 1 | `0x05` | 0 个地址字节，之后发 `0xFF` 反复读 |
| 页编程 | `0x02` | 3 个地址字节 + 数据字节 |
| 扇区擦除（4 KB） | `0x20` | 3 个地址字节 |
| 读数据 | `0x03` | 3 个地址字节 + 发 `0xFF` 收数据 |
| 读 JEDEC ID | `0x9F` | 发 3 次 `0xFF`，收 3 个字节 |

### 全章统一易错点

- [ ] SPI 的每一次传输都是**交换**，不存在「只发」或「只收」。
- [ ] **SS 必须先拉低**才开始时序；每个从机一根 SS，不能共用。
- [ ] 主从双方的 **CPOL / CPHA 必须一致**，否则读回来的位整体错位。
- [ ] SPI 用**推挽**输出，不要照搬 I2C 的开漏配置。
- [ ] W25Q64 **写之前必须先擦除**，且擦除最小单位是**扇区（4 KB）**而不是字节。
- [ ] W25Q64 每个数据位**只能 1→0**，不能 0→1。
- [ ] W25Q64 **写入不能跨页**，越界数据会绕回页首覆盖，且**不报错**。
- [ ] W25Q64 写入/擦除前要**写使能**，写/擦完成后要**等 BUSY 清零**。
- [ ] 硬件 SPI 也只是接管了 SCK / MOSI / MISO，**SS 仍然要用 GPIO 手动控制**。
- [ ] 官方工程目录编号**不等于**视频集号（`11-1` 目录对应 11-3 视频，`11-2` 目录对应 11-5 视频）。
