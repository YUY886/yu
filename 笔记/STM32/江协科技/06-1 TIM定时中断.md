# 06-1 TIM定时中断

> 本笔记对应教程目录中的“6-1 TIM定时中断”。内容整理为复习用知识点，后续可再根据视频逐段补充。

## 1. 定时器做什么

定时器的核心用途是：让程序按照固定的时间间隔自动执行任务。

典型流程：

```text
定时器时钟 → 预分频 → CNT计数 → 达到ARR → 更新事件 → 更新中断
```

定时中断适合处理周期性任务，例如：

- LED闪烁
- 按键扫描
- 软件定时
- 周期采样
- 电机控制中的固定周期任务

## 2. 时基单元

### 2.1 预分频器 PSC

预分频器把定时器输入时钟降低为计数器时钟：

```text
CK_CNT = CK_TIM / (PSC + 1)
```

`PSC` 写入的是“分频系数减 1”。例如想进行 7200 分频，应设置：

```c
PSC = 7200 - 1;
```

### 2.2 计数器 CNT

向上计数时，`CNT` 从 `0` 开始递增。计数器达到自动重装载值后产生更新事件，并重新开始计数。

### 2.3 自动重装载寄存器 ARR

`ARR` 决定一次更新事件需要多少个计数节拍。由于计数从 `0` 开始，因此计数次数为：

```text
ARR + 1
```

## 3. 定时周期计算

更新事件频率：

```text
f_update = CK_TIM / ((PSC + 1) × (ARR + 1))
```

更新周期：

```text
T_update = ((PSC + 1) × (ARR + 1)) / CK_TIM
```

例如定时器时钟为 `72 MHz`，设置：

```c
PSC = 7200 - 1;   // 计数频率为 10 kHz
ARR = 10000 - 1;  // 10000 个计数节拍
```

则更新周期为 `1 s`。

> 计算前必须确认具体 TIM 的输入时钟。STM32F103 中，APB 预分频会影响定时器时钟；不能只看 APB 总线名称判断频率。

## 4. 更新事件和更新中断

两者不是同一个概念：

- **更新事件**：计数器溢出等情况产生的硬件事件。
- **更新中断**：允许更新事件向 CPU 发出中断请求。

只有同时满足以下条件，才会进入中断服务函数：

1. 定时器产生更新事件；
2. 定时器更新中断已使能；
3. NVIC 对应的 TIM 中断通道已使能；
4. CPU 全局中断没有被屏蔽。

## 5. 标准外设库配置流程

```text
开启 TIM 时钟
  ↓
配置 PSC、ARR、计数模式
  ↓
清除更新标志
  ↓
开启 TIM 更新中断
  ↓
配置 NVIC
  ↓
启动 TIM
```

以 `TIM2` 为例，关键代码结构如下：

```c
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
TIM_TimeBaseInitStructure.TIM_Period = 10000 - 1;   // ARR
TIM_TimeBaseInitStructure.TIM_Prescaler = 7200 - 1; // PSC
TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

TIM_ClearFlag(TIM2, TIM_FLAG_Update);
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);

// 这里还需要配置 TIM2_IRQn 对应的 NVIC
TIM_Cmd(TIM2, ENABLE);
```

## 6. 中断服务函数

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        // 执行周期性任务

        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

中断函数应尽量短小。更合适的做法是在中断中设置标志位，再由主循环完成较复杂的任务。

## 7. 易错点

- `PSC` 和 `ARR` 都要注意“实际值减 1”。
- 初始化时基后，建议在开启中断前清除一次更新标志。
- 仅调用 `TIM_ITConfig()` 不够，还要配置 NVIC。
- 中断服务函数必须清除更新中断标志。
- 定时器时钟取决于时钟树和 APB 分频，不能想当然地写成系统主频。
- 不要在中断中执行长时间延时、复杂循环或大量阻塞式串口输出。

## 8. 一句话记忆

```text
PSC 决定“多久数一次”，ARR 决定“数多少次触发一次更新”。
```
