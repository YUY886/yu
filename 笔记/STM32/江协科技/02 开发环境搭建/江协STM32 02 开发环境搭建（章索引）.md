### 常用快捷键（Keil µVision5）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `N` | 新建文件 |
| `Ctrl` + `S` | 保存当前文件 |
| `Ctrl` + `Shift` + `S` | 全部保存 |
| `F7` | 编译当前工程（Build） |
| `Ctrl` + `F5` | 开始/停止调试会话 |
| `F5` | 全速运行（Run） |
| `F9` | 在光标行设置/取消断点 |
| `F10` | 单步跳过（Step Over） |
| `F11` | 单步进入（Step Into） |
| `F8` | 下载程序（Download，详见分集笔记「待核对」） |
| `Ctrl` + `/` | 注释/取消注释选中行 |
| `Ctrl` + `F` | 当前文件内查找 |

### 工程目录结构速查

```text
工程根目录/
├── Start/        启动文件 + 内核文件 + 系统时钟文件（ST 提供，不改）
│   ├── startup_stm32f10x_md.s
│   ├── stm32f10x.h
│   ├── system_stm32f10x.c / .h
│   └── core_cm3.c / .h
├── Library/      标准外设库（ST 提供，不改，**一层平铺，无 inc/src 子目录**）
│   ├── misc.c / misc.h
│   └── stm32f10x_gpio.c / .h、stm32f10x_rcc.c / .h …（`.c` 与 `.h` 同名放一起）
├── User/         用户自己的程序
│   ├── main.c
│   ├── stm32f10x_conf.h    ← 外设头文件"开关文件"（官方模板默认全部放开）
│   └── stm32f10x_it.c / .h ← 中断服务函数
├── Objects/      Keil 编译输出（.o / .axf / .hex）
└── Listings/     .map / .lst 列表文件
```

> [!important] 以官方工程为准的两点
> 依据 `程序源码\STM32Project-有注释版\2-1 STM32工程模板\` 的实际磁盘结构：**① `Library` 是平铺的一层，`IncludePath` 也只写 `.\Start;.\User;.\Library`；② Keil 分组只有 `Start`、`Library`、`User` 三个**。`System`（Delay）、`Hardware` 是后续章节才加的目录。

### Options for Target 关键设置（以官方工程文件为准）

| 选项卡 | 设置项 | 官方 2-1 模板的实际值 |
| --- | --- | --- |
| C/C++ | Define | `USE_STDPERIPH_DRIVER`（**只有这一个**） |
| C/C++ | Include Paths | `.\Start;.\User;.\Library` |
| Output | 输出目录 Objects | `.\Objects\`（`Create HEX File` 未勾） |
| Listing | 输出目录 Listings | `.\Listings\` |
| Debug → Settings → Flash Download | Programming Algorithm | `STM32F10x_128.FLM`（中容量算法，覆盖 64 KB） |
| Debug → Settings → Flash Download | Reset and Run | 课件第 16 页明确要求勾选 |
| Target | Xtal (MHz) | 官方工程文件无法确定（`<Cpu>` 里是 `CLOCK(12000000)`，与 `Xtal` 输入框不是同一个值） |
| Debug | 调试器下拉框 | 官方工程文件**不保存**该项 |

### 两个下载工具的分工

> [!warning] 这两个工具**不是**课件里的安装项
> 课件第 14 页「软件安装」只列 5 项：Keil5 MDK、器件支持包、软件注册、STLINK 驱动、USB 转串口驱动。**下面这张对比表来自第三方整理资料，不是课程官方依据**，引用时请注意。

|           | FlyMcu                     | STLINK Utility                |
| --------- | -------------------------- | ----------------------------- |
| 走什么线      | USB 转串口 → USART1           | ST-Link 调试器 → SWD             |
| 是否需要改跳线帽  | 需要（BOOT0 = 1 进 BootLoader） | 不需要                           |
| 能下载的文件    | 只能 `.hex`                  | `.hex` 和 `.bin`               |
| 能否单独改选项字节 | 不能（只能随下载一起写）               | 能，可单独 Apply                   |
| 课程里的定位    | 没有 ST-Link 时的替代方案          | ST-Link 的配套工具，日常主力是 Keil 内置下载 |
| 官方资料中的记载  | 课件/源码/接线图中均**未见**          | 课件/源码/接线图中均**未见**             |
