# 江协51 09-1 LED点阵屏显示图形

> [!abstract] 一句话核心
> 74HC595 发送列数据，P0 选通列，快速扫描即可显示一帧图形。

## 原理讲解

SER=P3.4 输入位数据，SCK=P3.6 移位，RCK=P3.5 锁存输出。

每列发送 8 位后，P0 输出 `~(0x80>>Column)` 选通该列，保持 1 ms 再关闭消影。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| SER | P3.4 |
| RCK | P3.5 |
| SCK | P3.6 |
| 列选通 | P0 |
| 单列保持 | 1 ms |

## 完整代码

### `Delay.c`

```c
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

### `main.c`

```c
#include <REGX52.H>
#include "Delay.h"

sbit RCK=P3^5;		//RCLK
sbit SCK=P3^6;		//SRCLK
sbit SER=P3^4;		//SER

#define MATRIX_LED_PORT		P0

/**
  * @brief  74HC595写入一个字节
  * @param  Byte 要写入的字节
  * @retval 无
  */
void _74HC595_WriteByte(unsigned char Byte)
{
	unsigned char i;
	for(i=0;i<8;i++)
	{
		SER=Byte&(0x80>>i);
		SCK=1;
		SCK=0;
	}
	RCK=1;
	RCK=0;
}

/**
  * @brief  LED点阵屏显示一列数据
  * @param  Column 要选择的列，范围：0~7，0在最左边
  * @param  Data 选择列显示的数据，高位在上，1为亮，0为灭
  * @retval 无
  */
void MatrixLED_ShowColumn(unsigned char Column,Data)
{
	_74HC595_WriteByte(Data);
	MATRIX_LED_PORT=~(0x80>>Column);
	Delay(1);
	MATRIX_LED_PORT=0xFF;
}

void main()
{
	SCK=0;
	RCK=0;
	while(1)
	{
		MatrixLED_ShowColumn(0,0x3C);
		MatrixLED_ShowColumn(1,0x42);
		MatrixLED_ShowColumn(2,0xA9);
		MatrixLED_ShowColumn(3,0x85);
		MatrixLED_ShowColumn(4,0x85);
		MatrixLED_ShowColumn(5,0xA9);
		MatrixLED_ShowColumn(6,0x42);
		MatrixLED_ShowColumn(7,0x3C);
	}
}
```

## 易错点

- 注意 595 先移位后锁存。
- 列数据 1 表示 LED 亮，P0 列选是低电平有效。
