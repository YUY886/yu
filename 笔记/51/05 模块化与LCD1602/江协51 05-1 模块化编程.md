# 江协51 05-1 模块化编程

> [!abstract] 一句话核心
> 把延时和数码管分别放进独立模块，主程序只关心业务流程。

## 原理讲解

Delay.c 实现延时，Delay.h 声明函数；Nixie.c 实现显示，Nixie.h 提供接口。

头文件使用 `#ifndef/#define/#endif` 防止重复包含，主程序只 `#include` 对应头文件。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| 延时模块 | Delay.c/.h |
| 数码管模块 | Nixie.c/.h |
| 位选 | P2.4/P2.3/P2.2 |
| 段码 | P0 |

## 完整代码

### `Delay.c`

```c
//延时子函数
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

### `Delay.h`

```c
#ifndef __DELAY_H__
#define __DELAY_H__

void Delay(unsigned int xms);

#endif
```

### `main.c`

```c
#include <REGX52.H>
#include "Delay.h"	//包含Delay头文件
#include "Nixie.h"	//包含数码管头文件

void main()
{
	while(1)
	{
		Nixie(1,1);	//在数码管的第1位置显示1
		Nixie(2,2);	//在数码管的第2位置显示2
		Nixie(3,3);	//在数码管的第3位置显示3
		Nixie(4,4);	//在数码管的第4位置显示4
		Nixie(5,5);	//在数码管的第5位置显示5
		Nixie(6,6);	//在数码管的第6位置显示6
	}
}
```

### `Nixie.c`

```c
#include <REGX52.H>
#include "Delay.h"	//包含Delay头文件

//数码管段码表
unsigned char NixieTable[]={0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F};

//数码管显示子函数
void Nixie(unsigned char Location,Number)
{
	switch(Location)		//位码输出
	{
		case 1:P2_4=1;P2_3=1;P2_2=1;break;
		case 2:P2_4=1;P2_3=1;P2_2=0;break;
		case 3:P2_4=1;P2_3=0;P2_2=1;break;
		case 4:P2_4=1;P2_3=0;P2_2=0;break;
		case 5:P2_4=0;P2_3=1;P2_2=1;break;
		case 6:P2_4=0;P2_3=1;P2_2=0;break;
		case 7:P2_4=0;P2_3=0;P2_2=1;break;
		case 8:P2_4=0;P2_3=0;P2_2=0;break;
	}
	P0=NixieTable[Number];	//段码输出
	Delay(1);				//显示一段时间
	P0=0x00;				//段码清0，消影
}
```

### `Nixie.h`

```c
#ifndef __NIXIE_H__
#define __NIXIE_H__

void Nixie(unsigned char Location,Number);

#endif
```

## 易错点

- .h 里写声明，.c 里写定义。
- 忘记包含头文件会在编译或链接阶段报错。
