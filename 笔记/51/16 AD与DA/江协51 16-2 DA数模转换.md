# 江协51 16-2 DA数模转换

> [!abstract] 一句话核心
> 用 100 us PWM 输出到 DA 引脚，经板级滤波得到渐变模拟电压。

## 原理讲解

Timer0 每 100 us 中断一次，`Counter` 与 `Compare` 比较，在 P2.1 输出 PWM。

主循环让 Compare 从 0 到 100 再回落，输出近似三角波。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| DA | P2.1 |
| 定时器 | Timer0 |
| 中断周期 | 100 us |
| PWM 级数 | 100 |
| 输出变化 | 每 10 ms 一级 |

## 完整代码

### `Delay.c`

```c
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

### `main.c`

```c
#include <REGX52.H>
#include "Delay.h"
#include "Timer0.h"

sbit DA=P2^1;

unsigned char Counter,Compare;	//计数值和比较值，用于输出PWM
unsigned char i;

void main()
{
	Timer0_Init();
	while(1)
	{
		for(i=0;i<100;i++)
		{
			Compare=i;			//设置比较值，改变PWM占空比
			Delay(10);
		}
		for(i=100;i>0;i--)
		{
			Compare=i;			//设置比较值，改变PWM占空比
			Delay(10);
		}
	}
}

void Timer0_Routine() interrupt 1
{
	TL0 = 0x9C;		//设置定时初值
	TH0 = 0xFF;		//设置定时初值
	Counter++;
	Counter%=100;	//计数值变化范围限制在0~99
	if(Counter<Compare)	//计数值小于比较值
	{
		DA=1;		//输出1
	}
	else				//计数值大于比较值
	{
		DA=0;		//输出0
	}
}
```

/**

void Timer0_Init(void)
{
	TMOD &= 0xF0;		//设置定时器模式
	TMOD |= 0x01;		//设置定时器模式
	TL0 = 0x9C;		//设置定时初值
	TH0 = 0xFF;		//设置定时初值
	TF0 = 0;		//清除TF0标志

	EA=1;
	PT0=0;

## 易错点

- DA 输出是 PWM 经滤波后的近似值，不是高精度 DAC。
- 滤波电路会限制响应速度。
