# 江协51 02-2 LED闪烁

> [!abstract] 一句话核心
> 在点亮和熄灭之间插入软件延时，人眼才能看到 LED 闪烁。

## 原理讲解

每次给 P2.0 输出相反电平后调用约 500 ms 延时，闪烁周期约 1 s。

延时函数由多层循环构成，是针对 12 MHz 晶振校准的软件延时。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| LED1 | P2.0 |
| 半周期 | 约 500 ms |
| 延时基准 | 12 MHz |

## 完整代码

### `main.c`

```c
#include <REGX52.H>
#include <INTRINS.H>

void Delay500ms()		//@12.000MHz
{
	unsigned char i, j, k;

	_nop_();
	i = 4;
	j = 205;
	k = 187;
	do
	{
		do
		{
			while (--k);
		} while (--j);
	} while (--i);
}


void main()
{
	while(1)
	{
		P2=0xFE;	//1111 1110
		Delay500ms();
		P2=0xFF;	//1111 1111
		Delay500ms();
	}
}
```

## 易错点

- 延时值与晶振频率绑定，换晶振后现象会变慢或变快。
- 不要把延时的形参类型写成 unsigned char。
