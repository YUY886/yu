# 江协51 02-1 点亮一个LED

> [!abstract] 一句话核心
> LED 是低电平点亮，直接给 P2.0 输出 0 就能建立最小型控制模型。

## 原理讲解

开发板 LED 阳极经限流电阻接电源，IO 引脚拉低形成电流通路，所以 P2.0=0 点亮。

`P2=0xFE` 的二进制是 `1111 1110`，最低位 0 对应 LED1，其余位保持熄灭。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| LED1 | P2.0 |
| 点亮电平 | 低电平 0 |
| 控制字节 | P2=0xFE |

## 完整代码

### `main.c`

```c
#include <REGX52.H>

void main()
{
	P2=0xFE;	//1111 1110
	while(1)
	{
		
	}
}
```

## 易错点

- 不要把位编号和引脚编号搞反。
- 主循环不能结束，可用 `while(1)` 保持状态。
