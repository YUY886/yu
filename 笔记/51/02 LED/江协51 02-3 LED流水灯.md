# 江协51 02-3 LED流水灯

> [!abstract] 一句话核心
> 逐个写出 LED 状态码，可直观建立流水灯与二进制位的关系。

## 原理讲解

从 `0xFE`、`0xFD`、`0xFB` 依次变化，0 的位置就是当前点亮的 LED。

每个状态后延时 500 ms，让肉眼稳定观察到移动效果。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| LED 端口 | P2 |
| 状态数量 | 8 个 |
| 单步延时 | 约 500 ms |

## 完整代码

### `main.c`

```c
#include <REGX52.H>
#include <INTRINS.H>

void Delay500ms()		//@12.000MHz
{
	unsigned char i, j, k;

	_nop_();
	i = 4;
	j = 205;
	k = 187;
	do
	{
		do
		{
			while (--k);
		} while (--j);
	} while (--i);
}


void main()
{
	while(1)
	{
		P2=0xFE;//1111 1110
		Delay500ms();
		P2=0xFD;//1111 1101
		Delay500ms();
		P2=0xFB;//1111 1011
		Delay500ms();
		P2=0xF7;//1111 0111
		Delay500ms();
		P2=0xEF;//1110 1111
		Delay500ms();
		P2=0xDF;//1101 1111
		Delay500ms();
		P2=0xBF;//1011 1111
		Delay500ms();
		P2=0x7F;//0111 1111
		Delay500ms();
	}
}
```

## 易错点

- 注意低电平点亮，状态字节不能直接等于移位后的 1。
- 每个状态后都要有延时。
