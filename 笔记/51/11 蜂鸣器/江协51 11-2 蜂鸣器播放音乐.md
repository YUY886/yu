# 江协51 11-2 蜂鸣器播放音乐

> [!abstract] 一句话核心
> 用定时器中断生成音符频率，用乐谱数组控制音调和时值。

## 原理讲解

`FreqTable[]` 存放定时器重装值，中断里按索引载入并翻转蜂鸣器。

`Music[]` 交替存音符索引和时值，主循环按 `SPEED` 播放，遇到 0xFF 停止。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| 蜂鸣器 | P1.5 |
| 定时器 | Timer0 中断 |
| 四分音符 | 500 ms |
| 停止符 | 0xFF |

## 完整代码

### `Delay.c`

```c
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

### `Timer0.c`

```c
#include <REGX52.H>

/**
  * @brief  定时器0初始化，1毫秒@12.000MHz
  * @param  无
  * @retval 无
  */
void Timer0Init(void)
{
	TMOD &= 0xF0;		//设置定时器模式
	TMOD |= 0x01;		//设置定时器模式
	TL0 = 0x18;		//设置定时初值
	TH0 = 0xFC;		//设置定时初值
	TF0 = 0;		//清除TF0标志
	TR0 = 1;		//定时器0开始计时
	ET0=1;
	EA=1;
	PT0=0;
}
```

## 易错点

- 休止符索引 0 必须跳过翻转。
- 音符之间要短停顿，否则连续音会糊成一片。
