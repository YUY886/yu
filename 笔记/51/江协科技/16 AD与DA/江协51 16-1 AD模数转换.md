# 16-1 AD 模数转换

> [!abstract] 这一集只解决一个问题
> **怎么把模拟量（电压）转成数字量，让单片机读取？**
>
> 答：用 **ADC（模数转换器）**。本课用 **XPT2046** 芯片（4 线 SPI 接口），通过发命令选通道、读 16 位得到 AD 值，实现电压采集。
>
> 下一集 [[江协51 16-2 DA数模转换]] ｜ 章索引 [[江协51 16 AD与DA（章索引）]]

## 1 为什么需要 AD

真实世界的物理量（温度、光照、电位器位置等）大多是**连续变化的模拟量**（电压），而单片机只懂**离散的数字量**（0/1）。AD 就是把模拟电压转成数字：

```text
模拟量（0~5V）──► ADC ──► 数字量（如 12 位：0~4095）
```

- 12 位 ADC：把 0~5V 分成 4096 级，每级约 1.22mV。
- 数字量越大，代表电压越高。

## 2 XPT2046 引脚

XPT2046 是 4 线 SPI 接口的触摸/ADC 芯片：

```c
sbit XPY2046_DIN=P3^4;   // 数据输入（发命令）
sbit XPY2046_CS=P3^5;    // 片选
sbit XPY2046_DCLK=P3^6;  // 时钟
sbit XPY2046_DOUT=P3^7;  // 数据输出（读结果）
```

| 引脚 | 作用 |
| --- | --- |
| DIN | 串行发命令字（选通道） |
| CS | 片选（低有效） |
| DCLK | 时钟 |
| DOUT | 串行读回 AD 结果 |

## 3 读 AD 值

```c
unsigned int XPT2046_ReadAD(unsigned char Command)
{
	unsigned char i;
	unsigned int Data=0;
	XPY2046_DCLK=0;
	XPY2046_CS=0;               // 选中
	for(i=0;i<8;i++)            // 发 8 位命令
	{
		XPY2046_DIN=Command&(0x80>>i);   // 高位先发
		XPY2046_DCLK=1;
		XPY2046_DCLK=0;
	}
	for(i=0;i<16;i++)           // 读 16 位结果
	{
		XPY2046_DCLK=1;
		XPY2046_DCLK=0;
		if(XPY2046_DOUT){Data|=(0x8000>>i);}  // 高位先收
	}
	XPY2046_CS=1;               // 释放
	return Data>>8;             // 取高 8 位（或完整 12 位）
}
```

- 先发 8 位命令（选择采样通道），再读 16 位结果。
- `return Data>>8`：这里取高 8 位（0~255），也可返回完整 12 位（0~4095）。

## 4 完整代码（16-1 读三个通道）

```c
#include <REGX52.H>
#include "Delay.h"
#include "LCD1602.h"
#include "XPT2046.h"

unsigned int ADValue;

void main(void)
{
	LCD_Init();
	LCD_ShowString(1,1,"ADJ  NTC  GR");
	while(1)
	{
		ADValue=XPT2046_ReadAD(XPT2046_XP);		//读AIN0，可调电阻
		LCD_ShowNum(2,1,ADValue,3);
		ADValue=XPT2046_ReadAD(XPT2046_YP);		//读AIN1，热敏电阻
		LCD_ShowNum(2,6,ADValue,3);
		ADValue=XPT2046_ReadAD(XPT2046_VBAT);	//读AIN2，光敏电阻
		LCD_ShowNum(2,11,ADValue,3);
		Delay(100);
	}
}
```

- 三个通道：可调电阻（XP）、热敏电阻（YP）、光敏电阻（VBAT）。
- `XPT2046_XP` 等是命令字宏，选择不同模拟输入通道。

## 5 易错点

- [ ] XPT2046 引脚搞错 → DIN/CS/DCLK/DOUT 对应 P3^4~P3^7。
- [ ] 数据方向搞反 → 命令高位先发（0x80>>i）。
- [ ] AD 值位数 → `Data>>8` 是 8 位（0~255），完整是 12 位（0~4095）。
- [ ] 通道命令字选错 → 不同宏对应不同通道。

## 6 自测

1. AD 转换的作用是什么？
2. 12 位 ADC 的分辨率是多少（0~5V）？
3. XPT2046 读 AD 的流程是什么？

> [!success]- 参考答案
> 1. 把连续变化的模拟量（电压）转成单片机能处理的离散数字量。
> 2. 把 0~5V 分成 4096 级，每级约 5/4096 ≈ 1.22mV。
> 3. 拉低 CS 选中 → 发 8 位命令（选通道）→ 读 16 位结果 → 释放 CS。
