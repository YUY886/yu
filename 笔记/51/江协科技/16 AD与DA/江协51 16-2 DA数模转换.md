# 16-2 DA 数模转换

> [!abstract] 这一集只解决一个问题
> **怎么把数字量转成模拟量（输出电压）？**
>
> 答：用 **PWM 实现 DA**——复用第 15 章的软件 PWM，通过改变占空比，在输出脚得到不同"平均电压"，实现数模转换。
>
> 上一集 [[江协51 16-1 AD模数转换]] ｜ 章索引 [[江协51 16 AD与DA（章索引）]]

## 1 DA 是什么

DA（数模转换）是 AD 的反过程：把数字量（如 0~255）转成模拟电压（0~5V）。

51 没有独立的 DAC 外设，但可以用 **PWM + 滤波**模拟 DA：

- PWM 的占空比决定了"平均电压"。
- 占空比 0% → 0V，占空比 100% → 5V，中间连续可调。
- 加个 RC 低通滤波，就能把 PWM 方波滤成平滑的直流电压。

## 2 PWM 做 DA

复用第 15 章的软件 PWM 骨架，只是把输出引脚换成 DA：

```c
sbit DA=P2^1;

unsigned char Counter,Compare;
unsigned char i;

void main()
{
	Timer0_Init();
	while(1)
	{
		for(i=0;i<100;i++)   // 占空比从 0 增到 99（电压渐升）
		{
			Compare=i;
			Delay(10);
		}
		for(i=100;i>0;i--)   // 占空比从 100 减到 1（电压渐降）
		{
			Compare=i;
			Delay(10);
		}
	}
}

void Timer0_Routine() interrupt 1
{
	TL0 = 0x9C;
	TH0 = 0xFF;
	Counter++;
	Counter%=100;
	if(Counter<Compare)
	{
		P2=1;    // 高电平
	}
	else
	{
		P2=0;    // 低电平
	}
}
```

- `Compare` 从 0 渐变到 99 再回来，占空比随之变化 → 输出电压渐变。
- 输出脚接 RC 滤波，就是连续变化的模拟电压。

## 3 与第 15 章的关系

DA 和直流电机调速用的是**同一套软件 PWM 骨架**：

| | 输出引脚 | 目的 |
| --- | --- | --- |
| 15 章直流电机 | P1_0 | 调速（等效电压 → 转速） |
| 16 章 DA | P2_1 | 数模转换（等效电压 → 模拟量） |

> [!tip] 同一个 PWM，两个用途
> PWM 的"占空比 → 平均电压"这个特性，既可以调速（第 15 章），也可以做 DA（本章）。理解了这一点，就串起了两章。

## 4 易错点

- [ ] DA 引脚搞错 → DA=P2^1。
- [ ] 计数器忘了 `%=100` → 占空比错乱。
- [ ] 没加 RC 滤波 → 输出是方波不是平滑直流。
- [ ] Compare 范围 → 0~100 之间。

## 5 自测

1. DA 和 AD 是什么关系？
2. 51 没有 DAC，怎么实现 DA？
3. PWM 做 DA 为什么通常要加 RC 滤波？

> [!success]- 参考答案
> 1. 互为逆过程：AD 把模拟量转数字量，DA 把数字量转模拟量。
> 2. 用 PWM 的占空比代表模拟量：占空比越大平均电压越高，配合滤波得到模拟电压。
> 3. PWM 输出是方波，加 RC 低通滤波才能滤成平滑的直流电压（真正的模拟量）。
