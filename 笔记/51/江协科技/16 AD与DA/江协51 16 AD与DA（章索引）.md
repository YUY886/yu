## 本章速查

### XPT2046 引脚

- `DIN=P3^4`、`CS=P3^5`、`DCLK=P3^6`、`DOUT=P3^7`。

### AD 读值

```c
unsigned int XPT2046_ReadAD(unsigned char Command)
{
	// 发 8 位命令字（选择通道）
	// 读 16 位数据
	// 返回 Data>>8（8 位）或完整 12 位
}
```

### DA（PWM 做 DA）

- 用第 15 章的软件 PWM，改占空比 → 输出不同"平均电压" → 实现 DA。
- `DA=P2^1`。

> [!tip] 记这一章最省力的办法
> AD 就记：**XPT2046 四线（DIN/CS/DCLK/DOUT）+ 发命令选通道 + 读 16 位**。DA 就记：**用 PWM 的占空比代表模拟量**（和第 15 章同骨架）。

## 全章统一易错点

- [ ] XPT2046 引脚搞错 → DIN/CS/DCLK/DOUT 对应 P3^4~P3^7。
- [ ] AD 值位数搞错 → 12 位范围 0~4095，8 位范围 0~255。
- [ ] DA 引脚搞错 → DA=P2^1。
- [ ] DA 的 PWM 周期/占空比混淆 → 占空比 = 模拟量比例。
