## 本章速查

### LCD1602 引脚

| 引脚 | 接 IO | 作用 |
| --- | --- | --- |
| RS | P2^6 | 寄存器选择（0=命令，1=数据） |
| RW | P2^5 | 读写（0=写，1=读） |
| E | P2^7 | 使能脉冲 |
| D0~D7 | P0 | 数据总线 |

### 常用函数

| 函数 | 作用 |
| --- | --- |
| `LCD_Init()` | 初始化 |
| `LCD_ShowChar(Line,Column,Char)` | 显示字符 |
| `LCD_ShowString(Line,Column,"str")` | 显示字符串 |
| `LCD_ShowNum(Line,Column,Num,Length)` | 显示十进制数 |
| `LCD_ShowHexNum(...)` | 显示十六进制 |
| `LCD_ShowBinNum(...)` | 显示二进制 |

> [!tip] 记这一章最省力的办法
> LCD1602 就记：**RS 选命令/数据、E 给脉冲锁存、P0 送数据**。写命令 = RS=0 送命令字节 + E 脉冲；写数据 = RS=1 送数据 + E 脉冲。显示函数都是在这两个底层函数之上封装的。

## 全章统一易错点

- [ ] RS/RW/E 接错 → RS=P2_6、RW=P2_5、E=P2_7。
- [ ] 写命令/写数据的 RS 状态搞反 → 命令 RS=0，数据 RS=1。
- [ ] 坐标从 0 开始 → LCD1602 坐标从 1 开始。
- [ ] 忘了初始化 → 不显示。
