# 14-2 LCD1602 功能函数代码

> [!abstract] 这一集只解决一个问题
> **怎么封装一套好用的 LCD1602 显示函数？**
>
> 答：在 14-1 的写命令/写数据基础上，封装 `LCD_ShowChar`（字符）、`LCD_ShowString`（字符串）、`LCD_ShowNum`（十进制）、`LCD_ShowHexNum`（十六进制）、`LCD_ShowBinNum`（二进制）等函数，调用即可显示。
>

## 1 函数全家桶

| 函数 | 作用 | 参数 |
| --- | --- | --- |
| `LCD_ShowChar(Line,Column,Char)` | 显示 1 个字符 | 行、列、字符 |
| `LCD_ShowString(Line,Column,String)` | 显示字符串 | 行、列、字符串指针 |
| `LCD_ShowNum(Line,Column,Num,Length)` | 显示十进制数 | 行、列、数、宽度 |
| `LCD_ShowSignedNum(...)` | 显示有符号数 | 含负号 |
| `LCD_ShowHexNum(...)` | 显示十六进制 | 含 0x 前缀 |
| `LCD_ShowBinNum(...)` | 显示二进制 | 8 位 |

- **坐标从 1 开始**：Line=1~2，Column=1~16。
- `Length`：显示宽度，不足补 0（或空格）。

## 2 定位函数（坐标 → 地址）

所有显示函数都要先"定位"——把（行，列）坐标换算成 DDRAM 地址：

```c
void LCD_SetCursor(unsigned char Line,unsigned char Column)
{
	if(Line==1)
	{
		LCD_WriteCommand(0x80|(Column-1));   // 第 1 行地址 0x00 起
	}
	else
	{
		LCD_WriteCommand(0x80|(Column-1+0x40));  // 第 2 行地址 0x40 起
	}
}
```

- 第 1 行地址 0x00~0x0F，第 2 行 0x40~0x4F。
- `0x80` 是"设置 DDRAM 地址"命令（最高位为 1）。

## 3 显示数字

`LCD_ShowNum` 显示十进制数，核心是把数**逐位拆出来转 ASCII**：

```c
void LCD_ShowNum(unsigned char Line,unsigned char Column,unsigned int Number,unsigned char Length)
{
	unsigned char i;
	LCD_SetCursor(Line,Column);
	for(i=Length;i>0;i--)          // 从高位到低位
	{
		LCD_WriteData('0'+Number/Pow10(i-1)%10);   // 取第 i 位
	}
}
```

> [!tip] 数字转字符的关键
> 显示数字就是"逐位取出 + 加 '0' 转 ASCII"。`Number/10^k%10` 取出第 k 位，加 `'0'`（0x30）变成字符 '0'~'9'，再写数据。

## 4 显示十六进制 / 二进制

原理类似，只是"取位"的进制不同：

- 十六进制：`Number >> 4*k & 0x0F`，0~9 加 '0'，A~F 加 'A'-10。
- 二进制：`Number >> k & 0x01`，0/1 加 '0'。

## 5 完整代码（核心函数）

```c
// 显示一个字符
void LCD_ShowChar(unsigned char Line,unsigned char Column,char Char)
{
	LCD_SetCursor(Line,Column);
	LCD_WriteData(Char);
}

// 显示字符串
void LCD_ShowString(unsigned char Line,unsigned char Column,char *String)
{
	unsigned char i;
	LCD_SetCursor(Line,Column);
	for(i=0;String[i]!='\0';i++)   // 逐个字符直到结束符
	{
		LCD_WriteData(String[i]);
	}
}

// 显示十进制数
void LCD_ShowNum(unsigned char Line,unsigned char Column,unsigned int Number,unsigned char Length)
{
	unsigned char i;
	LCD_SetCursor(Line,Column);
	for(i=Length;i>0;i--)
	{
		LCD_WriteData('0'+Number/Pow10(i-1)%10);
	}
}
```

## 6 易错点

- [ ] 坐标从 0 开始 → LCD1602 从 1 开始。
- [ ] 定位命令地址算错 → 第 2 行要 `+0x40`。
- [ ] 数字没加 '0' → 直接写数字值是 ASCII 控制字符，显示乱码。
- [ ] Length 参数理解错 → 是显示宽度，不是数值大小。

## 7 自测

1. `LCD_SetCursor(2,1)` 会写什么地址？
2. 显示数字为什么要 `+'0'`？
3. `LCD_ShowNum(1,1,234,4)` 显示什么？

> [!success]- 参考答案
> 1. 第 2 行第 1 列，地址 `0x80|(1-1+0x40)=0xC0`。
> 2. 因为字符 '0' 的 ASCII 是 0x30，数字 0~9 加 '0' 才能转成对应的 ASCII 字符显示。
> 3. 在第 1 行第 1 列显示 "0234"（4 位宽度，不足补 0）。
