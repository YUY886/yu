# 14-1 LCD1602 液晶显示屏

> [!abstract] 这一集只解决一个问题
> **LCD1602 的硬件接口和命令是怎么工作的？**
>
> 答：LCD1602 有 3 根控制线（RS/RW/E）+ 8 根数据线（P0）。**写命令**（RS=0）和**写数据**（RS=1）都要配合 E 使能脉冲。初始化写 4 条命令完成配置。

## 1 引脚定义

```c
sbit LCD_RS=P2^6;   // 寄存器选择
sbit LCD_RW=P2^5;   // 读写选择
sbit LCD_E=P2^7;    // 使能
#define LCD_DataPort P0   // 8 位数据总线
```

| 引脚 | 作用 | 取值 |
| --- | --- | --- |
| RS | 选择命令还是数据 | 0=命令，1=数据 |
| RW | 读写 | 0=写，1=读 |
| E | 使能脉冲 | 高电平锁存 |
| D0~D7 | 数据/命令字节 | P0 |

## 2 写命令 / 写数据

LCD1602 的核心是两个底层函数：

### 写命令（RS=0）

```c
void LCD_WriteCommand(unsigned char Command)
{
	LCD_RS=0;              // 命令
	LCD_RW=0;              // 写
	LCD_DataPort=Command;  // 送命令字节
	LCD_E=1;               // E 脉冲
	LCD_Delay();
	LCD_E=0;
	LCD_Delay();
}
```

### 写数据（RS=1）

```c
void LCD_WriteData(unsigned char Data)
{
	LCD_RS=1;              // 数据
	LCD_RW=0;              // 写
	LCD_DataPort=Data;     // 送数据字节
	LCD_E=1;               // E 脉冲
	LCD_Delay();
	LCD_E=0;
	LCD_Delay();
}
```

> [!note] 两者的唯一区别是 RS
> 写命令和写数据几乎一样，只有 `LCD_RS` 不同（命令=0、数据=1）。E 脉冲的下降沿把 P0 上的内容锁存进 LCD。

## 3 初始化

```c
void LCD_Init(void)
{
	LCD_WriteCommand(0x38);  // 8 位数据、2 行、5×7 点阵
	LCD_WriteCommand(0x0C);  // 显示开、光标关
	LCD_WriteCommand(0x06);  // 写后地址自动加 1
	LCD_WriteCommand(0x01);  // 清屏
}
```

| 命令 | 含义 |
| --- | --- |
| 0x38 | 8 位数据总线、2 行显示、5×7 点阵 |
| 0x0C | 开显示、关光标、光标不闪烁 |
| 0x06 | 写入后地址指针自动 +1（从左往右写） |
| 0x01 | 清屏，光标回原点 |

## 4 LCD1602 显示原理

- LCD1602 有 **DDRAM**（显示数据 RAM），每个地址对应屏幕上一个位置。
- 第 1 行地址 0x00~0x0F，第 2 行地址 0x40~0x4F（共 32 个字符位置）。
- 写入数据（字符的 ASCII 码），对应位置就显示该字符。

> [!tip] 显示字符 = 写 ASCII 码
> 要显示字母/数字，直接写它的 ASCII 码到数据口。比如显示 "A" 就是写 0x41。这就是 `LCD_ShowChar` 底层做的事。

## 5 易错点

- [ ] RS 状态搞反 → 命令 RS=0、数据 RS=1。
- [ ] E 脉冲没给 → 数据没锁存进去，不显示。
- [ ] 引脚接错 → RS=P2_6、RW=P2_5、E=P2_7。
- [ ] 初始化命令写错 → 显示异常。

## 6 自测

1. 写命令和写数据的唯一区别是什么？
2. E 引脚的作用是什么？
3. LCD_Init 写了哪 4 条命令？

> [!success]- 参考答案
> 1. 唯一区别是 RS 引脚：命令 RS=0，数据 RS=1。
> 2. E 是使能脉冲，下降沿把 P0 上的命令/数据锁存进 LCD。
> 3. 0x38（8 位/2 行/5×7）、0x0C（显示开/光标关）、0x06（地址自增）、0x01（清屏）。
