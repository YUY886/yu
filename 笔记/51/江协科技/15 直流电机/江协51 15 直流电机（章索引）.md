## 本章速查

### PWM 与占空比

- PWM = 脉冲宽度调制：快速开关，靠"高电平时间占比"（占空比）控制等效电压。
- 占空比 = 高电平时间 / 周期。占空比越大，等效电压越高（灯越亮、电机越快）。

### 软件 PWM（定时器）

```c
void Timer0_Routine() interrupt 1
{
	TL0 = 0x9C;   // 定时初值（100us）
	TH0 = 0xFF;
	Counter++;        // 计数值
	Counter%=100;     // 0~99 循环（周期 = 100×100us = 10ms）
	if(Counter<Compare)   // 小于比较值
		Motor=1;           // 输出高电平
	else
		Motor=0;           // 输出低电平
}
```

- `Compare`（比较值）决定占空比：Compare=50 → 50% 占空比。

> [!tip] 记这一章最省力的办法
> PWM 就记：**定时器里 Counter 从 0 数到 99，小于 Compare 输出高、否则输出低**。改 Compare 就改占空比 → 改等效电压 → 调光/调速。呼吸灯 = Compare 随时间渐变；调速 = 按键改 Compare。

## 全章统一易错点

- [ ] 占空比概念搞混 → 占空比越大 = 等效电压越高。
- [ ] 电机引脚搞错 → 直流电机接 P1_0。
- [ ] 计数器没 %100 → 溢出后占空比错乱。
- [ ] 比较值范围搞错 → Compare 应在 0~100 之间。
