# 15-1 直流电机驱动（PWM）

> [!abstract] 这一集只解决一个问题
> **怎么调节直流电机的转速（或 LED 的亮度）？**
>
> 答：用 **PWM（脉宽调制）**——不改变电压，而是快速开关，靠"高电平时间占比"（**占空比**）控制等效电压。占空比越大，等效电压越高。
>
> 下一集 [[江协51 15-2 LED呼吸灯与直流电机调速]] ｜ 章索引 [[江协51 15 直流电机（章索引）]]

## 1 为什么用 PWM

直流电机的转速、LED 的亮度都和"平均电压"有关。但 51 的输出只有 0V/5V 两档，不能直接调电压。

**PWM** 的解法：快速开关（如 10ms 一周期），靠**高电平占的比例**得到不同的"等效电压"：

```text
占空比 25%：  ███░░░░░░░   等效电压 ≈ 1.25V
占空比 50%：  █████░░░░░   等效电压 ≈ 2.5V
占空比 75%：  ███████░░░   等效电压 ≈ 3.75V
```

- **占空比 = 高电平时间 / 周期**。
- 开关频率足够高时，电机/LED 感受的是"平均电压"，实现连续可调。

## 2 呼吸灯（PWM 调亮度）

呼吸灯 = 占空比**缓慢渐变**（从小到大再到小），LED 亮度随之渐亮渐暗：

```c
sbit LED=P2^0;

void main()
{
	unsigned char Time,i;
	while(1)
	{
		for(Time=0;Time<100;Time++)   // 占空比从小到大（渐亮）
		{
			for(i=0;i<20;i++)
			{
				LED=0;                // 亮
				Delay(Time);          // 亮 Time
				LED=1;                // 灭
				Delay(100-Time);      // 灭 100-Time
			}
		}
		for(Time=100;Time>0;Time--)   // 占空比从大到小（渐暗）
		{
			for(i=0;i<20;i++)
			{
				LED=0;
				Delay(Time);
				LED=1;
				Delay(100-Time);
			}
		}
	}
}
```

- `Time` 从 0 增到 100：亮的比例越来越大 → 渐亮。
- 内层 `for(i=0;i<20;i++)` 循环 20 次，让每个占空比停留足够久，肉眼可见渐变。

## 3 易错点

- [ ] 占空比概念搞混 → 占空比越大 = 越亮/越快。
- [ ] 呼吸灯方向反了 → Time 从小到大是渐亮，从大到小是渐暗。
- [ ] 内层循环次数不够 → 渐变太快，看不出呼吸效果。

## 4 自测

1. PWM 靠什么实现"调节电压"？
2. 占空比 50% 时，等效电压大约是多少（5V 供电）？
3. 呼吸灯为什么有两个 for 循环（Time 增和 Time 减）？

> [!success]- 参考答案
> 1. 靠快速开关、改变高电平时间占比（占空比）来控制等效平均电压。
> 2. 约 2.5V（5V × 50%）。
> 3. 一个让占空比从小到大（渐亮），一个从大到小（渐暗），形成呼吸效果。
