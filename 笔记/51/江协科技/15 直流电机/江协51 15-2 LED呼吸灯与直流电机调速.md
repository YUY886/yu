# 15-2 LED 呼吸灯 & 直流电机调速

> [!abstract] 这一集只解决一个问题
> **怎么用定时器产生 PWM 来调速直流电机？**
>
> 答：用**软件 PWM**——定时器中断里 `Counter` 从 0 数到 99，`Counter < Compare` 输出高电平、否则输出低电平。改 `Compare`（比较值）就改占空比 → 调速。按键切换档位改 Compare。
>
> 上一集 [[江协51 15-1 直流电机驱动PWM]] ｜ 章索引 [[江协51 15 直流电机（章索引）]]

## 1 软件 PWM（定时器实现）

15-1 的呼吸灯用软件延时做 PWM，但会占用 CPU。这一集改用**定时器**做 PWM：

```c
sbit Motor=P1^0;

unsigned char Counter,Compare;   // 计数值、比较值

void Timer0_Routine() interrupt 1
{
	TL0 = 0x9C;		// 定时初值（约 100us）
	TH0 = 0xFF;
	Counter++;      // 计数值加 1
	Counter%=100;   // 限制在 0~99（周期 = 100 × 100us = 10ms）
	if(Counter<Compare)   // 小于比较值 → 高电平
	{
		Motor=1;
	}
	else                  // 大于等于 → 低电平
	{
		Motor=0;
	}
}
```

- 定时初值 0xFF9C → 定时约 100us，100 次 = 10ms 一个 PWM 周期。
- `Counter` 从 0 数到 99 循环；`Compare` 决定高电平占多少 → 占空比。
- `Compare=50` → 50% 占空比；`Compare=75` → 75%。

## 2 按键调速（改占空比）

用按键切换档位，改 `Compare`：

```c
void main()
{
	Timer0_Init();
	while(1)
	{
		KeyNum=Key();
		if(KeyNum==1)
		{
			Speed++;        // 档位加 1
			Speed%=4;       // 0~3 循环
			if(Speed==0){Compare=0;}   // 停止
			if(Speed==1){Compare=50;}  // 慢
			if(Speed==2){Compare=75;}  // 中
			if(Speed==3){Compare=100;} // 快
		}
		Nixie(1,Speed);   // 数码管显示档位
	}
}
```

- 4 个档位：0 停、1 慢（50%）、2 中（75%）、3 快（100%）。
- 数码管显示当前档位。

## 3 完整代码（15-2）

```c
#include <REGX52.H>
#include "Delay.h"
#include "Key.h"
#include "Nixie.h"
#include "Timer0.h"

sbit Motor=P1^0;

unsigned char Counter,Compare;
unsigned char KeyNum,Speed;

void main()
{
	Timer0_Init();
	while(1)
	{
		KeyNum=Key();
		if(KeyNum==1)
		{
			Speed++;
			Speed%=4;
			if(Speed==0){Compare=0;}
			if(Speed==1){Compare=50;}
			if(Speed==2){Compare=75;}
			if(Speed==3){Compare=100;}
		}
		Nixie(1,Speed);
	}
}

void Timer0_Routine() interrupt 1
{
	TL0 = 0x9C;
	TH0 = 0xFF;
	Counter++;
	Counter%=100;
	if(Counter<Compare)
	{
		Motor=1;
	}
	else
	{
		Motor=0;
	}
}
```

## 4 易错点

- [ ] 电机引脚搞错 → Motor=P1^0。
- [ ] 计数器忘了 `%=100` → 溢出后占空比错乱。
- [ ] 比较值范围搞错 → Compare 应在 0~100 之间。
- [ ] 定时初值 0xFF9C 记错 → 这是约 100us（PWM 周期 10ms）。

## 5 自测

1. `Counter<Compare` 判断如何控制占空比？
2. Compare=75 时的占空比是多少？
3. 调速的 4 个档位分别对应什么？

> [!success]- 参考答案
> 1. Counter 从 0 数到 99，小于 Compare 的区间输出高电平，所以 Compare 越大高电平占比越高。
> 2. 75%（Counter 0~74 共 75 个数为高电平，占 100 个的 75%）。
> 3. 0=停止（0%）、1=慢（50%）、2=中（75%）、3=快（100%）。
