## 本章速查

### I2C 引脚

- `I2C_SCL=P2^1`（时钟）、`I2C_SDA=P2^0`（数据）。

### AT24C02 地址

- 器件地址 `0xA0`（写），读 = `0xA0|0x01 = 0xA1`。

### I2C 基本时序

| 操作 | 说明 |
| --- | --- |
| 起始 Start | SDA 高→低，SCL 高 |
| 停止 Stop | SDA 低→高，SCL 高 |
| 发送字节 | 高位先发 8 位 |
| 接收字节 | 高位先收 8 位 |
| 应答 ACK | 接收方拉低 SDA 表示应答 |

> [!tip] 记这一章最省力的办法
> I2C 就记：**两线（SCL 时钟 + SDA 数据）+ 起始/停止 + 应答**。AT24C02 读写 = 起始 → 发器件地址(0xA0) → 发字地址 → 读写数据 → 停止。读操作要"伪写地址 + 再起始 + 读"（先定位再读）。

## 全章统一易错点

- [ ] I2C 引脚搞错 → SCL=P2_1、SDA=P2_0。
- [ ] 读操作忘了"再起始" → 读不到正确地址的数据。
- [ ] 应答位处理错 → 0 是应答、1 是非应答。
- [ ] AT24C02 地址写错 → 器件地址 0xA0。
