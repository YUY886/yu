# 12-2 秒表（定时器扫描按键数码管）

> [!abstract] 这一集只解决一个问题
> **怎么做一个完整的秒表（计秒 + 显示 + 按键控制）？**
>
> 答：综合前面所学——定时器计秒、数码管显示、按键控制，并引入"**定时器扫描按键和数码管**"的新方法（在定时器中断里做扫描，取代主循环轮询）。
>
> 上一集 [[江协51 12-1 AT24C02数据存储]] ｜ 章索引 [[江协51 12 AT24C02与秒表（章索引）]]

## 1 秒表的需求

秒表要同时做几件事：

1. **计时**：定时器每秒加 1。
2. **显示**：数码管动态显示时分秒。
3. **按键控制**：启动/停止/清零。

如果都在主循环里"轮询 + 死等延时"会很乱，这一集引入**定时器扫描**的工程化做法。

## 2 定时器扫描（新方法）

把"扫描按键"和"刷新数码管"都放到**定时器中断**里做，主循环只做核心逻辑：

```c
void Timer0_Routine() interrupt 1
{
	// ① 定时器 1ms 中断
	// ② 分频到合适频率后，扫描按键（消抖）
	// ③ 分频刷新数码管（动态扫描）
}
```

好处：定时器精确控制扫描频率，主循环不用再写 `while` 死等和延时，代码更清晰。

> [!tip] 扫描按键 vs 轮询按键
> 之前（第 3 章）是"主循环里 `if(P3_1==0)` 轮询 + Delay 消抖"。现在改成"定时器中断里固定周期扫一次按键 + 计数消抖"，不阻塞主循环。这是工程上的常见做法。

## 3 秒表逻辑

- **计秒**：定时器中断里 `Sec++`，到 60 进分、到 60 进时（同第 7 章时钟）。
- **按键**：一个键切换"启动/停止"，一个键"清零"。
- **显示**：数码管动态扫描显示。

```c
unsigned char Sec, Min, Hour;

void Timer0_Routine() interrupt 1
{
	// 定时 1ms，分频计秒
	// Sec++ → Min → Hour 进位
}
```

## 4 完整代码（思路骨架）

```c
#include <REGX52.H>
#include "Timer0.h"
#include "Key.h"
#include "Nixie.h"

unsigned char Sec,Min,Hour;
unsigned char KeyNum;

void main()
{
	Timer0_Init();
	while(1)
	{
		KeyNum=Key();
		if(KeyNum==1)  // 启动/停止
		{
			// 切换计时标志
		}
		if(KeyNum==2)  // 清零
		{
			Sec=Min=Hour=0;
		}
	}
}

void Timer0_Routine() interrupt 1
{
	static unsigned int T0Count;
	TL0=0x18; TH0=0xFC;
	T0Count++;
	if(T0Count>=1000)   // 1s
	{
		T0Count=0;
		Sec++;
		if(Sec>=60){Sec=0;Min++;
			if(Min>=60){Min=0;Hour++;
				if(Hour>=24)Hour=0;}}
	}
	// 数码管动态扫描（或另起分频）
}
```

## 5 易错点

- [ ] 秒表进位逻辑和时钟一样 → 60 进 1，注意时分秒范围。
- [ ] 定时器扫描没分频 → 1ms 扫一次按键/数码管太频繁。
- [ ] 按键消抖在中断里做 → 用计数消抖，别在中断里 Delay。
- [ ] 启动/停止状态没区分 → 需要一个标志位记录"是否在计时"。

## 6 自测

1. "定时器扫描"和"主循环轮询"有什么区别？
2. 秒表需要同时做哪三件事？
3. 为什么中断里不能直接调用软件延时消抖？

> [!success]- 参考答案
> 1. 定时器扫描在中断里固定周期执行、不阻塞主循环；主循环轮询会阻塞、需要死等延时。
> 2. 计时（定时器计秒）、显示（数码管动态扫描）、按键控制（启动/停止/清零）。
> 3. 中断里调用软件延时会让中断长时间占用 CPU，影响主程序和后续中断；应用"计数消抖"代替。
