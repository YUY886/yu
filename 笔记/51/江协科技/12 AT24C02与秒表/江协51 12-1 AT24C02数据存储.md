# 12-1 AT24C02 数据存储

> [!abstract] 这一集只解决一个问题
> **怎么让数据断电后也不丢（掉电保存）？**
>
> 答：用 **AT24C02 EEPROM**，通过 **I2C 总线**读写。EEPROM 是非易失存储器，断电数据仍在。I2C 只需两根线（SCL/SDA），用起始/停止/应答时序通信。
>

## 1 为什么需要 EEPROM

51 单片机内部的 RAM 掉电就丢，Flash 是存程序的。**AT24C02** 是 2Kbit（256 字节）的 **EEPROM**（电可擦除只读存储器），掉电数据不丢，适合存密码、配置等要持久化的数据。

## 2 I2C 总线

I2C 是两线串行总线，**多设备共享**：

| 线 | 作用 |
| --- | --- |
| SCL（P2^1） | 时钟线 |
| SDA（P2^0） | 数据线（双向） |

```c
sbit I2C_SCL=P2^1;
sbit I2C_SDA=P2^0;
```

### 基本时序

| 操作 | 时序 |
| --- | --- |
| **起始 Start** | SCL 高时，SDA 从高→低 |
| **停止 Stop** | SCL 高时，SDA 从低→高 |
| **发送字节** | 8 位，高位先发 |
| **接收字节** | 8 位，高位先收 |
| **应答 ACK** | 第 9 个时钟，接收方拉低 SDA 表示收到 |

## 3 I2C 基本函数

```c
void I2C_Start(void)      // 起始
{
	I2C_SDA=1;
	I2C_SCL=1;
	I2C_SDA=0;    // SDA 高→低
	I2C_SCL=0;
}

void I2C_Stop(void)       // 停止
{
	I2C_SDA=0;
	I2C_SCL=1;
	I2C_SDA=1;    // SDA 低→高
}

void I2C_SendByte(unsigned char Byte)   // 发送，高位先
{
	unsigned char i;
	for(i=0;i<8;i++)
	{
		I2C_SDA=Byte&(0x80>>i);
		I2C_SCL=1;
		I2C_SCL=0;
	}
}

unsigned char I2C_ReceiveByte(void)     // 接收，高位先
{
	unsigned char i,Byte=0x00;
	I2C_SDA=1;
	for(i=0;i<8;i++)
	{
		I2C_SCL=1;
		if(I2C_SDA){Byte|=(0x80>>i);}
		I2C_SCL=0;
	}
	return Byte;
}
```

## 4 AT24C02 读写

AT24C02 器件地址 **0xA0**（写），读地址 `0xA1`（=0xA0|0x01）。

### 写一个字节

```c
void AT24C02_WriteByte(unsigned char WordAddress,Data)
{
	I2C_Start();
	I2C_SendByte(AT24C02_ADDRESS);   // 0xA0
	I2C_ReceiveAck();
	I2C_SendByte(WordAddress);       // 字地址
	I2C_ReceiveAck();
	I2C_SendByte(Data);              // 数据
	I2C_ReceiveAck();
	I2C_Stop();
}
```

### 读一个字节

```c
unsigned char AT24C02_ReadByte(unsigned char WordAddress)
{
	unsigned char Data;
	I2C_Start();
	I2C_SendByte(AT24C02_ADDRESS);       // 0xA0（伪写定位）
	I2C_ReceiveAck();
	I2C_SendByte(WordAddress);           // 字地址
	I2C_ReceiveAck();
	I2C_Start();                          // 再次起始
	I2C_SendByte(AT24C02_ADDRESS|0x01);  // 0xA1（读）
	I2C_ReceiveAck();
	Data=I2C_ReceiveByte();               // 读数据
	I2C_SendAck(1);                       // 非应答
	I2C_Stop();
	return Data;
}
```

> [!warning] 读操作为什么"两次起始"
> AT24C02 读数据要先**用写模式定位字地址**（发 0xA0 + 字地址），再**重新起始、用读模式（0xA1）**读数据。这是因为 I2C 的读需要先告诉芯片"从哪个地址读"。

## 5 易错点

- [ ] I2C 引脚搞错 → SCL=P2^1、SDA=P2^0。
- [ ] 读操作漏了"再起始" → 读不到数据。
- [ ] 器件地址写错 → 写 0xA0、读 0xA1。
- [ ] 应答位理解错 → 0=应答、1=非应答。

## 6 自测

1. EEPROM 和 RAM 有什么区别？
2. I2C 的起始/停止条件各是什么？
3. 为什么读 AT24C02 要先"伪写"再"读"？

> [!success]- 参考答案
> 1. EEPROM 掉电数据不丢（非易失），RAM 掉电数据丢失（易失）。
> 2. 起始：SCL 高时 SDA 高→低；停止：SCL 高时 SDA 低→高。
> 3. 因为要先告诉芯片"从哪个字地址读"，所以先用写模式（0xA0）发字地址定位，再重新起始用读模式（0xA1）读数据。
