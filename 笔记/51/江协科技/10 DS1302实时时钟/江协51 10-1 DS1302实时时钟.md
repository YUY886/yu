# 10-1 DS1302 实时时钟

> [!abstract] 这一集只解决一个问题
> **怎么做一个断电也不停的时钟？**
>
> 答：用 **DS1302 时钟芯片**——它自带振荡器和备用电池，掉电仍计时。单片机通过 3 线接口读写它的时间寄存器（年/月/日/时/分/秒，BCD 码存储）。
>

## 1 为什么用 DS1302

第 7 章的定时器时钟，断电后时间就丢了（靠程序在 RAM 里计数）。DS1302 是**独立的时钟芯片**：

- 内部有晶振和计数器，**只要供电（含备用电池）就一直走**，单片机断电不影响。
- 单片机只需**读**它的时间寄存器来显示，或**写**来校准。

### 1.1 DS1302 为什么能"断电不停"

DS1302 内部结构：

```text
  DS1302 芯片内部
  ┌─────────────────────────────┐
  │  32.768kHz 晶振 ──► 分频器 ──► 秒计数器（BCD）     │
  │                              │  → 分 → 时 → 日 → 月 → 年 │
  │                              │                          │
  │  双电源：VCC2（主电源）+ VCC1（备用电池）              │
  │  有备用电池时，主电源断电自动切换到电池继续走时         │
  │  通信接口：CE/SCLK/IO（3 线）──► 供单片机读写寄存器    │
  └─────────────────────────────┘
```

- **32.768kHz 晶振**：这是 RTC（实时时钟）的"行业标准"频率。因为 32768 = 2^15，经过 15 级二分频恰好得到 1Hz（每秒一次），分频电路最简单。
- **双电源**：VCC2 主电源 + VCC1 备用电池。主电源断电时，芯片自动切到备用电池继续计时，所以"断电不停"。
- **BCD 计数**：内部秒/分/时用 BCD 码计数，溢出自动进位（59 秒 → 0 分 +1）。

> [!note] 定时器时钟 vs DS1302 时钟
> | | 定时器时钟（第7章） | DS1302 时钟（本章） |
> | --- | --- | --- |
> | 计时主体 | 单片机（软件计数） | 独立芯片（硬件计数） |
> | 断电后 | 时间丢失 | 继续走（有备用电池） |
> | 精度 | 依赖晶振 | 独立 32.768kHz 晶振，更准 |
> | 资源占用 | 占一个定时器 | 占 3 个 IO |

## 2 DS1302 接口与引脚

DS1302 用 **3 线接口**（类似 SPI 但非标准 SPI）：

| 引脚 | 接 IO | 作用 |
| --- | --- | --- |
| SCLK | P3^6 | 串行时钟 |
| IO | P3^4 | 数据（双向） |
| CE | P3^5 | 使能（片选，高电平有效） |

```c
sbit DS1302_SCLK=P3^6;
sbit DS1302_IO=P3^4;
sbit DS1302_CE=P3^5;
```

## 3 寄存器与命令字

DS1302 的时间存在 8 个寄存器里，每个寄存器有一个**命令字（地址）**：

| 寄存器 | 写入地址 | 内容 |
| --- | --- | --- |
| 秒 SECOND | 0x80 | 秒（BCD） |
| 分 MINUTE | 0x82 | 分 |
| 时 HOUR | 0x84 | 时 |
| 日 DATE | 0x86 | 日 |
| 月 MONTH | 0x88 | 月 |
| 星期 DAY | 0x8A | 星期 |
| 年 YEAR | 0x8C | 年 |
| 写保护 WP | 0x8E | 写保护控制 |

- **写**：地址最高位为 1（如 0x80）。
- **读**：地址 `| 0x01`（如 0x81），即最低位为 1。

## 4 读写时序

### 写一个字节

```c
void DS1302_WriteByte(unsigned char Command,Data)
{
	unsigned char i;
	DS1302_CE=1;               // 使能
	for(i=0;i<8;i++)
	{
		DS1302_IO=Command&(0x01<<i);  // 先送命令字（低位先送）
		DS1302_SCLK=1;
		DS1302_SCLK=0;
	}
	for(i=0;i<8;i++)
	{
		DS1302_IO=Data&(0x01<<i);     // 再送数据
		DS1302_SCLK=1;
		DS1302_SCLK=0;
	}
	DS1302_CE=0;               // 结束
}
```

### 读一个字节

```c
unsigned char DS1302_ReadByte(unsigned char Command)
{
	unsigned char i,Data=0x00;
	Command|=0x01;             // 转为读命令
	DS1302_CE=1;
	for(i=0;i<8;i++)           // 送读命令
	{
		DS1302_IO=Command&(0x01<<i);
		DS1302_SCLK=0;
		DS1302_SCLK=1;
	}
	for(i=0;i<8;i++)           // 读回数据
	{
		DS1302_SCLK=1;
		DS1302_SCLK=0;
		if(DS1302_IO){Data|=(0x01<<i);}
	}
	DS1302_CE=0;
	DS1302_IO=0;               // 读完把 IO 拉低
	return Data;
}
```

> [!note] DS1302 是"低位先送"
> 注意 DS1302 的命令字是 `0x01<<i` **低位先送**，而前面 74HC595 是 `0x80>>i` 高位先送。不同芯片时序不同，别混。

## 5 BCD 码转换

DS1302 内部用 **BCD 码**（一个字节的高 4 位存十位、低 4 位存个位）存储时间，而程序用十进制，需要转换：

```c
十进制 → BCD：Temp/10*16 + Temp%10   // 如 59 → 0x59
BCD → 十进制：Temp/16*10 + Temp%16   // 如 0x59 → 59
```

### 5.1 什么是 BCD 码

**BCD（Binary-Coded Decimal，二进制编码的十进制）**：用 4 位二进制表示 1 位十进制数。一个字节的高 4 位 = 十位，低 4 位 = 个位。

```text
  十进制 59 → BCD 0x59（高4位=5，低4位=9）
  十进制 23 → BCD 0x23
  十进制 6  → BCD 0x06（个位6，十位0）
```

- BCD 的每个"半字节"只能表示 0~9（不是 0~15），所以 `0x59` 是合法的（代表 59），但 `0x5A` 不合法（A=10 不是十进制位）。
- 好处：**直观**，每个十进制位独立，读取时不用做复杂的除法就能得到"十位"和"个位"。

> [!note] 为什么 RTC 芯片爱用 BCD
> 时钟芯片要"按十进制进位"（59 秒 → 0 分），用 BCD 码硬件上容易实现"十进制进位"逻辑。如果用纯二进制，59+1=60（0x3C），要判断"到 60 清零"反而麻烦。BCD 让硬件进位和人的十进制习惯一致。

### 5.2 转换公式推导

```text
十进制 → BCD：
  59 = 5*10 + 9（十位 5，个位 9）
  BCD = 5*16 + 9 = 0x59
  所以：BCD = (n/10)*16 + (n%10)   ← n/10 取十位，n%10 取个位

BCD → 十进制：
  0x59 = 5*16 + 9
  十进制 = 5*10 + 9 = 59
  所以：十进制 = (b/16)*10 + (b%16)   ← b/16 取高4位（十位），b%16 取低4位（个位）
```

写时间时十进制转 BCD：

```c
DS1302_WriteByte(DS1302_MINUTE, DS1302_Time[4]/10*16+DS1302_Time[4]%10);
```

读时间时 BCD 转十进制：

```c
Temp=DS1302_ReadByte(DS1302_MINUTE);
DS1302_Time[4]=Temp/16*10+Temp%16;
```

## 6 写保护

DS1302 有**写保护**功能：默认（WP=0x80）禁止写，要写时间必须先解除（WP 写 0x00），写完再上保护（0x80）：

```c
void DS1302_SetTime(void)
{
	DS1302_WriteByte(DS1302_WP,0x00);   // 解除写保护
	// ... 依次写年/月/日/时/分/秒/星期 ...
	DS1302_WriteByte(DS1302_WP,0x80);   // 重新写保护
}
```

## 7 完整代码（读时间）

```c
unsigned char DS1302_Time[]={19,11,16,12,59,55,6};  // 年、月、日、时、分、秒、星期

void DS1302_ReadTime(void)
{
	unsigned char Temp;
	Temp=DS1302_ReadByte(DS1302_YEAR);
	DS1302_Time[0]=Temp/16*10+Temp%16;   // BCD→十进制
	Temp=DS1302_ReadByte(DS1302_MONTH);
	DS1302_Time[1]=Temp/16*10+Temp%16;
	// ... 依次读日/时/分/秒/星期 ...
}
```

## 8 易错点

- [ ] 读写命令字搞混 → 读要 `|0x01`。
- [ ] BCD 没转换 → 时间显示错乱（59 显示成 0x59=89）。
- [ ] 写时间忘了解除写保护 → 写不进去。
- [ ] 数据方向搞反 → DS1302 低位先送（`0x01<<i`）。
- [ ] 读完没拉低 IO → 影响后续读。
