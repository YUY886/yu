## 本章速查

### DS1302 引脚与命令字

- 3 线接口：`SCLK=P3^6`、`IO=P3^4`、`CE=P3^5`。
- 寄存器地址（写入，最高位=1 表示写）：

| 寄存器 | 地址 |
| --- | --- |
| 秒 SECOND | 0x80 |
| 分 MINUTE | 0x82 |
| 时 HOUR | 0x84 |
| 日 DATE | 0x86 |
| 月 MONTH | 0x88 |
| 星期 DAY | 0x8A |
| 年 YEAR | 0x8C |
| 写保护 WP | 0x8E |

- 读 = 地址 `| 0x01`。

### BCD 码转换

```c
十进制 → BCD：Temp/10*16 + Temp%10
BCD → 十进制：Temp/16*10 + Temp%16
```

> [!tip] 记这一章最省力的办法
> DS1302 就记：**3 线（SCLK/IO/CE）+ 命令字（秒 0x80、分 0x82、时 0x84…）+ BCD 转换**。读写时序和 74HC595 类似（时钟线 + 数据线），只是多了 CE 使能。写时间前要先解除写保护（WP 写 0x00），写完再上保护（0x80）。

## 全章统一易错点

- [ ] 读写命令字搞混 → 读要 `|0x01`，写最高位=1。
- [ ] BCD 和十进制没转换 → 直接存十进制，芯片按 BCD 解析就错了。
- [ ] 忘了写保护 → 写入前 WP 写 0x00，写完写 0x80。
- [ ] IO 读完没拉低 → DS1302 读后 IO 要置 0，否则影响下次读。
