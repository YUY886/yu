# 10-2 DS1302 时钟 & 可调时钟

> [!abstract] 这一集只解决一个问题
> **怎么用按键调整 DS1302 时钟的时分秒？**
>
> 答：用按键切换"调整项"（时→分→秒），再按键增减数值，最后写回 DS1302。核心是**按键状态机** + 调用 10-1 的读写函数。
>
> 上一集 [[江协51 10-1 DS1302实时时钟]] ｜ 章索引 [[江协51 10 DS1302实时时钟（章索引）]]

## 1 可调时钟的设计思路

可调时钟需要三个动作：

```text
① 进入调整模式（某个按键切换）
② 选择要调的项目（时/分/秒，轮流转）
③ 增减数值（上/下键）
④ 确认写回 DS1302
```

用几个按键 + 一个"当前调整项"变量（状态）来实现。

## 2 按键状态机

用一个变量（如 `TimeSelect`）记录当前在调哪一项：

| TimeSelect | 调整项 |
| --- | --- |
| 0 | 正常显示（不调） |
| 1 | 调时 |
| 2 | 调分 |
| 3 | 调秒 |

- 按"设置键"：TimeSelect 在 0→1→2→3→0 间循环（0 是退出调整）。
- 按"加/减键"：修改当前 TimeSelect 对应的时分秒。
- 退出后：调用 `DS1302_SetTime()` 写回。

## 3 完整代码（示意）

```c
#include <REGX52.H>
#include "LCD1602.h"
#include "DS1302.h"
#include "Key.h"

unsigned char KeyNum,TimeSelect,TimeSetSelect;

void main()
{
	LCD_Init();
	DS1302_Init();
	DS1302_SetTime();      // 上电写入默认时间（首次使用）
	LCD_ShowString(1,1,"  :  :");
	
	while(1)
	{
		KeyNum=Key();      // 读按键
		
		// 设置键：切换调整项
		if(KeyNum==1)
		{
			TimeSelect++;
			TimeSelect%=4;    // 0,1,2,3 循环
		}
		
		// 加键/减键：调整当前项
		if(KeyNum==2 && TimeSelect==1) { DS1302_Time[3]++; if(DS1302_Time[3]>=24)DS1302_Time[3]=0; }  // 调时
		if(KeyNum==3 && TimeSelect==1) { DS1302_Time[3]--; if(DS1302_Time[3]==255)DS1302_Time[3]=23; }
		if(KeyNum==2 && TimeSelect==2) { DS1302_Time[4]++; if(DS1302_Time[4]>=60)DS1302_Time[4]=0; }  // 调分
		if(KeyNum==3 && TimeSelect==2) { DS1302_Time[4]--; if(DS1302_Time[4]==255)DS1302_Time[4]=59; }
		if(KeyNum==2 && TimeSelect==3) { DS1302_Time[5]++; if(DS1302_Time[5]>=60)DS1302_Time[5]=0; }  // 调秒
		if(KeyNum==3 && TimeSelect==3) { DS1302_Time[5]--; if(DS1302_Time[5]==255)DS1302_Time[5]=59; }
		
		DS1302_ReadTime();   // 读时间显示
		LCD_ShowNum(1,1,DS1302_Time[3],2);  // 时
		LCD_ShowNum(1,4,DS1302_Time[4],2);  // 分
		LCD_ShowNum(1,7,DS1302_Time[5],2);  // 秒
	}
}
```

> [!note] 上面是"思路示意"
> 官方 10-2 的完整实现更细致（含调整时闪烁、暂停走时等）。但核心就三件事：**切换调整项（状态机）→ 增减数值（带边界）→ 写回 DS1302**。理解这个骨架即可，完整代码以官方源码为准。

## 4 易错点

- [ ] 边界没处理 → 时加到 24、分秒加到 60 就错乱，要归 0/23/59。
- [ ] 减到负值 → `unsigned char` 减到 0 再减变 255，要特判 `==255` 归最大值。
- [ ] 调整后没写回 → 只改了 RAM 数组，没调 `DS1302_SetTime()`，芯片里没变。
- [ ] 调整项切换状态机写错 → `TimeSelect%=4` 保证 0~3 循环。

## 5 自测

1. 可调时钟的状态机有几个状态？分别代表什么？
2. 为什么调小时要 `>=24` 归 0，而不是 `>=60`？
3. 调整完为什么必须调 `DS1302_SetTime()`？

> [!success]- 参考答案
> 1. 4 个状态：0=正常显示、1=调时、2=调分、3=调秒。
> 2. 因为小时的量程是 0~23（24 小时制），到 24 要归 0。
> 3. 因为按键改的只是 RAM 里的 `DS1302_Time[]` 数组，必须调 `DS1302_SetTime()` 把新值写进 DS1302 芯片才会生效。
