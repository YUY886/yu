## 本章速查

### 串口初始化（4800bps@12MHz）

```c
void UART_Init()
{
	SCON=0x40;        // 方式 1（8 位 UART），允许接收
	PCON |= 0x80;     // SMOD=1（波特率加倍）
	TMOD &= 0x0F;     // 清 T1 配置
	TMOD |= 0x20;     // T1 模式 2（8 位自动重装）
	TL1 = 0xF3;       // 定时初值（4800bps）
	TH1 = 0xF3;
	ET1 = 0;          // 禁 T1 中断
	TR1 = 1;          // 启动 T1
}
```

### 发送/接收

```c
void UART_SendByte(unsigned char Byte)
{
	SBUF=Byte;       // 写 SBUF 即发送
	while(TI==0);    // 等发送完成标志
	TI=0;            // 清标志
}

void UART_Routine() interrupt 4   // 串口中断
{
	if(RI==1)        // 收到数据
	{
		// SBUF 里是收到的数据
		RI=0;        // 清接收标志
	}
}
```

> [!tip] 记这一章最省力的办法
> 串口就记：**SCON 选方式、PCON/定时器 1 定波特率、SBUF 收发数据、TI/RI 是收发完成标志**。发送 = 写 SBUF 后等 TI；接收 = interrupt 4 里查 RI 读 SBUF。

## 全章统一易错点

- [ ] 波特率不对 → 收发乱码（两端波特率必须一致）。
- [ ] 发送后忘了 `while(TI==0)` → 数据没发完就覆盖，丢数据。
- [ ] 接收忘了清 RI → 一直认为有数据到达。
- [ ] 晶振不是 12MHz → 波特率初值要换（11.0592MHz 更精确）。
