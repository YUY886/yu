# 08-1 串口通信

> [!abstract] 这一集只解决一个问题
> **单片机怎么和电脑"对话"（收发数据）？**
>
> 答：用**串口（UART，异步串行通信）**。核心是配置好**波特率**（两端一致），然后用 SCON/PCON/定时器 1 配置串口，通过 SBUF 收发数据。
>
> 下一集 [[江协51 08-2 串口向电脑发送数据与电脑通过串口控制LED]] ｜ 章索引 [[江协51 08 串口通信（章索引）]]

## 1 串口通信是什么

UART（通用异步收发器）用**两根线**（TXD 发送、RXD 接收）在设备间传数据：

```text
  单片机 ──TXD──► RXD── 电脑
         ◄──RXD── TXD──
```

- **异步**：没有时钟线，靠双方约定好的**波特率**（每秒传多少位）来同步。
- 一帧数据 = 起始位（1 位 0）+ 数据位（8 位）+ 停止位（1 位 1）。

> [!warning] 波特率必须两端一致
> 波特率（bps）是收发双方"说话的速度"。两端波特率不一致，收到的就是乱码。串口助手和单片机要设成同一个值。

## 2 波特率的产生

串口波特率由**定时器 1**（T1）产生。这里用 T1 的**模式 2（8 位自动重装）**，因为模式 2 会自动重装初值，最适合做波特率发生器。

本课用 **4800bps@12MHz**：

```c
void UART_Init()
{
	SCON=0x40;        // 方式 1（8 位 UART），允许接收
	PCON |= 0x80;     // SMOD=1（波特率加倍）
	TMOD &= 0x0F;     // 清 T1 的 4 位
	TMOD |= 0x20;     // T1 模式 2（8 位自动重装）
	TL1 = 0xF3;       // 定时初值
	TH1 = 0xF3;       // 自动重装值
	ET1 = 0;          // 禁止 T1 中断（只做波特率，不中断）
	TR1 = 1;          // 启动 T1
}
```

### 关键寄存器

| 寄存器/位 | 作用 |
| --- | --- |
| `SCON` | 串口控制寄存器（方式、允许接收等） |
| `PCON` 的 SMOD 位 | 波特率加倍位（SMOD=1 加倍） |
| `TMOD` | T1 设为模式 2 |
| `TL1`/`TH1` | 波特率初值 |
| `TR1` | 启动 T1 |

> [!note] 12MHz 波特率的"不完美"
> 12MHz 晶振下有些波特率（如 9600）误差较大，所以课程选 **4800bps**。更常见的是用 **11.0592MHz** 晶振，它能精确产生 9600 等标准波特率（因为 11059200 能被 9600 整除）。这也是为什么后面第 17 章红外有"11.0592MHz 版本"。

## 3 发送一个字节

```c
void UART_SendByte(unsigned char Byte)
{
	SBUF=Byte;        // 写 SBUF 触发发送
	while(TI==0);     // 等发送完成（TI 置 1）
	TI=0;             // 清发送完成标志
}
```

- `SBUF`：串口数据缓冲寄存器，写它就启动发送，读它得到接收数据。
- `TI`：发送完成标志，硬件在发完一帧后置 1，软件要手动清 0。

## 4 完整代码（8-1 发送数据）

```c
#include <REGX52.H>
#include "Delay.h"
#include "UART.h"

unsigned char Sec;

void main()
{
	UART_Init();			//串口初始化
	while(1)
	{
		UART_SendByte(Sec);	//串口发送一个字节
		Sec++;				//Sec自增
		Delay(1000);		//延时1秒
	}
}
```

- 效果：每秒往电脑发一个递增的字节，串口助手里能看到数据。

## 5 易错点

- [ ] 波特率两端不一致 → 乱码。
- [ ] 发送后没等 `while(TI==0)` → 数据未发完被覆盖。
- [ ] 忘了清 TI → 只发一次就卡住。
- [ ] 晶振 12MHz 却设 9600 标准波特率 → 误差大，可能乱码。

## 6 自测

1. 串口通信为什么叫"异步"？
2. 串口波特率由谁产生？
3. `UART_SendByte` 里 `while(TI==0)` 的作用？

> [!success]- 参考答案
> 1. 因为没有独立时钟线，靠双方约定好的波特率来同步收发节奏。
> 2. 由定时器 1（T1）产生，这里用 T1 的模式 2（自动重装）。
> 3. 等待发送完成（TI 置 1），确保上一个字节发完再发下一个，避免数据覆盖丢失。
