# 11-1 蜂鸣器

> [!abstract] 这一集只解决一个问题
> **怎么让蜂鸣器发出提示音？**
>
> 答：蜂鸣器接在 P1_5，快速**翻转引脚**（`Buzzer=!Buzzer`）产生方波声音。翻转越快音调越高。`Buzzer_Time(ms)` 让它响一段时间。
>

## 1 蜂鸣器是什么

蜂鸣器分两种：

| 类型 | 特点 |
| --- | --- |
| **有源蜂鸣器** | 内部有振荡器，通电就响固定音（简单） |
| **无源蜂鸣器** | 没有振荡器，需要外部给**方波**才响（可调音） |

本课用**无源蜂鸣器**，通过给不同频率的方波来发出不同音调。

## 2 发声原理

声音的音调由**频率**决定。给蜂鸣器引脚一个方波（反复 0→1→0→1），频率越快音调越高：

### 2.1 方波频率和音调的关系

```text
  方波：  ┌─┐  ┌─┐  ┌─┐
        ──┘ └──┘ └──┘ └──
          ←T→  ←T→       T = 一个周期

  频率 f = 1/T
  频率越高（T 越短）→ 音调越高
```

- 给蜂鸣器引脚一个**方波**，蜂鸣器振膜就按这个频率振动发声。
- **翻转越快，频率越高，音调越高**。比如 1kHz 的方波（每 500μs 翻转一次）就是"嘀"的声音。

> [!note] 频率和周期的换算
> 周期 T = 1 / 频率 f。
> - 1kHz（1000Hz）→ 周期 1ms → 每 500μs 翻转一次（半周期翻转）。
> - 2kHz → 周期 0.5ms → 每 250μs 翻转一次。
>
> 本课 `Buzzer_Delay500us()` 每 500μs 翻转一次，即半周期 500μs、全周期 1ms，频率 = 1kHz。

```c
sbit Buzzer=P1^5;   // 蜂鸣器引脚

void Buzzer_Delay500us()  // 约 500us
{
	unsigned char i;
	_nop_();
	i = 247;
	while (--i);
}

void Buzzer_Time(unsigned int ms)
{
	unsigned int i;
	for(i=0;i<ms*2;i++)   // 翻转 ms*2 次
	{
		Buzzer=!Buzzer;         // 翻转一次
		Buzzer_Delay500us();    // 保持 500us
	}
}
```

- `Buzzer=!Buzzer` 每 500us 翻转一次，产生约 1kHz 的方波 → 响一声。
- `Buzzer_Time(ms)`：响 ms 毫秒（`ms*2` 次翻转，每次 500us）。为什么 `ms*2`？因为 1ms 里翻转 2 次（两个半周期）。

## 3 完整代码

```c
#include <REGX52.H>
#include <INTRINS.H>

//蜂鸣器端口：
sbit Buzzer=P1^5;

void Buzzer_Delay500us()		//@12.000MHz
{
	unsigned char i;
	_nop_();
	i = 247;
	while (--i);
}

void Buzzer_Time(unsigned int ms)
{
	unsigned int i;
	for(i=0;i<ms*2;i++)
	{
		Buzzer=!Buzzer;
		Buzzer_Delay500us();
	}
}
```

## 4 易错点

- [ ] 引脚搞错 → 蜂鸣器是 P1_5。
- [ ] 忘了 `#include <INTRINS.H>` → `_nop_()` 未定义。
- [ ] 有源/无源搞混 → 无源才需要方波驱动。
- [ ] 翻转频率和时长搞混 → 频率决定音调，`ms` 决定响多久。

## 5 自测

1. 有源蜂鸣器和无源蜂鸣器有什么区别？
2. 声音的音调由什么决定？
3. `Buzzer_Time(1000)` 大约响多久？

> [!success]- 参考答案
> 1. 有源内部有振荡器、通电就响固定音；无源需要外部给方波才响、可调音。
> 2. 由方波频率（翻转速度）决定，翻转越快音调越高。
> 3. 约 1 秒（1000ms）。
