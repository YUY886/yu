## 知识地图

```text
              ┌─ 读引脚电平 → 按着亮、松开灭（3-1）
独立按键读取 ─┼─ 加消抖 + 松手检测 → 每按一次状态取反（3-2）
              ├─ 按键自增计数 → LED 二进制显示（3-3）
              └─ 双按键增减 → LED 移位（3-4）
```

- **3-1 是地基**：按键接 P3_1/P3_0，按下为低电平，`if(P3_1==0)` 判断按下。
- **3-2 加消抖**：引入延时消抖 + 松手检测，实现"按一次、动作一次"。
- **3-3 / 3-4 是练习**：把按键和变量、移位结合起来。

## 本章速查

### 按键接线与读法

- 独立按键 **K1=P3_1、K2=P3_0**（还有 K3=P3_2、K4=P3_3）。
- 按下时引脚被拉低 → **按下 = 0**，松开 = 1。
- 读按键：`if(P3_1==0)` 表示 K1 按下。

### 消抖三件套（3-2 起必用）

```c
if(P3_1==0)        // 1. 检测按下
{
    Delay(20);     // 2. 延时消抖（避开按下瞬间的抖动）
    while(P3_1==0);// 3. 松手检测（按住不松就一直等）
    Delay(20);     // 4. 松手再消抖
    // 这里才是"按了一次"要执行的动作
}
```

> [!tip] 记这一章最省力的办法
> 独立按键就记住一个判断式 `if(P3_1==0)` 和消抖三件套 `Delay(20) → while(P3_1==0) → Delay(20)`。后面矩阵键盘、定时器按键、红外按键全是这套逻辑的变体。

## 全章统一易错点

- [ ] 按键电平搞反 → 按下是 0，判断"按下"要写 `==0`，不是 `==1`。
- [ ] 不消抖 → 按一下可能触发多次（抖动导致多次误判）。
- [ ] 忘了松手检测 → 一直按住会反复触发动作。
- [ ] 把 `P3_1` 写成 `P3.1` → 51 里位变量是 `P3_1`（下划线），`.` 是另一种语法易混淆。
