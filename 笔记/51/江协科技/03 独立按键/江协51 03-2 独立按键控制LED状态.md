# 03-2 独立按键控制 LED 状态

> [!abstract] 这一集只解决一个问题
> **怎么让"每按一次按键、LED 状态切换一次"（而不是按住才亮）？**
>
> 答：引入两个关键技术——**延时消抖**（滤掉按下瞬间的抖动）和**松手检测**（按住不松就不重复触发），然后在动作里用 `P2_0=~P2_0` 取反。
>

## 1 为什么要消抖

机械按键按下/松开时，金属触点会**弹跳**，电平不是干净地"高→低"，而是"高→低→高→低→低"这样抖几下（持续几 ms）。如果不处理，程序会误判成"按了好几次"。

```text
理想：  高 ────────┐           ┌─────
                 └───────────┘
实际：  高 ────┐  ┌┐┌┐┌┐ ┌─────┘  ← 抖动毛刺
              └──┘└┘└┘└┘└┘
```

**消抖** = 检测到按下后，先延时 20ms 跳过抖动期，再确认状态。

## 2 消抖三件套

```c
if(P3_1==0)         // ① 检测到按下
{
    Delay(20);      // ② 延时消抖（避开抖动）
    while(P3_1==0); // ③ 松手检测：按住不松就一直卡在这里
    Delay(20);      // ④ 松手再消抖

    P2_0=~P2_0;     // ⑤ 动作：LED 取反
}
```

- **延时消抖**：`Delay(20)` 等 20ms，让抖动过去。
- **松手检测**：`while(P3_1==0);` 只要还按着就空转等待，直到松手才继续。这样保证**按一次只动作一次**。
- **取反**：`~P2_0` 是位取反，1 变 0、0 变 1，实现"亮↔灭"切换。

## 3 完整代码

```c
#include <REGX52.H>

void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
		xms--;
	}
}

void main()
{
	while(1)
	{
		if(P3_1==0)			//如果K1按键按下
		{
			Delay(20);		//延时消抖
			while(P3_1==0);	//松手检测
			Delay(20);		//延时消抖
			
			P2_0=~P2_0;		//LED1取反
		}
	}
}
```

> [!note] 这里的 Delay 是带参数的
> 从本集开始，延时函数升级为 `Delay(unsigned int xms)`——想延时多少 ms 就传多少，比 2-2 的写死 500ms 灵活。它内部 i=2/j=239 对应约 1ms@12MHz。

## 4 易错点

- [ ] 只消抖、不松手检测 → 按住不松会连续触发多次。
- [ ] 只松手检测、不消抖 → 抖动导致按一次触发多次。
- [ ] `~P2_0` 理解错 → `~` 是取反，不是"取低电平"，效果是亮灭切换。
- [ ] 两个 Delay(20) 漏一个 → 消抖不充分。

## 5 自测

1. 消抖和松手检测分别解决什么问题？
2. `P2_0=~P2_0` 实现的效果是什么？
3. 为什么 `while(P3_1==0);` 后面有个分号？

> [!success]- 参考答案
> 1. 消抖解决"机械抖动导致按一次被误判成多次"；松手检测解决"按住不松被反复触发"。
> 2. 每按一次按键，LED 状态取反一次（亮↔灭切换）。
> 3. 因为 `while(P3_1==0);` 是一个空循环体（循环体为空语句），分号是空语句；它表示"只要还按着就原地等待"。
