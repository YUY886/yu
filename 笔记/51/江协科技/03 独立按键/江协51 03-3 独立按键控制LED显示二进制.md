# 03-3 独立按键控制 LED 显示二进制

> [!abstract] 这一集只解决一个问题
> **怎么用 8 颗 LED 显示一个不断自增的二进制数？**
>
> 答：每按一次按键，变量 `LEDNum` 自增 1，再把 `~LEDNum`（取反）写到 P2 端口。LEDNum 的每一位对应一颗 LED，LED 就按二进制规律点亮。
>
> 上一集 [[江协51 03-2 独立按键控制LED状态]] ｜ 下一集 [[江协51 03-4 独立按键控制LED移位]] ｜ 章索引 [[江协51 03 独立按键（章索引）]]

## 1 变量 + 取反 = 二进制显示

关键是一行 `P2=~LEDNum`：

- `LEDNum` 自增后，它的二进制位直接决定哪几颗 LED 亮。
- 因为 LED 是**低电平点亮**，所以要**取反**（`~`）：`LEDNum` 为 1 的位，取反后变 0，对应 LED 亮。

举例：

| LEDNum | 二进制 | ~LEDNum（输出到 P2） | 亮起的 LED |
| --- | --- | --- | --- |
| 0 | 0000 0000 | 1111 1111 | 无（全灭） |
| 1 | 0000 0001 | 1111 1110 | 第 1 颗 |
| 2 | 0000 0010 | 1111 1101 | 第 2 颗 |
| 3 | 0000 0011 | 1111 1100 | 第 1、2 颗 |
| ... | ... | ... | ... |

> [!tip] 这正是"用灯显示二进制"
> LED 亮灭就代表二进制的 0 和 1（亮=1，因为取反后亮对应原值 1）。第 1 颗到第 8 颗分别是二进制的最低位到最高位。

## 2 完整代码

```c
#include <REGX52.H>

void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}

void main()
{
	unsigned char LEDNum=0;
	while(1)
	{
		if(P3_1==0)			//如果K1按键按下
		{
			Delay(20);		//延时消抖
			while(P3_1==0);	//松手检测
			Delay(20);		//延时消抖
			
			LEDNum++;		//变量自增
			P2=~LEDNum;		//变量取反输出给LED
		}
	}
}
```

- `unsigned char LEDNum=0`：8 位无符号变量，范围 0~255，正好对应 8 颗 LED。
- `LEDNum++`：每按一次加 1。
- `P2=~LEDNum`：取反后整体赋值给 P2 端口。

## 3 易错点

- [ ] 忘了取反 `~` → 写成 `P2=LEDNum`，灯的亮灭规律反了（变成高电平点亮）。
- [ ] 变量类型用错 → 8 位 `unsigned char` 够用（0~255）；用 `int` 也行但范围含义不同。
- [ ] 变量没初始化 → 初值随机，显示结果不确定。
- [ ] `LEDNum++` 溢出 → 到 255 后再加变 0，是循环，属正常现象。

## 4 自测

1. `P2=~LEDNum` 里的 `~` 起什么作用？为什么需要它？
2. LEDNum=5（0000 0101）时，哪几颗 LED 亮？
3. 为什么变量要用 `unsigned char` 而不是 `char`？

> [!success]- 参考答案
> 1. `~` 是取反。因为 LED 低电平点亮，`LEDNum` 中为 1 的位需要变成 0 才能点亮对应 LED，所以取反。
> 2. LEDNum=5=0000 0101，取反后 1111 1010，第 1、3 颗 LED 亮（0 在第 1、3 位）。
> 3. `unsigned char` 是 8 位无符号整数（0~255），正好对应 8 颗 LED 的 8 个二进制位，且无符号避免符号位干扰。
