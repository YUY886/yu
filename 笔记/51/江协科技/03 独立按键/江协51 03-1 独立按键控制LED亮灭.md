# 03-1 独立按键控制 LED 亮灭

> [!abstract] 这一集只解决一个问题
> **怎么读按键的状态（输入）？**
>
> 答：按键一端接 IO 引脚、另一端接 GND，按下时引脚被拉低。所以 `if(P3_1==0)` 就是"K1 被按下"。按下时给 LED 输出 0 点亮，松开输出 1 熄灭。
>
> 下一集 [[江协51 03-2 独立按键控制LED状态]] ｜ 章索引 [[江协51 03 独立按键（章索引）]]

## 1 输入与输出的区别

前面第 2 章只做"输出"（程序控制引脚电平）。这一章第一次做"**输入**"——程序读取外界（按键）的状态：

```text
  输出：程序 ──写──► 引脚 ──► 控制 LED（第 2 章）
  输入：按键 ──► 引脚 ──读──► 程序判断（本章）
```

- 读引脚电平：直接用 `P3_1` 的值，为 0 表示低电平，为 1 表示高电平。
- 51 的 IO 口是**准双向口**，读之前通常要先给端口写 1（`P3=0xFF` 或复位后默认），这里因为复位后端口默认输出 1，直接读即可。

## 2 按键电路

```text
   +5V ──[上拉电阻]──┬── IO 引脚（P3.1）
                     │
                  ┌──┴──┐
                  │按键 K1│
                  └──┬──┘
                     │
                    GND
```

- **没按下**：引脚被上拉电阻拉到高电平，读 `P3_1` 得 1。
- **按下**：引脚直接接 GND，被拉低，读 `P3_1` 得 0。

所以 **"按下" = 读到的值是 0**。

## 3 完整代码

```c
#include <REGX52.H>

void main()
{
	while(1)
	{
		if(P3_1==0 || P3_0==0)	//如果K1按键或K2按键按下
		{
			P2_0=0;		//LED1输出0，点亮
		}
		else
		{
			P2_0=1;		//LED1输出1，熄灭
		}
	}
}
```

- `P3_1==0 || P3_0==0`：K1 或 K2 任意一个按下（逻辑或）。
- 按下 → `P2_0=0` 点亮 LED1；松开 → `P2_0=1` 熄灭。

> [!note] 这是"按住亮、松开灭"
> 本集是**最简单**的按键读取，没有消抖、没有松手检测——所以效果是"按住就一直亮、松开就灭"。要"每按一次切换一次状态"，得看 3-2。

## 4 易错点

- [ ] 判断"按下"写成 `==1` → 本板按下是 0，应写 `==0`。
- [ ] 把 `||`（或）写成 `&&`（与）→ 会变成"两个都按下才亮"。
- [ ] 引脚名写错 → 按键是 P3_1/P3_0，LED 是 P2_0。

## 5 自测

1. 为什么判断"按下"要写 `P3_1==0` 而不是 `==1`？
2. `if(P3_1==0 || P3_0==0)` 中 `||` 的作用是什么？
3. 本集代码没有消抖，会有什么现象？

> [!success]- 参考答案
> 1. 因为按键一端接 GND，按下时引脚被拉低为 0，所以"按下"对应读到的值是 0。
> 2. `||` 是逻辑或，表示"K1 按下**或** K2 按下"任意一个成立就执行。
> 3. 按住就一直亮、松开就灭；且按键瞬间的机械抖动可能造成短暂的误判（本集未处理，3-2 才消抖）。
