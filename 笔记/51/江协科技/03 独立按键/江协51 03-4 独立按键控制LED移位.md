# 03-4 独立按键控制 LED 移位

> [!abstract] 这一集只解决一个问题
> **怎么让亮的那颗 LED 左右移动（K1 往一个方向、K2 往另一个方向）？**
>
> 答：用移位运算 `0x01<<LEDNum` 生成"只有一位为 1"的数，取反后给 P2；用 `LEDNum++`/`LEDNum--` 改变亮灯位置，并做**边界限制**防止越界。
>
> 上一集 [[江协51 03-3 独立按键控制LED显示二进制]] ｜ 章索引 [[江协51 03 独立按键（章索引）]]

## 1 移位运算

`0x01 << LEDNum` 是左移：把 `0000 0001` 整体左移 LEDNum 位。

| LEDNum | 0x01<<LEDNum | 取反后 ~(...) | 亮的 LED |
| --- | --- | --- | --- |
| 0 | 0000 0001 | 1111 1110 | 第 1 颗 |
| 1 | 0000 0010 | 1111 1101 | 第 2 颗 |
| 2 | 0000 0100 | 1111 1011 | 第 3 颗 |
| ... | ... | ... | ... |
| 7 | 1000 0000 | 0111 1111 | 第 8 颗 |

- `0x01<<LEDNum` 产生"只有第 LEDNum 位为 1"的数，取反后就是"只有那一位为 0"→ 对应灯亮。
- 相比 2-3 流水灯写死 8 个值，这里用 `LEDNum` 变量 + 移位，一个式子搞定任意位置。

### 1.1 移位运算的本质

`0x01 << LEDNum` 是**左移运算**，把 `0000 0001` 这个字节里的"1"向左移动 LEDNum 位：

```text
  LEDNum=0: 0000 0001   （1 在第 0 位）
  LEDNum=1: 0000 0010   （1 左移 1 位，到第 1 位）
  LEDNum=2: 0000 0100   （1 到第 2 位）
  ...
  LEDNum=7: 1000 0000   （1 到第 7 位）
```

- 每左移 1 位，数值翻倍（`1<<0=1`、`1<<1=2`、`1<<2=4`...`1<<7=128`），这正是二进制的"位权"。
- `<<` 左移时**右边补 0**，左边移出的位丢弃。

> [!note] 移位 vs 乘法
> `0x01 << n` 等价于 `1 * 2^n`。移位运算比乘法快，且在"位操作"语境下更直观（明确表达"第 n 位为 1"）。嵌入式里操作单个位，几乎都用移位。

## 2 边界限制

LEDNum 是 0~7（8 颗灯），超出范围必须处理：

```c
if(LEDNum>=8)   // 加到 8 时回到 0
    LEDNum=0;

if(LEDNum==0)   // 减到 0 时跳到 7（反向）
    LEDNum=7;
else
    LEDNum--;
```

- 正向（K1）：`LEDNum++`，到 8 归 0 → 循环右移。
- 反向（K2）：`LEDNum--`，到 0 归 7 → 循环左移。

## 3 完整代码

```c
#include <REGX52.H>
void Delay(unsigned int xms);

unsigned char LEDNum;

void main()
{
	P2=~0x01;				//上电默认LED1点亮
	while(1)
	{
		if(P3_1==0)			//如果K1按键按下
		{
			Delay(20);
			while(P3_1==0);
			Delay(20);
			
			LEDNum++;		//LEDNum自增
			if(LEDNum>=8)	//限制LEDNum自增范围
				LEDNum=0;
			P2=~(0x01<<LEDNum);	//LED的第LEDNum位点亮
		}
		if(P3_0==0)			//如果K2按键按下
		{
			Delay(20);
			while(P3_0==0);
			Delay(20);
			
			if(LEDNum==0)	//LEDNum减到0后变为7
				LEDNum=7;
			else			//LEDNum未减到0，自减
				LEDNum--;
			P2=~(0x01<<LEDNum);	//LED的第LEDNum位点亮
		}
	}
}

void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

> [!note] 两个按键各自独立判断
> K1 和 K2 各写一个 `if` 块（不是 if/else），因为两个按键是独立的。`LEDNum` 是全局变量，两个块共享。

## 4 易错点

- [ ] `0x01<<LEDNum` 优先级理解错 → `<<` 优先级低于 `~`，所以写 `~(0x01<<LEDNum)` 要加括号，否则先取反再移位就错了。
- [ ] 边界没处理 → LEDNum 超出 0~7，移位结果错误或越界。
- [ ] 反向减到 0 没归 7 → 减到 -1（实为 255），移位溢出。
- [ ] 两个按键用 if/else 写 → 会漏掉"两个同时按下"的情况（虽然这里影响不大，但语义不对）。

## 5 自测

1. `0x01<<3` 的结果是多少？对应哪颗 LED？
2. 为什么要做边界限制 `LEDNum>=8 → 0`？
3. 为什么 `~(0x01<<LEDNum)` 要加括号？

> [!success]- 参考答案
> 1. `0x01<<3 = 0000 1000`（第 3 位为 1），取反后第 4 颗 LED 亮。
> 2. LEDNum 表示第几颗灯（0~7 共 8 颗），自增超过 7 就超出 8 位范围，必须归 0 循环。
> 3. 因为 `~` 优先级高于 `<<`，不加括号会先执行 `~0x01` 再左移，结果错误；加括号保证先移位再取反。
