## 本章速查

### LED 点亮原理

- 开发板 LED 是**低电平点亮**：LED 阳极经限流电阻接 +5V，阴极接 IO 引脚；IO 输出 0 时电流从 5V 流过 LED 到引脚，LED 亮；输出 1 时两端等电位，LED 灭。
- 所以"点亮"对应给引脚写 **0**，"熄灭"写 **1**。

### 端口赋值 vs 位操作

```c
sbit LED1 = P2^0;   // 位定义：把 P2.0 命名成 LED1（需在 REGX52.H 基础上自己定义）
LED1 = 0;            // 单引脚输出低电平 → 点亮

P2 = 0xFE;           // 整体赋值：P2 低 8 位 = 1111 1110，只有 P2.0 为 0
```

- `P2 = 0xFE` 的二进制是 `1111 1110`，最低位（P2.0）为 0，其余为 1 → 只有第 1 颗 LED 亮。
- `0xFD = 1111 1101` → 第 2 颗亮；`0xFB = 1111 1011` → 第 3 颗亮……依次类推。

> [!tip] 记这一章最省力的办法
> 点灯 = 给引脚写 0（低电平点亮）。整章就三个动作：**单引脚赋值（sbit）→ 整体赋值（P2=0xXX）→ 加延时（Delay）**。十六进制 `0xFE` 里"哪个位是 0，哪颗灯就亮"。

## 全章统一易错点

- [ ] 把点亮电平搞反 → 本开发板 LED 是**低电平点亮**，写 0 亮、写 1 灭。
- [ ] `0xFE` 和二进制位对不上 → `0xFE=1111 1110`，最低位是 0，点亮的是 P2.0（第 1 颗）。
- [ ] 主函数忘了 `while(1)` → 程序执行完就"跑飞"，LED 现象不稳定。
- [ ] 延时函数参数理解错 → `Delay500ms()` 名字里的 500ms 是按 12MHz 晶振算的，换晶振要重算。
