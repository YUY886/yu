# 02-3 LED 流水灯

> [!abstract] 这一集只解决一个问题
> **怎么让 8 颗 LED 依次点亮，形成"流水"效果？**
>
> 一句话：依次给 P2 端口赋 8 个不同的值（`0xFE → 0xFD → 0xFB → ... → 0x7F`），每个值之间加延时。每个值里"0"所在的那一位对应的 LED 亮，0 的位置逐步左移，就是流水灯。
>
> 这一集真正的知识点是**位操作**——十六进制、二进制、移位运算，这是 51 乃至所有嵌入式编程的底层基本功。
>
> 上一集 [[江协51 02-2 LED闪烁]] ｜ 章索引 [[江协51 02 LED（章索引）]]

## 1 十六进制与二进制位

流水灯的核心是理解"一个十六进制数 = 8 个二进制位 = 8 颗 LED 的状态"。

### 1.1 一个字节的 8 个位

51 的端口是 8 位，一个字节（`unsigned char`）也是 8 位，两者一一对应：

```text
  位编号：  7    6    5    4    3    2    1    0
  引脚：   P2.7  P2.6  P2.5  P2.4  P2.3  P2.2  P2.1  P2.0
  值 0xFE:  1    1    1    1    1    1    1    0
            │    │    │    │    │    │    │    │
            │    │    │    │    │    │    │    └─ 0 → 亮（P2.0）
            └────┴────┴────┴────┴────┴────┴────── 1 → 灭
```

- **位 0 是最低位**（最右边），对应 P2.0（第 1 颗 LED）。
- **位 7 是最高位**（最左边），对应 P2.7（第 8 颗 LED）。
- 低电平点亮，所以"位是 0 → 亮，位是 1 → 灭"。

### 1.2 十六进制如何转二进制

十六进制的每一位 = 4 个二进制位：

```text
  F = 1111
  E = 1110
  D = 1101
  B = 1011
  7 = 0111
  ...
```

所以 `0xFE` = `F`(1111) + `E`(1110) = `1111 1110`。

> [!tip] 记十六进制的一个小技巧
> 0~9 对应十进制，A~F 对应 10~15：
> A=1010、B=1011、C=1100、D=1101、E=1110、F=1111。
> 流水灯里常用的 `0xFE/0xFD/0xFB/0xF7/0xEF/0xDF/0xBF/0x7F`，就是"从右往左，0 的位置一位位移动"。

### 1.3 流水灯的取值序列

| 赋值 | 二进制 | 亮的 LED（0 的位置） |
| --- | --- | --- |
| `0xFE` | 1111 1110 | 第 1 颗（P2.0） |
| `0xFD` | 1111 1101 | 第 2 颗（P2.1） |
| `0xFB` | 1111 1011 | 第 3 颗（P2.2） |
| `0xF7` | 1111 0111 | 第 4 颗（P2.3） |
| `0xEF` | 1110 1111 | 第 5 颗（P2.4） |
| `0xDF` | 1101 1111 | 第 6 颗（P2.5） |
| `0xBF` | 1011 1111 | 第 7 颗（P2.6） |
| `0x7F` | 0111 1111 | 第 8 颗（P2.7） |

- 规律：**0 从最低位逐步左移到最高位**。0 在哪一位，哪颗 LED 亮。

## 2 完整代码（官方写法：逐个写死）

```c
#include <REGX52.H>
#include <INTRINS.H>

void Delay500ms()		//@12.000MHz
{
	unsigned char i, j, k;

	_nop_();
	i = 4;
	j = 205;
	k = 187;
	do
	{
		do
		{
			while (--k);
		} while (--j);
	} while (--i);
}


void main()
{
	while(1)
	{
		P2=0xFE;//1111 1110
		Delay500ms();
		P2=0xFD;//1111 1101
		Delay500ms();
		P2=0xFB;//1111 1011
		Delay500ms();
		P2=0xF7;//1111 0111
		Delay500ms();
		P2=0xEF;//1110 1111
		Delay500ms();
		P2=0xDF;//1101 1111
		Delay500ms();
		P2=0xBF;//1011 1111
		Delay500ms();
		P2=0x7F;//0111 1111
		Delay500ms();
	}
}
```

> [!tip] 这种写法"笨"但有教学价值
> 官方 2-3 用的是"逐个写死 8 个值"的直白写法，好处是让新手一眼看清"0 在左移"。但代码冗长、不灵活。更优雅的写法见下面第 3 节。

## 3 流水灯的其他写法（进阶，理解位操作）

### 3.1 写法二：移位运算 + for 循环

用**左移运算** `<<` 和**按位取反** `~` 代替写死 8 个值：

```c
void main()
{
	unsigned char i;
	while(1)
	{
		for(i = 0; i < 8; i++)   // i 从 0 到 7
		{
			P2 = ~(0x01 << i);   // 0x01 左移 i 位再取反
			Delay500ms();
		}
	}
}
```

逐行拆解 `P2 = ~(0x01 << i);`：

```text
  i=0: 0x01<<0 = 0000 0001 → ~ 取反 = 1111 1110 = 0xFE（第 1 颗亮）
  i=1: 0x01<<1 = 0000 0010 → ~ = 1111 1101 = 0xFD（第 2 颗亮）
  i=2: 0x01<<2 = 0000 0100 → ~ = 1111 1011 = 0xFB（第 3 颗亮）
  ...
  i=7: 0x01<<7 = 1000 0000 → ~ = 0111 1111 = 0x7F（第 8 颗亮）
```

> [!note] `<<` 左移和 `~` 取反
> - `0x01 << i`：把 1 向左移 i 位（右边补 0）。
> - `~x`：按位取反（0 变 1，1 变 0）。因为"低电平点亮"，所以要先取反让"亮的位变 0"。
> - 这种写法更简洁，且**在第 3 章按键移位、第 7 章流水灯模式里会反复用到**，务必理解。

### 3.2 写法三：循环左移 `_crol_()`

用 `INTRINS.H` 里的**循环左移函数** `_crol_()`：

```c
#include <INTRINS.H>

void main()
{
	unsigned char temp = 0xFE;   // 初始：第 1 颗亮
	while(1)
	{
		P2 = temp;
		Delay500ms();
		temp = _crol_(temp, 1);   // 循环左移 1 位
	}
}
```

- `_crol_(temp, 1)` 把 temp 循环左移 1 位：最高位移到最低位（"循环"的意思）。
- `0xFE(1111 1110)` → 循环左移 → `0xFD(1111 1101)` → ... → `0x7F` → 又回到 `0xFE`。

> [!tip] 三种写法怎么选
> - 学习理解 → 官方写死版（2-3）最直观。
> - 代码简洁 → 移位+for（3.1）最通用，也是后面章节的主流写法。
> - 循环往复 → `_crol_()`（3.2）专门用于"循环"移动。
>
> 三种本质都是"让 0 的位置移动"，理解了底层位操作，三种都能看懂。

## 4 更进一步（2-4 Plus 版的思路）

官方还提供了 `2-4 LED流水灯Plus`，改用**带参数的延时函数**，让不同灯的延时不同（前面灯慢、后面灯快），制造"变速流水"效果：

```c
void Delay1ms(unsigned int xms)		//@12.000MHz，约 1ms 的基准延时
{
	unsigned char i, j;
	while(xms)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
		xms--;
	}
}
```

- `Delay1ms(1000)` ≈ 1 秒，`Delay1ms(100)` ≈ 0.1 秒。
- 带参数的延时函数比"写死 500ms"更灵活，是后面各章延时函数（`Delay(xms)`）的原型。第 3 章起官方源码的延时函数都统一成这种带参数的形式。

## 5 易错点

- [ ] 十六进制和二进制位对不上 → `0xFE` 是 `1111 1110`，不是 `1111 1111`。
- [ ] 忘了延时 → 所有 LED 看起来同时亮（变化太快人眼分辨不出）。
- [ ] 8 个值顺序写错 → 流水方向不对或不连续。
- [ ] 漏了 `while(1)` → 只跑一遍就停。
- [ ] `<<` 左移和 `~` 取反搞混 → `~(0x01<<i)` 里先移位再取反，顺序别反。
- [ ] 位编号和引脚对应错 → 位 0 对应 P2.0（第 1 颗），位 7 对应 P2.7（第 8 颗）。

## 6 自测

1. `0xDF` 对应二进制是多少？哪颗 LED 亮？
2. 流水灯的本质是什么（0 的位置如何变化）？
3. `Delay1ms(100)` 大约延时多久（12MHz）？
4. `P2 = ~(0x01 << 3);` 的结果是什么？哪颗 LED 亮？
5. `_crol_(0xFE, 1)` 的结果是多少？

> [!success]- 参考答案
> 1. `0xDF=1101 1111`，第 6 颗（P2.5）亮（0 在第 6 位）。
> 2. 本质是让"0"的位置从最低位逐步左移到最高位；0 所在位对应 LED 低电平点亮。
> 3. 约 0.1 秒（100 × 1ms）。
> 4. `0x01<<3 = 0000 1000`，取反 = `1111 0111 = 0xF7`，第 4 颗（P2.3）亮。
> 5. `0xFE(1111 1110)` 循环左移 1 位 = `1111 1101 = 0xFD`。
