# 02-3 LED 流水灯

> [!abstract] 这一集只解决一个问题
> **怎么让 8 颗 LED 依次点亮，形成"流水"效果？**
>
> 答：依次给 P2 端口赋 8 个不同的值（`0xFE → 0xFD → 0xFB → ... → 0x7F`），每个值之间加延时。每个值里"0"所在的那一位对应的 LED 亮，0 的位置逐步左移，就是流水灯。
>
> 上一集 [[江协51 02-2 LED闪烁]] ｜ 章索引 [[江协51 02 LED（章索引）]]

## 1 十六进制与二进制位

流水灯的核心是理解"一个十六进制数 = 8 个二进制位 = 8 颗 LED 的状态"：

| 赋值 | 二进制 | 亮的 LED（0 的位置） |
| --- | --- | --- |
| `0xFE` | 1111 1110 | 第 1 颗（P2.0） |
| `0xFD` | 1111 1101 | 第 2 颗（P2.1） |
| `0xFB` | 1111 1011 | 第 3 颗（P2.2） |
| `0xF7` | 1111 0111 | 第 4 颗（P2.3） |
| `0xEF` | 1110 1111 | 第 5 颗（P2.4） |
| `0xDF` | 1101 1111 | 第 6 颗（P2.5） |
| `0xBF` | 1011 1111 | 第 7 颗（P2.6） |
| `0x7F` | 0111 1111 | 第 8 颗（P2.7） |

- 规律：**0 从最低位逐步左移到最高位**。0 在哪一位，哪颗 LED 亮。
- `0xFE` 的 `F=1111`、`E=1110`，拼起来 `1111 1110`。

## 2 完整代码

```c
#include <REGX52.H>
#include <INTRINS.H>

void Delay500ms()		//@12.000MHz
{
	unsigned char i, j, k;

	_nop_();
	i = 4;
	j = 205;
	k = 187;
	do
	{
		do
		{
			while (--k);
		} while (--j);
	} while (--i);
}


void main()
{
	while(1)
	{
		P2=0xFE;//1111 1110
		Delay500ms();
		P2=0xFD;//1111 1101
		Delay500ms();
		P2=0xFB;//1111 1011
		Delay500ms();
		P2=0xF7;//1111 0111
		Delay500ms();
		P2=0xEF;//1110 1111
		Delay500ms();
		P2=0xDF;//1101 1111
		Delay500ms();
		P2=0xBF;//1011 1111
		Delay500ms();
		P2=0x7F;//0111 1111
		Delay500ms();
	}
}
```

> [!tip] 这种写法"笨"但有教学价值
> 官方 2-3 用的是"逐个写死 8 个值"的直白写法，好处是让新手一眼看清"0 在左移"。更优雅的写法是用 `_crol_()`（循环左移）或 `P2 = ~(0x01 << i)` 配合 for 循环，第 2-4 集（Plus 版）和第 7 章会用到。

## 3 更进一步（2-4 Plus 版的思路）

官方还提供了 `2-4 LED流水灯Plus`，改用**带参数的延时函数**，让不同灯的延时不同（前面灯慢、后面灯快），制造"变速流水"效果：

```c
void Delay1ms(unsigned int xms)		//@12.000MHz，约 1ms 的基准延时
{
	unsigned char i, j;
	while(xms)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
		xms--;
	}
}
```

- `Delay1ms(1000)` ≈ 1 秒，`Delay1ms(100)` ≈ 0.1 秒。
- 带参数的延时函数比"写死 500ms"更灵活，是后面各章延时函数（`Delay(xms)`）的原型。

## 4 易错点

- [ ] 十六进制和二进制位对不上 → `0xFE` 是 `1111 1110`，不是 `1111 1111`。
- [ ] 忘了延时 → 所有 LED 看起来同时亮（变化太快人眼分辨不出）。
- [ ] 8 个值顺序写错 → 流水方向不对或不连续。
- [ ] 漏了 `while(1)` → 只跑一遍就停。

## 5 自测

1. `0xDF` 对应二进制是多少？哪颗 LED 亮？
2. 流水灯的本质是什么（0 的位置如何变化）？
3. `Delay1ms(100)` 大约延时多久（12MHz）？

> [!success]- 参考答案
> 1. `0xDF=1101 1111`，第 6 颗（P2.5）亮（0 在第 6 位）。
> 2. 本质是让"0"的位置从最低位逐步左移到最高位；0 所在位对应 LED 低电平点亮。
> 3. 约 0.1 秒（100 × 1ms）。
