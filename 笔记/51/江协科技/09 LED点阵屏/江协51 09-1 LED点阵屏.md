# 09-1 LED 点阵屏

> [!abstract] 这一集只解决一个问题
> **怎么在 8×8 点阵屏上显示一个图形（如笑脸）？**
>
> 答：用 **74HC595 移位寄存器**串行把一列的 8 位亮灭数据送进去，再用 P0 选列逐列扫描，快速循环就显示出一个完整图形。
>

## 1 点阵屏结构

8×8 LED 点阵屏 = 8 行 × 8 列 = 64 颗 LED。显示图形就是**逐列扫描**：每列送一个 8 位数据（这列的 8 颗灯哪颗亮），快速扫过 8 列，利用视觉暂留看到完整图形。

```text
   列0  列1  列2  ...  列7
行0  ●    ○    ●        ○
行1  ○    ●    ○        ●
...
行7  ○    ●    ●        ○
```

## 2 74HC595 移位寄存器

64 颗灯不可能用 64 个 IO。**74HC595** 是"串入并出"移位寄存器：用 3 根线（数据+时钟）把 8 位数据**串行**移进去，再一次性**并行**输出 8 位，从而用 3 个 IO 控制 8 位输出。

### 2.1 "串入并出"的底层原理

74HC595 内部有一个**移位寄存器**（8 位）+ 一个**锁存寄存器**（8 位），分两级：

```text
  串行输入（SER）──► [移位寄存器 8 位] ──锁存(RCK)──► [锁存寄存器 8 位] ──► 8 位并行输出
                        ▲                                    │
                        │                                    │
                   移位时钟 SCK                          输出引脚 Q0~Q7
                  （每个脉冲移入 1 位）
```

- **移位阶段（SCK 时钟）**：每个 SCK 上升沿，SER 上的一位数据被"推进"移位寄存器，原来的数据整体右移一位。8 个脉冲后，8 位数据全部进入移位寄存器。
- **锁存阶段（RCK 时钟）**：一个 RCK 上升沿，把移位寄存器的 8 位内容"拷"到锁存寄存器，并并行输出到 Q0~Q7。

> [!note] 为什么要分"移位"和"锁存"两级
> 如果只有移位寄存器，那么移位的**过程中**输出会跟着一起变（数据一位位挪动，输出会"闪烁"）。分成两级后：
> 1. 先用 SCK 把 8 位数据安静地移进移位寄存器（此时输出不变，因为锁存器还锁着旧数据）。
> 2. 再用一个 RCK 脉冲"一次性"把完整的新数据输出。
>
> 这样输出就是干净的一整字节切换，不会出现中间状态。这是"串入并出"芯片的通用设计。

### 2.2 引脚定义

| 引脚 | 接 IO | 作用 |
| --- | --- | --- |
| SER | P3^4 | 串行数据输入 |
| SCK（SRCLK） | P3^6 | 移位时钟（上升沿移入 1 位） |
| RCK（RCLK） | P3^5 | 锁存时钟（上升沿把移位结果并行输出） |

```c
sbit RCK=P3^5;
sbit SCK=P3^6;
sbit SER=P3^4;
```

## 3 写一个字节

```c
void _74HC595_WriteByte(unsigned char Byte)
{
	unsigned char i;
	for(i=0;i<8;i++)
	{
		SER=Byte&(0x80>>i);  // 从最高位开始，逐位送到 SER
		SCK=1;               // 移位时钟上升沿
		SCK=0;               // 移入一位
	}
	RCK=1;                   // 锁存时钟上升沿
	RCK=0;                   // 把 8 位并行输出
}
```

- `Byte&(0x80>>i)`：`0x80>>i` 是"第 i 位（从最高位算）为 1"的掩码，从**最高位（MSB）**开始逐位取数据。
- 8 次 SCK 脉冲后，8 位数据已全部移入内部移位寄存器。
- 一次 RCK 脉冲，把移位寄存器的内容**并行**送到输出端。

> [!tip] 为什么从最高位（MSB）开始送
> 移位寄存器是"先进入的数据被推到后面"，如果从 MSB 开始送，最后 MSB 会落在最高输出位。这是 74HC595 的时序约定（高位在前，MSB-first）。送数据的方向必须和芯片约定一致，否则 8 位顺序会反。

## 4 逐列扫描显示图形

```c
#define MATRIX_LED_PORT  P0

void MatrixLED_ShowColumn(unsigned char Column,Data)
{
	_74HC595_WriteByte(Data);              // 送列数据（哪几行亮）
	MATRIX_LED_PORT=~(0x80>>Column);       // 选列（哪一列）
	Delay(1);                              // 显示 1ms
	MATRIX_LED_PORT=0xFF;                  // 消影
}
```

- `Data`：这一列 8 行的亮灭（高位在上，1 亮 0 灭）。
- `~(0x80>>Column)`：`0x80>>Column` 是"第 Column 位为 1"，取反后该位为 0 → 选中该列（低电平选列）。

## 5 完整代码（显示笑脸）

```c
void main()
{
	SCK=0;
	RCK=0;
	while(1)
	{
		MatrixLED_ShowColumn(0,0x3C);
		MatrixLED_ShowColumn(1,0x42);
		MatrixLED_ShowColumn(2,0xA9);
		MatrixLED_ShowColumn(3,0x85);
		MatrixLED_ShowColumn(4,0x85);
		MatrixLED_ShowColumn(5,0xA9);
		MatrixLED_ShowColumn(6,0x42);
		MatrixLED_ShowColumn(7,0x3C);
	}
}
```

- 8 列数据拼成一个笑脸图案。
- 每列显示 1ms，快速循环，视觉上就是稳定的笑脸。

## 6 易错点

- [ ] 74HC595 三线接错 → SER/SCK/RCK 顺序不能乱。
- [ ] 数据方向反 → 用 `0x80>>i` 从高位送，别用 `0x01<<i`。
- [ ] 列选忘了消影 → 重影。
- [ ] `Column` 范围 0~7 → 传 8 会越界。

## 7 自测

1. 74HC595 的"串入并出"是什么意思？
2. `Byte&(0x80>>i)` 为什么要从最高位送？
3. `~(0x80>>Column)` 实现什么？

> [!success]- 参考答案
> 1. 数据一位一位串行移入，最后一次性并行输出 8 位，用 3 个 IO 控制 8 位输出。
> 2. 因为移位寄存器从高位（MSB）开始移入，所以要先取最高位送。
> 3. 产生"第 Column 位为 0"的值，低电平选中第 Column 列。
