## 本章速查

### 点阵屏引脚

- 74HC595 三线：`SER=P3^4`（数据）、`SCK=P3^6`（移位时钟）、`RCK=P3^5`（锁存时钟）。
- 列选（逐列扫描）：`P0` 口，`MATRIX_LED_PORT=~(0x80>>Column)` 选第 Column 列。

### 74HC595 写字节

```c
void _74HC595_WriteByte(unsigned char Byte)
{
	unsigned char i;
	for(i=0;i<8;i++)
	{
		SER=Byte&(0x80>>i);  // 从最高位开始送
		SCK=1;               // 上升沿移入一位
		SCK=0;
	}
	RCK=1;                   // 锁存：并行输出
	RCK=0;
}
```

> [!tip] 记这一章最省力的办法
> 点阵屏 = **74HC595 串行送"哪几颗亮"（列数据）+ P0 选"哪一列"（列扫描）**。74HC595 记住三线：SER 送数据、SCK 移一位、RCK 锁存输出。动画就是"多帧数组 + 偏移换帧"。

## 全章统一易错点

- [ ] 74HC595 三线接错 → SER/SCK/RCK 顺序别乱。
- [ ] 数据送反 → `0x80>>i` 是从高位送，别用 `0x01<<i`（那是低位先送）。
- [ ] 列选忘了消影/延时 → 显示重影。
- [ ] 动画偏移越界 → Offset 超过数组长度要归 0。
