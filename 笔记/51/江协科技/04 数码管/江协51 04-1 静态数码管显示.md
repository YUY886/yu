# 04-1 静态数码管显示

> [!abstract] 这一集只解决一个问题
> **怎么让数码管在指定位置显示一个数字？**
>
> 答：分两步——**位码**（P2_2/P2_3/P2_4 经 74HC138 译码）选"第几位"，**段码**（P0 输出段码表里的值）决定"显示什么数字"。
>
> 下一集 [[江协51 04-2 动态数码管显示]] ｜ 章索引 [[江协51 04 数码管（章索引）]]

## 1 数码管是什么

数码管（Nixie tube / 七段数码管）由 8 个 LED 段组成：a、b、c、d、e、f、g 七段组成数字，外加小数点 dp。

```text
     a
    ───
 f │   │ b
    ───   ← g
 e │   │ c
    ───
     d    · dp
```

- 显示"1"就是点亮 b、c 两段；显示"8"就是 a~g 全亮。
- **共阴极**数码管：所有段的阴极接一起（接地），给某段阳极高电平就点亮该段。

## 2 段码表

每一段的亮灭对应一个二进制位，8 段拼成一个字节，这就是**段码**：

| 数字 | 段码（共阴） | 二进制（dp g f e d c b a） |
| --- | --- | --- |
| 0 | 0x3F | 0011 1111 |
| 1 | 0x06 | 0000 0110 |
| 2 | 0x5B | 0101 1011 |
| 3 | 0x4F | 0100 1111 |
| 4 | 0x66 | 0110 0110 |
| 5 | 0x6D | 0110 1101 |
| 6 | 0x7D | 0111 1101 |
| 7 | 0x07 | 0000 0111 |
| 8 | 0x7F | 0111 1111 |
| 9 | 0x6F | 0110 1111 |

```c
unsigned char NixieTable[]={0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F};
```

> [!tip] 段码不用死记，理解就能推
> 记住 a=第0位、b=第1位、…、dp=第7位。想显示"2"就是 a,b,g,e,d 亮 → 位 0,1,6,4,3 为 1 → `0101 1011 = 0x5B`。理解了就能自己算，不用背表。

## 3 位码与 74HC138

开发板有 8 个数码管位，用 **74HC138（3-8 译码器）** 把 3 根 IO（P2_2/P2_3/P2_4）译码成 8 个位选，节省 IO。

| Location | P2_4 | P2_3 | P2_2 | 选中的位 |
| --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 1 | 第 1 位 |
| 2 | 1 | 1 | 0 | 第 2 位 |
| 3 | 1 | 0 | 1 | 第 3 位 |
| 4 | 1 | 0 | 0 | 第 4 位 |
| 5 | 0 | 1 | 1 | 第 5 位 |
| 6 | 0 | 1 | 0 | 第 6 位 |
| 7 | 0 | 0 | 1 | 第 7 位 |
| 8 | 0 | 0 | 0 | 第 8 位 |

> [!note] 74HC138 是"3 线选 8 线"
> 74HC138 是 3-8 译码器：3 个输入（A/B/C）对应 8 个输出（Y0~Y7），每次只有一个输出有效（低电平）。用 3 根 IO 代替 8 根 IO 来选位，这是典型的"译码复用"。

## 4 完整代码

```c
#include <REGX52.H>

//数码管段码表
unsigned char NixieTable[]={0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F};

//数码管显示子函数
void Nixie(unsigned char Location,Number)
{
	switch(Location)		//位码输出
	{
		case 1:P2_4=1;P2_3=1;P2_2=1;break;
		case 2:P2_4=1;P2_3=1;P2_2=0;break;
		case 3:P2_4=1;P2_3=0;P2_2=1;break;
		case 4:P2_4=1;P2_3=0;P2_2=0;break;
		case 5:P2_4=0;P2_3=1;P2_2=1;break;
		case 6:P2_4=0;P2_3=1;P2_2=0;break;
		case 7:P2_4=0;P2_3=0;P2_2=1;break;
		case 8:P2_4=0;P2_3=0;P2_2=0;break;
	}
	P0=NixieTable[Number];	//段码输出
}

void main()
{
	Nixie(2,3);	//在数码管的第2位置显示3
	while(1)
	{
		
	}
}
```

- `Nixie(Location, Number)`：在 Location 位显示 Number 数字。
- `switch(Location)` 选位码，`P0=NixieTable[Number]` 送段码。

## 5 易错点

- [ ] 段码表索引和数字对不上 → `NixieTable[3]` 是显示"3"（0x4F），不是第 3 位。
- [ ] 位码/段码顺序反了 → 先选位再送段码（先 Location 后 Number）。
- [ ] 段码 0x3F 等记错 → 共阴数码管"0"是 0x3F，不是 0xC0（那是共阳）。
- [ ] Location 范围 1~8 → 传 0 或 9 会没 case 匹配，位码不确定。

## 6 自测

1. 显示数字"5"的段码是多少？为什么？
2. 位码和段码分别由哪些引脚控制？
3. `Nixie(2,3)` 实现什么效果？

> [!success]- 参考答案
> 1. 0x6D（0110 1101），即 a、c、d、f、g 五段点亮。
> 2. 位码由 P2_2/P2_3/P2_4（经 74HC138 译码）控制，段码由 P0 输出。
> 3. 在数码管第 2 位显示数字 3。
