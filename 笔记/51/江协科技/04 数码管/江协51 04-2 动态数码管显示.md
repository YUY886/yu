# 04-2 动态数码管显示

> [!abstract] 这一集只解决一个问题
> **怎么让多个数码管"同时"显示不同的数字？**
>
> 答：利用**视觉暂留**，快速轮流点亮每一位（每显示一位延时 1ms 就换下一位），人眼看起来就像同时显示。关键在两点：**快速扫描** + **消影**。
>
> 上一集 [[江协51 04-1 静态数码管显示]] ｜ 章索引 [[江协51 04 数码管（章索引）]]

## 1 为什么需要动态扫描

静态显示（4-1）一次只能让**一个位置**显示一个数字（选位后段码固定）。要显示"123"三个数字，不能同时给三个位送不同的段码——因为**段码总线 P0 只有一路**，同一时刻只能输出一个数字的段码。

解决办法：**轮流显示**——第 1 位显示"1"、第 2 位显示"2"、第 3 位显示"3"，每步只停留约 1ms，飞快循环。

```text
  第1位显示1 →(1ms)→ 第2位显示2 →(1ms)→ 第3位显示3 →(1ms)→ 循环
```

### 1.1 视觉暂留原理

人眼看到的图像不会立刻消失，会**残留约 0.1 秒**（视觉暂留 / 视觉惰性）。当数码管每 1ms 切换一位、三个位一轮约 3ms 时：

- 切换速度（约 333 次/秒）远快于人眼的暂留时间（0.1s）。
- 人眼分不出快速切换，看到的是"三个位都在亮"→ 视觉上"同时显示 123"。

> [!note] 这和电影/动画是同一个原理
> 电影每秒 24 帧、动画每秒 30 帧，都是利用视觉暂留让"快速切换的静止画面"看起来连续。动态扫描就是把"8 个数码管"当成"8 帧画面"快速轮播。

## 2 消影（消除鬼影）

切换位时有个隐患：**上一次的段码还残留在 P0 上**，切到下一位瞬间，新位会短暂显示旧的段码，产生"鬼影"（重影）。

```text
  正常：  第1位显示1 → 第2位显示2 → 第3位显示3
  有鬼影：第1位显示1 → 第2位先显示1(残留)再显示2 → ...
                        ↑ 这段"1"就是鬼影
```

- 鬼影的电路原因：P0 是**共享的段码总线**，切位时如果 P0 还是上一个数字的段码，新选中的位会立刻把这个"旧段码"亮出来，形成短暂的重影。

解决办法是**消影**：每显示完一位，先把段码清零（`P0=0x00` 全灭），再切下一位：

```c
P0=NixieTable[Number];	// 送段码
Delay(1);				// 显示 1ms
P0=0x00;				// 段码清零，消影（熄灭后再切位）
```

> [!tip] 消影的本质是"先灭再切"
> 正确的切换顺序是：**送段码 → 显示 → 关段码（全灭）→ 切位 → 送下一段码**。关键是在"切位"之前先把段码关掉，这样新位点亮时不会有旧段码残留。

## 3 完整代码

```c
#include <REGX52.H>

//数码管段码表
unsigned char NixieTable[]={0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F};

//延时子函数
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}

//数码管显示子函数
void Nixie(unsigned char Location,Number)
{
	switch(Location)		//位码输出
	{
		case 1:P2_4=1;P2_3=1;P2_2=1;break;
		case 2:P2_4=1;P2_3=1;P2_2=0;break;
		case 3:P2_4=1;P2_3=0;P2_2=1;break;
		case 4:P2_4=1;P2_3=0;P2_2=0;break;
		case 5:P2_4=0;P2_3=1;P2_2=1;break;
		case 6:P2_4=0;P2_3=1;P2_2=0;break;
		case 7:P2_4=0;P2_3=0;P2_2=1;break;
		case 8:P2_4=0;P2_3=0;P2_2=0;break;
	}
	P0=NixieTable[Number];	//段码输出
	Delay(1);				//显示一段时间
	P0=0x00;				//段码清0，消影
}

void main()
{
	while(1)
	{
		Nixie(1,1);		//在数码管的第1位置显示1
		Nixie(2,2);		//在数码管的第2位置显示2
		Nixie(3,3);		//在数码管的第3位置显示3
	}
}
```

- `Nixie()` 里已经内建了 `Delay(1)` 和消影，所以 main 里连续调用三个 `Nixie` 就能实现动态扫描。
- 三个位轮流显示，人眼看到"123"。

> [!note] 消影代码加在 Nixie 函数里
> 注意 4-2 的 `Nixie()` 比 4-1 多了两行：`Delay(1)` 和 `P0=0x00`（消影）。这就是动态和静态显示在代码上的唯一区别。

## 4 易错点

- [ ] 忘了消影 → 出现鬼影/重影。
- [ ] 延时太长（如 Delay(100)）→ 明显闪烁，不像同时显示。
- [ ] 延时太短 → 重影（切换太快）。
- [ ] main 里漏了 while(1) → 只扫一遍就停，显示不全。

## 5 自测

1. 动态扫描为什么能"同时"显示多个数字？
2. 消影解决什么问题？怎么做？
3. 动态扫描的延时常取多少？为什么不能太长或太短？

> [!success]- 参考答案
> 1. 利用人眼视觉暂留：快速轮流点亮各位（约 1ms/位），人眼分不出快速切换，看起来像同时显示。
> 2. 消影解决切换位时"旧段码残留导致鬼影"的问题；做法是每显示一位后 `P0=0x00` 清零段码再切下一位。
> 3. 约 1ms。太长会闪烁，太短会出现重影。
