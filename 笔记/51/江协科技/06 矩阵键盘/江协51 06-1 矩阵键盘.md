# 06-1 矩阵键盘

> [!abstract] 这一集只解决一个问题
> **怎么用 8 个 IO 实现 16 个按键？**
>
> 答：用**矩阵键盘**——把 16 个按键排成 4×4 网格，4 根行线 + 4 根列线。用"行列扫描"法：逐行拉低、逐列读取，判断哪个交叉点的按键被按下，返回键码 1~16。
>
> 下一集 [[江协51 06-2 矩阵键盘密码锁]] ｜ 章索引 [[江协51 06 矩阵键盘（章索引）]]

## 1 为什么用矩阵键盘

独立按键（第 3 章）一个按键占一个 IO，16 个按键就要 16 个 IO。矩阵键盘把按键排成行列，**4 行 + 4 列只用 8 个 IO** 就能接 16 个按键（行×列）。

```text
        列0      列1      列2      列3
         │        │        │        │
行0 ──┬──┴──┬──┴──┬──┴──┬──┴──
      S1     S5     S9     S13
行1 ──┬──┴──┬──┴──┬──┴──┬──┴──
      S2     S6     S10    S14
行2 ──┬──┴──┬──┴──┬──┴──┬──┴──
      S3     S7     S11    S15
行3 ──┬──┴──┬──┴──┬──┴──┬──┴──
      S4     S8     S12    S16
```

### 1.1 省 IO 的本质：复用

矩阵键盘省 IO 的本质，和数码管的 74HC138 译码一样，是**"复用"思想**：

```text
  独立按键：16 个按键 → 16 根线（1 键 1 线）
  矩阵键盘：16 个按键 → 4 行 + 4 列 = 8 根线（每个按键接在"一行一列"的交叉点）
```

- 每个按键不在单独一根线上，而是接在**某一行和某一列的交叉点**。
- 判断"哪个键按下" = 判断"哪一行 + 哪一列"——行列组合出 4×4=16 种可能。
- 这和"4 位二进制表示 16 个数"是同一个道理：**用 N 根线表达 N² 个状态**。

> [!note] 为什么不能一次读所有键
> 矩阵键盘的缺点是**不能同时检测多个按键**（会有"鬼键/重影"问题，多个键同时按会误判）。但对"密码锁"这种一次只按一个键的场景，矩阵键盘完全够用，且大幅省 IO。

## 2 引脚与键码布局

矩阵键盘接 **P1 口**：

- **行**（扫描输出）：P1_3、P1_2、P1_1、P1_0（行 0~3）
- **列**（读取输入）：P1_7、P1_6、P1_5、P1_4（列 0~3）

键码（KeyNumber）返回 1~16，布局：

| | 列0(P1_7) | 列1(P1_6) | 列2(P1_5) | 列3(P1_4) |
| --- | --- | --- | --- | --- |
| 行0(P1_3) | 1 | 5 | 9 | 13 |
| 行1(P1_2) | 2 | 6 | 10 | 14 |
| 行2(P1_1) | 3 | 7 | 11 | 15 |
| 行3(P1_0) | 4 | 8 | 12 | 16 |

## 3 行列扫描原理

核心逻辑：**逐行拉低，读列判断**。

### 3.1 电路上的分析

矩阵键盘的按键，一端接行线、一端接列线。按下时，行线和列线**导通**：

```text
        列线 P1_7（输入，内部上拉=1）
         │
  按键 S1 ──┐（按下时，行线和列线连通）
         │
        行线 P1_3（输出）
```

- **行线是输出**：扫描时把某一行拉低（写 0），其余行保持 1。
- **列线是输入**：读列线电平，如果某列为 0，说明这一列被"按下"的按键拉低了。

具体步骤：

1. 先把 P1 全写 1（`P1=0xFF`）。
2. 让第 0 行输出 0（`P1_3=0`），其余行保持 1。
3. 读 4 个列：如果某列为 0，说明第 0 行和该列交叉的按键被按下（按键把这一列拉低）。
4. 换下一行，重复。

> [!note] 为什么"拉低行、读列"就能定位按键
> 当第 0 行被拉低（=0）、其余行=1 时：
> - 若 S1 按下 → S1 把行 0 和列 0 连通 → 列 0（P1_7）被拉到 0。
> - 若 S5 按下 → 列 1（P1_6）被拉到 0。
> - 若这行没有按键按下 → 4 个列都被内部上拉保持 1。
>
> 所以"读哪列为 0"就能判断"这一行哪一列的键被按下"。逐行扫完，就能覆盖全部 16 个键。

```c
unsigned char MatrixKey()
{
	unsigned char KeyNumber=0;
	
	P1=0xFF;
	P1_3=0;   // 扫描第 0 行
	if(P1_7==0){Delay(20);while(P1_7==0);Delay(20);KeyNumber=1;}  // S1
	if(P1_6==0){Delay(20);while(P1_6==0);Delay(20);KeyNumber=5;}  // S5
	if(P1_5==0){Delay(20);while(P1_5==0);Delay(20);KeyNumber=9;}  // S9
	if(P1_4==0){Delay(20);while(P1_4==0);Delay(20);KeyNumber=13;} // S13
	
	// ... 依次扫描 P1_2、P1_1、P1_0 三行 ...
	
	return KeyNumber;
}
```

> [!note] 消抖和松手检测已内建
> 注意每个 `if(P1_x==0)` 里都带了 `Delay(20); while(P1_x==0); Delay(20);`，说明矩阵键盘的消抖 + 松手检测**封装在 MatrixKey 函数内部**，main 里直接调用即可，不用再写一遍。

## 4 完整代码

### MatrixKey.c（核心函数）

```c
#include <REGX52.H>
#include "Delay.h"

unsigned char MatrixKey()
{
	unsigned char KeyNumber=0;
	
	P1=0xFF;
	P1_3=0;
	if(P1_7==0){Delay(20);while(P1_7==0);Delay(20);KeyNumber=1;}
	if(P1_6==0){Delay(20);while(P1_6==0);Delay(20);KeyNumber=5;}
	if(P1_5==0){Delay(20);while(P1_5==0);Delay(20);KeyNumber=9;}
	if(P1_4==0){Delay(20);while(P1_4==0);Delay(20);KeyNumber=13;}
	
	P1=0xFF;
	P1_2=0;
	if(P1_7==0){Delay(20);while(P1_7==0);Delay(20);KeyNumber=2;}
	if(P1_6==0){Delay(20);while(P1_6==0);Delay(20);KeyNumber=6;}
	if(P1_5==0){Delay(20);while(P1_5==0);Delay(20);KeyNumber=10;}
	if(P1_4==0){Delay(20);while(P1_4==0);Delay(20);KeyNumber=14;}
	
	P1=0xFF;
	P1_1=0;
	if(P1_7==0){Delay(20);while(P1_7==0);Delay(20);KeyNumber=3;}
	if(P1_6==0){Delay(20);while(P1_6==0);Delay(20);KeyNumber=7;}
	if(P1_5==0){Delay(20);while(P1_5==0);Delay(20);KeyNumber=11;}
	if(P1_4==0){Delay(20);while(P1_4==0);Delay(20);KeyNumber=15;}
	
	P1=0xFF;
	P1_0=0;
	if(P1_7==0){Delay(20);while(P1_7==0);Delay(20);KeyNumber=4;}
	if(P1_6==0){Delay(20);while(P1_6==0);Delay(20);KeyNumber=8;}
	if(P1_5==0){Delay(20);while(P1_5==0);Delay(20);KeyNumber=12;}
	if(P1_4==0){Delay(20);while(P1_4==0);Delay(20);KeyNumber=16;}
	
	return KeyNumber;
}
```

### main.c

```c
#include <REGX52.H>
#include "Delay.h"
#include "LCD1602.h"
#include "MatrixKey.h"

unsigned char KeyNum;

void main()
{
	LCD_Init();
	LCD_ShowString(1,1,"MatrixKey:");
	while(1)
	{
		KeyNum=MatrixKey();			//获取矩阵键盘键码
		if(KeyNum)					//如果有按键按下
		{
			LCD_ShowNum(2,1,KeyNum,2);	//LCD显示键码
		}
	}
}
```

## 5 易错点

- [ ] 行列方向搞反 → 行是输出（P1_3~P1_0），列是输入（P1_7~P1_4）。
- [ ] 扫描前漏了 `P1=0xFF` → 端口残留导致误判。
- [ ] 键码值记错 → 键码按"列优先"递增：同列键码差 4（1,5,9,13）。
- [ ] `if(KeyNum)` 判断漏了 → 没按键时 KeyNum=0，直接显示会刷屏。

## 6 自测

1. 矩阵键盘为什么能用 8 个 IO 接 16 个按键？
2. 行列扫描的"行"和"列"分别是输入还是输出？
3. 键码 10 对应哪个按键（第几行第几列）？

> [!success]- 参考答案
> 1. 因为按键按 4×4 行列排列，行×列=16，只需 4 行 + 4 列 = 8 个 IO。
> 2. 行是输出（拉低扫描），列是输入（读取判断）。
> 3. 键码 10 在第 1 行第 2 列（S10），对应 P1_2 行、P1_5 列。
