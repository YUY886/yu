# 06-2 矩阵键盘密码锁

> [!abstract] 这一集只解决一个问题
> **怎么用矩阵键盘做一个密码锁？**
>
> 答：把 16 个键码分成三类——数字键（S1~S10，输入密码）、确认键（S11）、取消键（S12）。用 `Password*10+数字` 累积输入，确认时和正确密码比较，显示 OK/ERR。
>
> 上一集 [[江协51 06-1 矩阵键盘]] ｜ 章索引 [[江协51 06 矩阵键盘（章索引）]]

## 1 键码分类

16 个键码在本集被赋予不同角色：

| 键码 | 按键 | 角色 |
| --- | --- | --- |
| 1~10 | S1~S10 | 数字键（对应 0~9，`KeyNum%10` 取个位） |
| 11 | S11 | 确认键 |
| 12 | S12 | 取消键 |
| 13~16 | S13~S16 | 未使用 |

## 2 密码累积逻辑

输入密码的核心是**十进制左移一位 + 追加一位**：

```c
Password *= 10;        // 密码整体左移一位（如 23 → 230）
Password += KeyNum%10; // 追加当前按的数字（如 230 + 4 = 234）
```

- `KeyNum%10`：键码 1~10 取个位，映射成数字 1~9、0（10%10=0）。
- 每输入一位，密码向左移一位腾出个位，再加新数字。

## 3 完整代码

```c
#include <REGX52.H>
#include "Delay.h"
#include "LCD1602.h"
#include "MatrixKey.h"

unsigned char KeyNum;
unsigned int Password,Count;

void main()
{
	LCD_Init();
	LCD_ShowString(1,1,"Password:");
	while(1)
	{
		KeyNum=MatrixKey();
		if(KeyNum)
		{
			if(KeyNum<=10)	//如果S1~S10按键按下，输入密码
			{
				if(Count<4)	//如果输入次数小于4
				{
					Password*=10;				//密码左移一位
					Password+=KeyNum%10;		//获取一位密码
					Count++;	//计次加一
				}
				LCD_ShowNum(2,1,Password,4);	//更新显示
			}
			if(KeyNum==11)	//如果S11按键按下，确认
			{
				if(Password==2345)	//如果密码等于正确密码
				{
					LCD_ShowString(1,14,"OK ");	//显示OK
					Password=0;
					Count=0;
					LCD_ShowNum(2,1,Password,4);
				}
				else				//否则
				{
					LCD_ShowString(1,14,"ERR");	//显示ERR
					Password=0;
					Count=0;
					LCD_ShowNum(2,1,Password,4);
				}
			}
			if(KeyNum==12)	//如果S12按键按下，取消
			{
				Password=0;		//密码清零
				Count=0;		//计次清零
				LCD_ShowNum(2,1,Password,4);
			}
		}
	}
}
```

## 4 关键点解析

- **`Count<4` 限制位数**：密码最多 4 位（正确密码 2345 是 4 位），输入超过 4 位就不再累积。
- **正确密码是 2345**：`if(Password==2345)`，这是写死的默认密码。
- **确认后清空**：无论对错，确认后 `Password=0; Count=0`，准备下一次输入。
- **显示位置**：`LCD_ShowNum(2,1,Password,4)` 在第 2 行显示 4 位密码；结果 OK/ERR 显示在第 1 行第 14 列。

## 5 易错点

- [ ] `KeyNum%10` 忘写 → 键码 10 会直接当成 10 累加，数字错乱。
- [ ] `Password*=10` 漏了 → 数字不会左移，多位数无法累积。
- [ ] 忘了限制 `Count<4` → 可无限输入，超出显示宽度。
- [ ] 确认后没清空 → 下次输入会接着上次的密码。
- [ ] 正确密码改错 → 本集默认 2345，改的话要同步改判断。

## 6 自测

1. `Password*=10; Password+=KeyNum%10;` 这两句实现了什么？
2. 为什么键码 10 要 `%10`（变成 0）？
3. `Count<4` 的作用是什么？

> [!success]- 参考答案
> 1. 实现"十进制左移一位再追加一位"：每次输入把旧密码左移一位，个位腾出来加新数字，从而累积成多位数。
> 2. 因为键码 10（S10）代表数字 0，`10%10=0` 才能正确映射成数字 0。
> 3. 限制密码最多 4 位，防止无限输入超出显示宽度。
