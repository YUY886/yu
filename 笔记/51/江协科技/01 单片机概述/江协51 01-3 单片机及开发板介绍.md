# 01-3 单片机及开发板介绍

> [!abstract] 这一集只解决一个问题
> **单片机这颗芯片内部长什么样、它是怎么工作的？**
>
> 一句话：单片机 = **CPU + 存储器（ROM 存程序 / RAM 存数据）+ 特殊功能寄存器（SFR，控制外设的开关）+ IO 端口（P0~P3）**。程序烧进 ROM，CPU 一条条取指执行，通过 IO 口读写外设，通过 SFR 控制定时器、串口等内部外设。
>
> 这一集是整门课的**地基**：后面每一章"为什么这么写寄存器""为什么变量要放对地方"，答案都在这一集。
>
> 上一集 [[江协51 01-2 开发工具介绍及软件安装]] ｜ 章索引 [[江协51 01 单片机概述（章索引）]]

## 1 单片机的内部结构

一颗 51 单片机芯片，从外到内可以分成几层：

```text
                          ┌────────────────────────────────────┐
                          │           STC89C52 芯片内部           │
   ┌──────────┐           │                                    │
   │  外部晶振  │──► 振荡器 ─┼─► 时钟节拍（每个机器周期 = 12 个振荡周期）│
   └──────────┘           │                                    │
                          │   ┌────────────┐                    │
   ┌──────────┐           │   │    CPU      │  8 位内核          │
   │  复位电路  │──► 复位 ───┼─►│ (8051内核)  │                    │
   └──────────┘           │   └─────┬──────┘                    │
                          │         │ 内部总线                    │
                          │  ┌──────┴───────────────────────┐   │
                          │  │ 存储器         SFR（特殊功能寄存器）│   │
                          │  │ ROM(8KB Flash)  P0~P3/TMOD/TCON… │   │
                          │  │ RAM(512B)      定时器/串口/中断…   │   │
                          │  └────────────────────────────────┘   │
                          │              │                        │
                          └──────────────┼────────────────────────┘
                                         │
                              P0~P3 四组 IO 引脚（引出到芯片 40 个脚）
```

几个关键点：

- **CPU 是 8 位内核**：一次能处理 8 位（一个字节）数据。所以 51 里最常用的变量类型是 `unsigned char`（占 1 字节，正好 8 位）。
- **振荡器 + 晶振**产生时钟节拍，CPU 靠它"一步一步"走。51 的指令执行以**机器周期**为单位，一个机器周期 = 12 个振荡周期（12 分频）。晶振 12MHz 时，一个机器周期 = 1μs——这是后面所有延时、定时器初值计算的根基。
- **内部总线**把 CPU、存储器、SFR 连在一起，CPU 通过总线读写它们。
- **SFR（特殊功能寄存器）** 是整门课的核心：它是一组特殊的"存储单元"，每个都有特定地址，往里面写值就能控制对应的外设。

> [!tip] 一个核心心智模型：一切皆寄存器
> 51 单片机没有操作系统、没有库函数包装，你写的每一句代码，本质都是**读写某个寄存器**。点灯 = 写 `P2` 寄存器；延时 = 数循环；定时 = 写 `TMOD/TH0/TL0`。把"SFR 是控制外设的开关"这个模型立住，整门课就通了。

## 2 存储器结构：哈佛结构

51 单片机采用**哈佛结构（Harvard Architecture）**——程序存储器和数据存储器**物理上分开、地址空间独立**：

```text
                哈佛结构（51）
                ┌──────────────────────────────┐
   程序存储器     │   ROM / Flash                │  存程序代码
  （代码空间）    │   8KB（STC89C52RC）           │  掉电不丢失
                │   地址独立：0x0000 ~ 0x1FFF    │
                ├──────────────────────────────┤
   数据存储器     │   RAM                        │  存运行时变量、堆栈
  （数据空间）    │   512B（256B 内部 RAM + 256B 扩展）│  掉电丢失
                │   地址独立：0x00 ~ 0xFF 等      │
                └──────────────────────────────┘
```

对比两种结构：

| | 哈佛结构（51/STM32） | 冯·诺依曼结构（PC） |
| --- | --- | --- |
| 程序与数据存储 | **分开**，两条独立总线 | 合并，共用一条总线 |
| 能否同时取指和取数 | 能（并行） | 不能（分时复用总线） |
| 典型代表 | 51、STM32、DSP | 通用 PC、x86 |

> [!note] ROM vs RAM，一句话分清
> **ROM（Flash）存程序**，烧进去后掉电还在，因为它是 Flash 存储器；**RAM 存变量**，断电就清空，因为它是易失性存储。你写的 `unsigned char LEDNum=0;` 这个变量就放在 RAM 里，程序代码本身放在 ROM（Flash）里。

### 2.1 程序存储器的入口地址

51 单片机**复位后，程序计数器 PC 从 0x0000 开始取指**，所以：

- 复位电路一动作，程序就从 ROM 的 0x0000 地址开始从头执行。
- 这也是为什么"复位"能让程序重新跑一遍。

## 3 特殊功能寄存器 SFR

**SFR（Special Function Register，特殊功能寄存器）** 是 51 单片机的核心控制接口。它本质上是一段**有特定地址的存储单元**，每个 SFR 对应一个外设功能。

```text
  写程序：                   芯片内部：
  ┌──────────┐   写值     ┌──────────────┐
  │  P2 = 0xFE │ ────────► │ SFR: P2      │ ──► IO 引脚 P2.0~P2.7
  │            │           │ (地址 0xA0)   │      输出电平
  └──────────┘           └──────────────┘
  ┌──────────┐   写值     ┌──────────────┐
  │ TMOD=0x01 │ ────────► │ SFR: TMOD    │ ──► 定时器 0 设为方式 1
  └──────────┘           │ (地址 0x89)   │
                          └──────────────┘
```

几个必须理解的点：

- **SFR 有固定地址**，分布在 RAM 地址空间的 0x80~0xFF 区域。头文件 `REGX52.H` 里已经用 `sfr` 关键字把这些地址和名字绑定好了，所以你写 `P2` 编译器就知道是地址 0xA0。
- **SFR 分为"可位寻址"和"不可位寻址"两类**：
  - 可位寻址的（如 `P0`、`TCON`、`SCON`、`IE`）：能单独操作某一位，用 `sbit` 定义位名（如 `sbit LED = P1^2;`）。
  - 不可位寻址的（如 `TMOD`、`SBUF`、`TH0`）：只能整体读写，不能 `sbit` 单独操作某一位。

### 3.1 REGX52.H 头文件做了什么

每次写程序开头都有 `#include <REGX52.H>`。这个头文件里主要干了两件事：

1. **用 `sfr` 定义所有 SFR 的名字**：`sfr P0 = 0x80;`、`sfr P1 = 0x90;` 等，把寄存器名和地址绑定。
2. **用 `sbit` 定义可位寻址 SFR 的位名**：如 `sbit P1_2 = P1^2;`，让你能直接写 `P1_2 = 0;` 而不必写 `P1 &= ~0x04;`。

> [!warning] 不包含头文件会怎样
> 没有 `#include <REGX52.H>`，编译器不认识 `P2`、`P1_2`、`TMOD` 这些符号，会报"未定义标识符"错误。头文件不是可选的，是必须的。

## 4 IO 端口：P0~P3

51 单片机最核心的资源是 **4 组 8 位并行 IO 口**，共 32 个可编程引脚。这是 CPU 与外界交互的唯一通道。

| 端口 | 引脚数 | 内部上拉 | 特殊之处 |
| --- | --- | --- | --- |
| P0 | 8 | **无（开漏）** | 作普通 IO 需外接上拉；兼作低 8 位地址/数据总线 |
| P1 | 8 | 有 | 纯普通 IO，无第二功能 |
| P2 | 8 | 有 | 兼作高 8 位地址总线 |
| P3 | 8 | 有 | 每位都有第二功能（RXD/TXD/INT0/INT1/T0/T1/RD/WR） |

### 4.1 P0 口为什么"特殊"

P0 口内部**没有上拉电阻**，是**开漏结构**。这意味着：

- P0 口输出高电平时，如果**没有外接上拉电阻**，引脚是"浮空"的，得不到稳定的 5V。
- 所以开发板上用 P0 驱动数码管段码时，往往接了上拉电阻（或利用数码管本身的结构）。
- P1/P2/P3 内部自带弱上拉，输出高电平能直接到 5V，当普通 IO 更方便。

> [!note] 准双向口
> 51 的 IO 口（尤其 P1/P2/P3）是**准双向口（quasi-bidirectional）**：输出 1 时靠内部弱上拉拉高，输出 0 时靠内部强下拉拉低。读引脚之前，通常要先输出 1，让引脚处于"释放"状态，才能正确读到外部输入电平。这个细节在第 3 章按键里会体现。

### 4.2 P3 口的第二功能

P3 口每个引脚都有一个"兼职"，后面章节会逐个用到：

| P3 引脚 | 第二功能 | 含义 | 用到它的章节 |
| --- | --- | --- | --- |
| P3.0 / P3.1 | RXD / TXD | 串口接收 / 发送 | 第 8 章串口 |
| P3.2 / P3.3 | INT0 / INT1 | 外部中断 0 / 1 | 第 7 章中断 |
| P3.4 / P3.5 | T0 / T1 | 定时器 0 / 1 外部计数输入 | 第 7 章定时器 |
| P3.6 / P3.7 | WR / RD | 外部存储器写 / 读 | 本课基本不用 |

> [!tip] 第二功能 vs 普通 IO 怎么切换
> 当你用串口时，P3.0/P3.1 自动被串口外设接管，不能再当普通 IO；当你没用串口时，它们就是普通 IO。这是硬件自动的，不需要额外配置（区别于 STM32 需要显式配复用模式）。

## 5 开发板（普中 HC6800-ES V2.0）外设接线

课程所有实验都基于这张接线表（已对照官方源码逐条核对）：

| 外设 | 引脚 | 说明 | 涉及章节 |
| --- | --- | --- | --- |
| LED（8 个） | P2_0 ~ P2_7 | 低电平点亮（阳极接 5V，阴极接 IO） | 第 2 章 |
| 独立按键 K1~K4 | P3_1 / P3_0 / P3_2 / P3_3 | 按下为低电平 | 第 3 章 |
| 数码管位选 | P2_2 / P2_3 / P2_4 | 经 74HC138 译码选位 | 第 4 章 |
| 数码管段选 | P0 | 段码（8 段 + 小数点） | 第 4 章 |
| 矩阵键盘（4×4） | P1_0 ~ P1_7 | 行 P1_7~P1_4 输出、列 P1_3~P1_0 读取 | 第 6 章 |
| LCD1602 | RS=P2_6、RW=P2_5、E=P2_7、数据 P0 | 液晶显示 | 第 5/14 章 |
| 蜂鸣器 | P1_5 | 无源蜂鸣器（需 PWM） | 第 11 章 |
| 直流电机 | P1_0 | 经驱动电路 | 第 15 章 |
| DS1302 | CE=P3_6、IO=P3_4、SCLK=P3_5 | 实时时钟芯片 | 第 10 章 |
| DS18B20 | DQ=P3_7 | 单总线温度传感器 | 第 13 章 |

> [!tip] 这张表就是后面所有实验的"引脚地图"
> 后面每一章接外设时都会回到这张表。记不住没关系，用到哪章翻哪章即可。但请先记住最常用的三组：**LED 在 P2、按键在 P3、数码管段码在 P0**——这三组从第 2 章开始几乎每集都要用。

## 6 最小系统三要素

一块能跑起来的最小单片机系统，必须有这三样东西：

```text
                 +5V ───► 电源
                 │
   晶振（12MHz）──┼──► 提供时钟节拍
   （XTAL1/XTAL2）│
                 │
   复位电路 ──────┘──► 上电/按键复位，PC 归 0x0000
```

1. **电源**：5V 供电（STC89C52 典型工作电压 5V，注意和 STM32 的 3.3V 区分）。
2. **晶振**：提供时钟。课程开发板常用 **12MHz**，决定了定时器/延时的计算基准。少数工程（如红外、串口精确波特率）用 **11.0592MHz**——因为 11.0592MHz 能整除常用波特率，算出的波特率误差更小。
3. **复位电路**：上电或按键复位，让 PC 回到 0x0000，程序从头执行。

> [!note] 12MHz vs 11.0592MHz
> 这是 51 里一个经典知识点：
> - **12MHz**：一个机器周期 = 1μs（好算），课程大部分延时、定时器用它。
> - **11.0592MHz**：机器周期不是整数微秒，但它能整除 9600、19200 等波特率，串口通信时波特率误差小。所以官方源码里"红外遥控"和"串口"相关工程会标注 11.0592MHz。
>
> 这两个频率的选择贯穿第 2 章（软件延时）到第 17 章（红外遥控），务必理解。

## 7 完整示例：认识你的第一个程序

虽然这一集不写程序，但提前看一眼第 2 章会写的第一个点灯程序，能立刻把"寄存器思维"落地：

```c
#include <REGX52.H>   // ① 引入头文件，让编译器认识 P2、P2_0 这些符号

void main()
{
    P2 = 0xFE;   // ② 往 P2 寄存器写 0xFE（1111 1110）
                 //    P2.0 输出 0（低电平）→ 对应的 LED 亮
                 //    其余 P2.1~P2.7 输出 1（高电平）→ 对应 LED 灭
}
```

- 第 ① 步：`#include <REGX52.H>` 引入 SFR 定义。
- 第 ② 步：`P2 = 0xFE;` 就是**往 SFR（P2，地址 0xA0）写一个值**，8 个位分别控制 8 个引脚的输出电平。

这就是 51 编程的全部本质——**给寄存器赋值**。后面 17 章，无非是"给哪个寄存器、赋什么值、什么时候赋"。

## 8 易错点

- [ ] 把芯片型号记错（如 STM32、AVR）→ 本课芯片是 **STC89C52**（8051 内核，8 位）。
- [ ] 以为 STC89C52 是 3.3V → 它是 **5V** 单片机，IO 高电平 5V（STM32 才是 3.3V）。
- [ ] 混淆 ROM 和 RAM → **ROM 存程序（掉电不丢），RAM 存变量（掉电丢）**。
- [ ] 认为 P0 和 P1/P2/P3 一样能直接驱动 → **P0 无内部上拉（开漏）**，输出高电平要外接上拉。
- [ ] 不知道晶振频率 → 12MHz 是后面所有延时、定时器初值的计算基础，记错全盘皆错。
- [ ] 混淆"芯片引脚"和"开发板外设引脚" → 芯片引脚是芯片 40 脚本身，外设引脚是板上外设接到哪个 IO 口。
- [ ] 不写 `#include <REGX52.H>` → `P2`、`P1_2` 等符号未定义，编译报错。
- [ ] 分不清可位寻址/不可位寻址寄存器 → 只有可位寻址的 SFR 才能用 `sbit` 单独操作某一位。

## 9 自测

1. 单片机内部由哪几大部分组成？CPU 是几位的？
2. 哈佛结构和冯·诺依曼结构的本质区别是什么？51 属于哪种？
3. ROM 和 RAM 分别存什么？哪个掉电丢失？
4. 什么是 SFR？`P2 = 0xFE;` 这行代码本质上在做什么？
5. P0 口和 P1/P2/P3 口有什么区别？P3 口有哪些第二功能？
6. 最小系统需要哪三个要素？12MHz 晶振意味着什么？

> [!success]- 参考答案
> 1. CPU（8 位内核）+ 存储器（ROM/RAM）+ SFR（特殊功能寄存器）+ IO 端口（P0~P3）。CPU 是 8 位，一次处理一个字节。
> 2. 哈佛结构把程序存储器和数据存储器**物理分开、地址独立**（两条总线可并行访问）；冯·诺依曼结构两者合并、共用一条总线。51 属于**哈佛结构**。
> 3. **ROM 存程序代码**（掉电不丢，是 Flash）；**RAM 存运行时变量**（掉电丢失）。你定义的变量在 RAM，程序代码在 ROM。
> 4. SFR 是特殊功能寄存器，一组有固定地址、控制外设的存储单元。`P2 = 0xFE;` 就是**往地址 0xA0 的 P2 寄存器写 0xFE**，让 P2.0 输出低电平、其余输出高电平。
> 5. **P0 口内部无上拉电阻（开漏结构）**，输出高电平需外接上拉；P1/P2/P3 内部带弱上拉。P3 口第二功能：P3.0/P3.1=RXD/TXD（串口）、P3.2/P3.3=INT0/INT1（外部中断）、P3.4/P3.5=T0/T1（定时器外部计数）、P3.6/P3.7=WR/RD。
> 6. 电源（5V）、晶振、复位电路。12MHz 晶振意味着**一个机器周期 = 1μs**（12 个振荡周期），这是后面延时和定时器初值计算的基准。
