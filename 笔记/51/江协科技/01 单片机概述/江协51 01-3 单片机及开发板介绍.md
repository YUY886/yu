# 01-3 单片机及开发板介绍

> [!abstract] 这一集只解决一个问题
> **手上的 STC89C52 芯片和开发板长什么样、各外设接在哪些引脚上？**
>
> 芯片 = STC89C52（8051 内核，40 引脚 DIP 封装，4 组 IO 口 P0~P3）；开发板 = 普中 HC6800-ES V2.0，板上已把 LED、按键、数码管、液晶等外设焊好并接好引脚，直接用 IO 口控制即可。
>
> 上一集 [[江协51 01-2 开发工具介绍及软件安装]] ｜ 章索引 [[江协51 01 单片机概述（章索引）]]

## 1 STC89C52 芯片

| 项目 | 值 |
| --- | --- |
| 内核 | 8051（8 位） |
| 封装 | DIP-40（40 引脚直插） |
| Flash（程序） | 8KB |
| RAM（数据） | 512B（256B 内部 + 扩展） |
| IO 口 | P0、P1、P2、P3 四组，每组 8 位 |
| 定时器 | T0、T1、T2 |
| 串口 | 1 个全双工 UART |
| 工作电压 | 5V（典型） |

> [!note] 芯片 vs 开发板
> **芯片**是 STC89C52 这颗 IC 本身；**开发板**是把芯片、晶振、复位电路、电源、USB 转串口、以及一堆外设（LED/按键/数码管/液晶等）集成在一块 PCB 上的板子，让你不用自己搭电路就能跑实验。

## 2 四组 IO 口

51 单片机最核心的资源是 **4 组 8 位并行 IO 口**：

| 端口 | 引脚数 | 内部上拉 | 主要用途 / 第二功能 |
| --- | --- | --- | --- |
| P0 | 8 | **无（开漏）** | 普通 IO（需外接上拉）；地址/数据总线 |
| P1 | 8 | 有 | 普通 IO |
| P2 | 8 | 有 | 普通 IO；高 8 位地址 |
| P3 | 8 | 有 | 普通 IO；第二功能（RXD/TXD/INT0/INT1/T0/T1/RD/WR） |

> [!warning] P0 口最特殊
> **P0 口内部没有上拉电阻**，作为普通输出口时，高电平靠外部上拉才能得到 5V；直接接 LED 等负载要特别注意。P1/P2/P3 内部都有上拉，直接当普通 IO 用更方便。

P3 口的第二功能（后面章节会用到）：

| P3 引脚 | 第二功能 | 含义 |
| --- | --- | --- |
| P3.0 / P3.1 | RXD / TXD | 串口接收 / 发送 |
| P3.2 / P3.3 | INT0 / INT1 | 外部中断 0 / 1 |
| P3.4 / P3.5 | T0 / T1 | 定时器 0 / 1 外部计数输入 |
| P3.6 / P3.7 | WR / RD | 外部存储器写 / 读 |

## 3 开发板（普中 HC6800-ES V2.0）外设接线

课程所有实验都基于这张接线表（已对照官方源码核对）：

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| LED（8 个） | P2_0 ~ P2_7 | 低电平点亮 |
| 独立按键 K1~K4 | P3_1 / P3_0 / P3_2 / P3_3 | 按下为低电平 |
| 数码管位选 | P2_2 / P2_3 / P2_4 | 经 74HC138 译码选位 |
| 数码管段选 | P0 | 段码 |
| 矩阵键盘（4×4） | P1_0 ~ P1_7 | 行/列扫描 |
| LCD1602 | RS=P2_6、RW=P2_5、E=P2_7、数据 P0 | 见第 5/14 章 |
| 蜂鸣器 | P1_5 | 见第 11 章 |
| 直流电机 | P1_0 | 见第 15 章 |

> [!tip] 这张表就是后面所有实验的"引脚地图"
> 后面每一章在接外设时都会回到这张表。记不住没关系，用到哪章翻哪章即可；关键先记住**LED 在 P2、按键在 P3、数码管段码在 P0**。

## 4 最小系统三要素

一块能跑起来的最小单片机系统需要三样东西：

1. **电源**：5V 供电（STC89C52 工作电压）。
2. **晶振**：提供时钟，课程开发板常用 **12MHz** 晶振（决定了定时器/延时的计算基准）。
3. **复位电路**：上电或按键复位，让程序从头执行。

> [!note] 12MHz 晶振是后面所有定时计算的前提
> 课程源码里的延时函数、定时器初值（如 `TL0=0x18, TH0=0xFC` 对应 1ms）都是按 **12MHz 晶振**算的。换晶振频率，这些参数就要重算。这一点从第 2 章软件延时到第 7 章定时器贯穿始终。

## 5 易错点

- [ ] 把芯片型号记成别的（如 STM32、AVR）→ 本课芯片是 STC89C52。
- [ ] 认为 P0 和 P1/P2/P3 一样能直接驱动 → P0 无上拉，接法不同。
- [ ] 不知道晶振频率是 12MHz → 后面所有延时、定时器初值都无法理解。
- [ ] 混淆"芯片引脚"和"开发板外设引脚" → 芯片引脚是芯片本身 40 脚，外设引脚是板子上外设接到哪个 IO 口。

## 6 自测

1. STC89C52 有几组 IO 口？分别是什么？
2. P0 口和其他三组 IO 口有什么本质区别？
3. 最小系统需要哪三个要素？本课晶振频率是多少？

> [!success]- 参考答案
> 1. 四组，P0、P1、P2、P3，每组 8 位（共 32 个 IO 引脚）。
> 2. **P0 口内部没有上拉电阻（开漏结构）**，作普通输出高电平时需外接上拉；P1/P2/P3 内部都有上拉。
> 3. 电源（5V）、晶振、复位电路三要素；本课晶振 12MHz。
