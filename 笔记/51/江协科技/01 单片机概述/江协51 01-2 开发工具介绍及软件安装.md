# 01-2 开发工具介绍及软件安装

> [!abstract] 这一集只解决一个问题
> **把开发 51 单片机的工具链装好、跑通。**
>
> 两条工具链：**Keil C51**（写代码 + 编译出 `.hex` 文件）+ **STC-ISP**（把 `.hex` 下载进 STC89C52 芯片）。装好这两个，才能开始写第一个程序。
>
> 上一集 [[江协51 01-1 课程简介]] ｜ 下一集 [[江协51 01-3 单片机及开发板介绍]] ｜ 章索引 [[江协51 01 单片机概述（章索引）]]

## 1 工具链全景

```text
 写代码          编译              烧录              运行
 ┌────────┐   ┌────────┐   ┌──────────────┐   ┌──────────┐
 │ Keil C51 │ → │ 生成 .hex │ → │ STC-ISP 下载  │ → │ 开发板执行 │
 │ (写 .c)  │   │ (机器码)  │   │ (经串口烧芯片) │   │ (现象)    │
 └────────┘   └────────┘   └──────────────┘   └──────────┘
```

- **Keil C51**：集成开发环境（IDE），负责写 C 代码、编译、链接，最终生成 **`.hex`**（Intel HEX 格式的机器码文件）。
- **STC-ISP**：STC 官方的下载工具，通过**串口（USB 转 TTL）**把 `.hex` 烧进芯片的 Flash。

> [!note] Keil 和 STC-ISP 分工别搞混
> Keil **不负责下载**，它只是"翻译官"，把 C 代码翻译成机器码；STC-ISP **不负责写代码**，它只是"搬运工"，把 hex 搬进芯片。

## 2 安装 Keil C51

1. 下载并安装 **Keil C51**（注意是 **C51 版**，用于 51 单片机；另有 MDK-ARM 版是给 STM32 用的，别装错）。
2. 安装时勾选 8051 相关的组件。
3. （如需）注册/破解以获得更大代码空间；未注册也可编译小工程。

> [!warning] C51 版 vs MDK-ARM 版
> 51 单片机用 **Keil C51**，STM32 用 **Keil MDK-ARM**。两个是不同的产品，装错版本会找不到 STC89C52 的器件包。

## 3 新建一个 Keil 工程（骨架）

```text
Project → New uVision Project
   → 选芯片：STC89C52（或 Atmel AT89C52）
   → 新建 .c 文件，加入工程
   → 右键 Target → Options → Output 勾选「Create HEX File」
   → 编译（Build）→ 生成 .hex
```

- 必须勾选 **Create HEX File**，否则编译成功也拿不到 `.hex`，无法下载。
- 芯片型号若列表里没有 STC89C52，可先选 Atmel AT89C52（同为 8051 内核，寄存器兼容）。

## 4 安装并使用 STC-ISP

1. 安装 **STC-ISP**（STC 官方烧录软件）。
2. 开发板通过 **USB 线**连接电脑（板上一般已集成 USB 转串口芯片 CH340，需装对应驱动）。
3. STC-ISP 里：
   - 选 **芯片型号**：STC89C52
   - 选 **串口号**（COM 口，设备管理器里可查）
   - **打开程序文件**：选 Keil 生成的 `.hex`
   - 点 **下载/编程**，然后给开发板**断电再上电**（STC89C52 需冷启动进入下载模式）

> [!tip] STC89C52 下载要"冷启动"
> 老款 STC89C52 不会自动复位进入下载，常见做法是：STC-ISP 点"下载"后，**先断开开发板电源再重新上电**（或按下复位键），芯片启动瞬间检测串口下载信号。这是新手最常卡住的一步。

## 5 易错点

- [ ] Keil 装成 MDK-ARM 版 → 找不到 STC89C52，无法编译 51 工程。
- [ ] 没勾选 "Create HEX File" → 编译成功但没有 .hex，STC-ISP 里选不到文件。
- [ ] STC-ISP 没选对芯片型号或 COM 口 → 一直提示"检测不到目标芯片"。
- [ ] CH340 驱动没装 → 电脑不识别开发板，找不到 COM 口。
- [ ] 点下载后没做冷启动 → STC89C52 一直停在"正在检测目标单片机"。

## 6 自测

1. Keil C51 和 STC-ISP 分别负责什么？
2. 编译成功后为什么还需要 STC-ISP？
3. `.hex` 文件是什么？怎么生成它？

> [!success]- 参考答案
> 1. Keil C51 负责写 C 代码并编译成机器码（`.hex`），STC-ISP 负责把 `.hex` 通过串口下载进芯片。
> 2. Keil 只是编译，生成的文件还"躺"在电脑里；必须靠 STC-ISP 把它烧进 STC89C52 的 Flash，芯片才能执行。
> 3. `.hex` 是 Intel HEX 格式的机器码文件，芯片实际执行的就是它。在 Keil 的 Options → Output 里勾选 "Create HEX File" 后编译即可生成。
