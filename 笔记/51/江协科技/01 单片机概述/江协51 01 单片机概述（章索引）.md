## 本章速查

### 单片机（MCU）三大件

| 组成 | 作用 | 51 对应 |
| --- | --- | --- |
| CPU | 执行指令、运算 | 8 位 8051 内核 |
| 存储器 | 存程序（ROM/Flash）+ 存数据（RAM） | 片内 Flash / SRAM |
| IO 口 | 与外界交互（输入/输出） | P0/P1/P2/P3 四组 8 位并行口 |

### 51 单片机四组 IO 口

| 端口 | 特点 |
| --- | --- |
| P0 | 8 位，开源极结构（做普通 IO 需外接上拉电阻），也作地址/数据总线 |
| P1 | 8 位，内部带上拉电阻，普通 IO |
| P2 | 8 位，内部带上拉电阻，普通 IO，也作高 8 位地址 |
| P3 | 8 位，内部带上拉电阻，每位都有第二功能（如 RXD/TXD/INT0/INT1/T0/T1） |

### 开发板外设引脚速查（普中 HC6800-ES V2.0）

| 外设 | 引脚 |
| --- | --- |
| LED（8 个） | P2（P2_0 ~ P2_7），低电平点亮 |
| 独立按键 K1/K2/K3/K4 | P3_1 / P3_0 / P3_2 / P3_3（低电平按下） |
| 数码管（位选） | P2_2 / P2_3 / P2_4（经 74HC138 译码） |
| 数码管（段选） | P0 |
| 矩阵键盘 | P1（P1_0 ~ P1_7） |

> [!tip] 记这一章最省力的办法
> 第 1 章不用记代码，只要记住三件事：**单片机是一颗"集成计算机"芯片**、**Keil 写代码 + STC-ISP 烧录**、**开发板上 LED 在 P2、按键在 P3、数码管段码在 P0**。这三条从第 2 章开始会反复用到。

## 全章统一易错点

- [ ] 以为"单片机"和"开发板"是一回事 → 单片机是芯片，开发板是把芯片+外设+供电焊好的板子。
- [ ] 分不清 P0 和 P1/P2/P3 的区别 → P0 内部没有上拉电阻，直接驱动 LED 等要外接上拉。
- [ ] 混淆 Keil 和 STC-ISP 的分工 → Keil 只负责编译出 hex 文件，STC-ISP 才负责把 hex 下载进芯片。
- [ ] 下载时没选对芯片型号/串口号 → STC-ISP 要选 STC89C52 和正确的 COM 口。
