# 01-1 课程简介

> [!abstract] 这一集只解决一个问题
> **单片机是什么？这门课要学什么、能做出什么东西？**
>
> 一句话：单片机（MCU）就是把**中央处理器（CPU）、存储器（ROM/RAM）、输入输出接口（IO）** 集成在一颗芯片上的微型计算机。本课用 C 语言在 8051 内核上编程，做出 LED 流水灯、数码管时钟、温度计、遥控小车等一个个能跑在开发板上的小作品。

## 1 什么是单片机

**单片机 = 单片微型计算机（Single-Chip Microcomputer / MCU，Microcontroller Unit）**。把一台计算机的核心部件集成到一颗芯片里：

```text
  传统计算机（PC）                    单片机（MCU）
  ┌─────────────┐                ┌────────────────────┐
  │ CPU（处理器） │                │ CPU（8 位 8051 内核）│
  │ 内存条（RAM） │   → 缩小集成 →  │ 存储器（Flash + RAM） │
  │ 硬盘（ROM）  │                │ IO 口（P0~P3）       │
  │ 主板 + 外设  │                │ 定时器/串口/中断      │
  └─────────────┘                └────────────────────┘
```

区别只在于**规模和用途**：

| | PC 计算机 | 单片机 |
| --- | --- | --- |
| 处理能力 | 强大（64 位、GHz 级） | 有限（8 位、MHz 级） |
| 价格 | 高 | 极低（几元一颗） |
| 体积 | 大 | 指甲盖大小 |
| 用途 | 通用计算、娱乐 | **嵌入式控制**：家电、玩具、工业设备 |

> [!tip] 单片机无处不在
> 你身边几乎所有"会动、会亮、会响、有按键"的电子设备里都藏着一颗单片机：空调遥控器、洗衣机、微波炉、电子秤、智能水表、汽车里的无数 ECU…… 学单片机就是学会"给这些设备写大脑"。

## 2 为什么用 8051 / 51 单片机入门

**8051** 是 Intel 在 1980 年推出的经典 8 位单片机内核，距今 40 多年，仍然是嵌入式入门的事实标准：

- **结构简单**：8 位、寄存器少、指令少，容易建立"寄存器→硬件"的直观映射。
- **资料海量**：中文教程、书籍、例程最多，遇到问题容易搜到答案。
- **便宜易得**：本课用的 STC89C52 几块钱一颗，开发板百元内。
- **承上启下**：学会了 51，再学 STM32（ARM Cortex-M）只是"寄存器变多、外设变强"，思路一脉相承。

> [!note] 51 vs STM32（一句话定位）
> 51 是 8 位老将，寄存器少、直接、适合打基础；STM32 是 32 位主流，外设丰富、功能强、是实际项目的主力。这门课用 51 入门，学的是**嵌入式编程的通用思维**，这些思维在 STM32 上完全复用。

## 3 本课程能做什么

课程循序渐进，从点一个 LED 到做一个综合小系统：

| 阶段 | 内容 | 代表作 |
| --- | --- | --- |
| 基础 | 点灯、按键、数码管 | LED 流水灯、按键计数器 |
| 进阶 | 定时器、串口、液晶 | 数码管时钟、串口助手通信 |
| 外设 | I2C、单总线、AD/DA、红外 | 温度计、密码锁、遥控调速 |

## 4 怎么学（这门课的方法）

- **动手为主**：每一集都对应一个能跑的实验，抄一遍代码 → 烧进开发板 → 看现象 → 改参数再试。
- **先照抄、再理解**：新手先保证代码能跑通建立信心，再去抠每一行为什么。
- **寄存器思维**：51 编程的本质是"给寄存器赋值"，学会看芯片手册查寄存器。

## 5 易错点

- [ ] 把"单片机"当成一个具体型号 → 单片机是一类芯片的总称，51/STM32 都是，本课学的是 8051 内核的 STC89C52。
- [ ] 以为学单片机要先精通 C 语言 → 会基本语法（变量、循环、函数）就够入门，边学边补。
- [ ] 只看不练 → 单片机是动手课，不烧板子等于没学。

## 6 自测

1. 单片机（MCU）和普通 PC 计算机的本质区别是什么？
2. 单片机的"三大件"是哪三个部分？
3. 为什么 51 适合作为单片机入门？

> [!success]- 参考答案
> 1. 本质区别在**规模和用途**：PC 是通用的强计算设备，单片机是把 CPU+存储+IO 集成在一颗芯片里、专用于嵌入式控制的低成本微型计算机。
> 2. **CPU（中央处理器）、存储器（ROM/RAM）、IO 输入输出接口**三部分。
> 3. 结构简单（8 位、寄存器少、易理解）、资料海量、便宜易得，且学到的嵌入式编程思维能平滑迁移到 STM32。
