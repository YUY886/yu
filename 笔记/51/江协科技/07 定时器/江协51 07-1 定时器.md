# 07-1 定时器

> [!abstract] 这一集只解决一个问题
> **怎么不占用 CPU 地精确计时？**
>
> 答：用**硬件定时器**。定时器独立于 CPU 后台计数，到点触发**中断**。只需配置 TMOD（模式）、TL0/TH0（初值）、ET0/EA（开中断），再写一个 `interrupt 1` 中断函数即可。
>

## 1 定时器 vs 软件延时

| | 软件延时（Delay） | 硬件定时器 |
| --- | --- | --- |
| 实现 | CPU 空转数循环 | 独立硬件计数器 |
| 是否占 CPU | 占满（延时期间干不了别的） | 不占（后台计数） |
| 精度 | 粗略、受编译影响 | 精确 |
| 适用 | 短延时 | 精确定时、多任务 |

> [!tip] 为什么需要定时器
> 软件延时期间 CPU 被"锁死"，什么也做不了。定时器让"计时"交给硬件，CPU 可以同时处理按键、显示等其他事——这是从"单任务"走向"多任务"的关键一步。

## 2 定时器工作原理

STC89C52 有 T0、T1（本集用 T0）。定时器本质是一个**计数器**：

1. 每过一个**机器周期**（12MHz 晶振下 = 1μs），计数器加 1。
2. 计数器从初值开始加，加到**溢出**（16 位模式从 0xFFFF 到 0x0000）时触发中断。
3. 溢出后重装初值，重新计时。

**初值怎么算**（要定时 1ms）：

```text
机器周期 = 12 / 12MHz = 1μs
1ms = 1000μs → 要数 1000 次
初值 = 65536 - 1000 = 64536 = 0xFC18
   高 8 位 TH0 = 0xFC
   低 8 位 TL0 = 0x18
```

> [!warning] 初值和晶振绑定
> 0xFC18 是按 **12MHz 晶振**算的。换晶振（如 11.0592MHz，串口常用）就要重算初值。这是第 8 章串口波特率、第 17 章红外两个晶振版本共存的根本原因。

## 3 定时器初始化

```c
void Timer0Init(void)
{
	TMOD &= 0xF0;	// 清 T0 的 4 位（保留 T1 配置）
	TMOD |= 0x01;	// 模式 1：16 位定时器
	TL0 = 0x18;		// 低 8 位初值
	TH0 = 0xFC;		// 高 8 位初值
	TF0 = 0;		// 清溢出标志
	TR0 = 1;		// 启动定时器 0
	ET0 = 1;		// 允许定时器 0 中断
	EA  = 1;		// 允许总中断
	PT0 = 0;		// 优先级（默认低）
}
```

### 各寄存器作用

| 寄存器/位 | 作用 |
| --- | --- |
| `TMOD` | 定时器工作方式寄存器（低 4 位管 T0，高 4 位管 T1） |
| `TL0`/`TH0` | 初值低/高 8 位 |
| `TF0` | 溢出标志（溢出自动置 1） |
| `TR0` | 启动/停止（1 启动） |
| `ET0` | 定时器 0 中断使能 |
| `EA` | 总中断开关（**必须开**） |

> [!warning] EA 总中断别忘
> 即使 ET0=1，只要 EA=0，中断仍然进不来。**EA 是所有中断的"总闸"**，这是新手最常漏的一行。

## 4 中断函数

```c
void Timer0_Routine() interrupt 1
{
	static unsigned int T0Count;
	TL0 = 0x18;		// 重装初值
	TH0 = 0xFC;
	T0Count++;		// 每 1ms 进来一次
	// ... 用 T0Count 分频做具体事
}
```

- `interrupt 1`：中断号，定时器 0 的中断号是 **1**。
- `static unsigned int T0Count`：**静态变量**，只初始化一次，值在多次中断间保持——用它来"分频"。
- 16 位模式要**手动重装初值**（`TL0/TH0`），因为模式 1 不会自动重装。

> [!note] 为什么用 static
> 普通局部变量每次进函数都会重新初始化，累加结果会丢失。`static` 让变量"记住"上次的值，这样 `T0Count++` 才能持续累加实现分频。

## 5 完整代码（7-1 的 Timer0.c）

```c
#include <REGX52.H>

void Timer0Init(void)
{
	TMOD &= 0xF0;		//设置定时器模式
	TMOD |= 0x01;		//设置定时器模式
	TL0 = 0x18;		//设置定时初值
	TH0 = 0xFC;		//设置定时初值
	TF0 = 0;		//清除TF0标志
	TR0 = 1;		//定时器0开始计时
	ET0=1;
	EA=1;
	PT0=0;
}
```

> [!tip] 中断函数模板（官方给的）
> 官方源码里附了一段"中断函数模板"注释，直接抄改即可：
> ```c

> 	TH0 = 0xFC;
> 	T0Count++;

> 	{
> 		T0Count=0;
> 		// 你的代码
> 	}
> }
> ```

## 6 易错点

- [ ] 忘了 `EA=1` → 中断进不来。
- [ ] 忘了重装 TL0/TH0 → 只准第一次。
- [ ] 分频变量没加 static → 累加无效。
- [ ] 初值 0xFC18 记反（TH0=0x18/TL0=0xFC）→ 定时错乱。
- [ ] 中断号写错 → T0 是 interrupt 1，T1 是 interrupt 3。

## 7 自测

1. 定时器比软件延时好在哪里？
2. 为什么 12MHz 下 1ms 定时初值是 0xFC18？
3. `EA` 和 `ET0` 分别是什么？为什么都要开？

> [!success]- 参考答案
> 1. 定时器后台独立计数，不占用 CPU（软件延时占满 CPU）；精度更高。
> 2. 机器周期=12/12MHz=1μs，1ms 要数 1000 次，初值=65536-1000=64536=0xFC18，高 8 位 0xFC、低 8 位 0x18。
> 3. EA 是总中断开关（总闸），ET0 是定时器 0 中断使能（分闸）。都要开中断才能生效。
