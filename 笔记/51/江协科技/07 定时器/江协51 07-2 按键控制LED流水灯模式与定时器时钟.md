# 07-2 按键控制 LED 流水灯模式 & 定时器时钟

> [!abstract] 这一集只解决一个问题
> **怎么用定时器做两件典型的事：按键切换流水灯方向 + 数码管时钟？**
>
> 答：都用 Timer0 的 1ms 中断，在中断里用 `static` 变量**分频**——500 次 = 500ms 切一次流水灯，1000 次 = 1s 走一秒时钟。
>
> 上一集 [[江协51 07-1 定时器]] ｜ 章索引 [[江协51 07 定时器（章索引）]]

## 1 分频的概念

定时器 1ms 中断一次，但很多任务（流水灯切一帧、时钟走一秒）不需要这么快。**分频**就是"每 N 次中断才做一次事"：

```c
static unsigned int T0Count;  // 分频计数器（static 保持）
T0Count++;                     // 每 1ms 加 1
if(T0Count >= 500)             // 满 500 次 = 500ms
{
    T0Count = 0;               // 清零，重新计
    // 做一次"500ms 任务"
}
```

- 500 次 → 500ms（流水灯切换速度）。
- 1000 次 → 1s（时钟走秒）。

## 2 应用一：按键切换流水灯模式

用 `_crol_`/`_cror_`（循环左移/右移，在 `INTRINS.H` 里）实现流水灯，按键切换方向：

```c
#include <REGX52.H>
#include "Timer0.h"
#include "Key.h"
#include <INTRINS.H>

unsigned char KeyNum,LEDMode;

void main()
{
	P2=0xFE;          // 上电先亮第 1 颗
	Timer0Init();
	while(1)
	{
		KeyNum=Key();     // 读按键
		if(KeyNum)
		{
			if(KeyNum==1)     // K1 按下
			{
				LEDMode++;        // 模式切换
				if(LEDMode>=2)LEDMode=0;
			}
		}
	}
}

void Timer0_Routine() interrupt 1
{
	static unsigned int T0Count;
	TL0 = 0x18;
	TH0 = 0xFC;
	T0Count++;
	if(T0Count>=500)   // 500ms
	{
		T0Count=0;
		if(LEDMode==0)          // 模式 0：左移
			P2=_crol_(P2,1);
		if(LEDMode==1)          // 模式 1：右移
			P2=_cror_(P2,1);
	}
}
```

> [!tip] `_crol_(P2,1)` 循环左移
> `_crol_(P2,1)` 把 P2 的值循环左移 1 位（最高位移到最低位），配合低电平点亮，效果就是流水灯。`_cror_` 是循环右移。这两个函数在 `INTRINS.H` 里。

## 3 应用二：定时器时钟

用三个变量 `Sec/Min/Hour` 记录时分秒，中断里每秒进位：

```c
unsigned char Sec=55,Min=59,Hour=23;

void Timer0_Routine() interrupt 1
{
	static unsigned int T0Count;
	TL0 = 0x18;
	TH0 = 0xFC;
	T0Count++;
	if(T0Count>=1000)   // 1s
	{
		T0Count=0;
		Sec++;            // 秒加 1
		if(Sec>=60)       // 60 秒进 1 分
		{
			Sec=0;
			Min++;
			if(Min>=60)   // 60 分进 1 时
			{
				Min=0;
				Hour++;
				if(Hour>=24)  // 24 时归 0
				{
					Hour=0;
				}
			}
		}
	}
}
```

main 里循环显示（动态扫描）：

```c
while(1)
{
	LCD_ShowNum(2,1,Hour,2);
	LCD_ShowNum(2,4,Min,2);
	LCD_ShowNum(2,7,Sec,2);
}
```

- 上电初值 `Sec=55,Min=59,Hour=23` 是为演示进位特意设的（马上能看到 59→00 的进位）。

## 4 易错点

- [ ] 分频变量忘 static → 累加失效，任务永不触发。
- [ ] 分频阈值和实际时长对不上 → 500 次=500ms（1ms 中断），1000 次=1s。
- [ ] 进位判断顺序错 → 先 Sec++ 再判断 >=60，别写成先判断再加。
- [ ] `_crol_`/`_cror_` 忘 include `<INTRINS.H>`。

## 5 自测

1. 什么是分频？为什么需要它？
2. 500 次分频对应多少时间（1ms 中断）？
3. 时钟的秒→分→时进位逻辑是怎么写的？

> [!success]- 参考答案
> 1. 分频就是"每 N 次中断才执行一次任务"，把高频中断（1ms）降成低频任务（500ms/1s）。需要它是因为很多任务不需要 1ms 执行一次。
> 2. 500 × 1ms = 500ms。
> 3. 每秒 Sec++，Sec 到 60 清零并 Min++，Min 到 60 清零并 Hour++，Hour 到 24 归 0。
