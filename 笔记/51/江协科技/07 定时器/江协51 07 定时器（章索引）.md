## 本章速查

### 定时器初值计算（12MHz）

- 模式 1（16 位定时器），机器周期 = 12 / 12MHz = 1μs。
- 定时 1ms 需要计 1000 个数，初值 = 65536 - 1000 = 64536 = 0xFC18。
- 所以 **TL0=0x18、TH0=0xFC** 对应定时 1ms。

### 定时器初始化（Timer0Init）

```c
void Timer0Init(void)
{
	TMOD &= 0xF0;	// 清 T0 的 4 位，保留 T1
	TMOD |= 0x01;	// 模式 1（16 位定时器）
	TL0 = 0x18;		// 低 8 位初值
	TH0 = 0xFC;		// 高 8 位初值
	TF0 = 0;		// 清溢出标志
	TR0 = 1;		// 启动定时器 0
	ET0 = 1;		// 开定时器 0 中断
	EA  = 1;		// 开总中断
	PT0 = 0;		// 优先级
}
```

### 中断函数

```c
void Timer0_Routine() interrupt 1
{
	TL0 = 0x18;   // 重装初值（16 位模式要手动重装）
	TH0 = 0xFC;
	// 每 1ms 进来一次，用 static 变量分频计数
}
```

> [!tip] 记这一章最省力的办法
> 定时器就三步：**TMOD 选模式 + TL0/TH0 装初值 + interrupt 1 中断函数**。初值 0xFC18 对应 1ms@12MHz 要背住。中断里用 `static` 变量累计做分频（如 500 次=500ms），这样 CPU 干别的、定时器在后台精确计时。

## 全章统一易错点

- [ ] 忘了 `EA=1`（总中断）→ 只开 ET0 也没用，中断进不来。
- [ ] 16 位模式忘了在中断里重装初值 → 第一次之后定时不准。
- [ ] 初值算错 → 0xFC18 是 1ms@12MHz，换晶振要重算。
- [ ] 分频变量没加 `static` → 每次进中断重新初始化，永远计不到。
- [ ] 中断函数里做太多耗时操作 → 影响主程序实时性。
