# 05-2 LCD1602 调试工具

> [!abstract] 这一集只解决一个问题
> **怎么在开发过程中实时看到变量的值（调试）？**
>
> 答：用 **LCD1602 液晶屏**——调用封装好的 `LCD_Init()` 初始化，再用 `LCD_ShowNum()`、`LCD_ShowString()` 把变量/字符串显示到屏幕上。从此调试不必靠猜，直接"打印"出来看。
>
> 上一集 [[江协51 05-1 模块化编程]] ｜ 章索引 [[江协51 05 模块化与LCD1602（章索引）]]

## 1 为什么 LCD1602 是"调试工具"

前面的 LED、数码管能显示的信息有限（LED 只能显示 0/1，数码管只能显示数字）。LCD1602 能显示**16 列 × 2 行 = 32 个字符**（字母、数字、符号），足以把变量值、状态字都打出来。

调试思路：把想知道的值 `LCD_ShowNum(1,1,Result,3)` 显示出来，眼睛一看就知道程序对不对。

## 2 LCD1602 是什么

**LCD1602** 是一种**字符型液晶屏**，名字里的 "16" 表示 16 列、"02" 表示 2 行，即 **16×2 = 32 个字符**的显示能力。

```text
  列 1  2  3  ...  16
  ┌────────────────────┐
  │ H  e  l  l  o  ... │ ← 第 1 行
  ├────────────────────┤
  │ 1  2  3  ...       │ ← 第 2 行
  └────────────────────┘
```

- 每个字符位置是 **5×7 点阵**（5 列 × 7 行像素）。
- 内部自带**字符发生器**（CGROM），内置了 ASCII 字符、数字、符号的字模，你只需发一个 ASCII 码，屏就会自动显示出对应字符，不用自己画点阵。
- 能显示字母、数字、常用符号，适合做**调试显示**（比 LED/数码管信息量大得多）。

> [!note] LCD1602 vs 数码管
> 数码管只能显示数字（还只是 0~9），LCD1602 能显示字母、数字、符号，还能同时显示 32 个字符，信息量远超数码管。所以从本章起，LCD1602 成为课程主力调试工具。

## 3 LCD1602 引脚

LCD1602 通过一组控制线（RS/RW/E）+ 一组数据线（D0~D7）与单片机通信：

| 引脚 | 接 IO | 作用 |
| --- | --- | --- |
| RS | P2_6 | 寄存器选择：0=命令，1=数据 |
| RW | P2_5 | 读写选择：0=写，1=读 |
| E | P2_7 | 使能脉冲（下降沿锁存） |
| D0~D7 | P0 | 8 位数据总线 |

```c
sbit LCD_RS=P2^6;
sbit LCD_RW=P2^5;
sbit LCD_E=P2^7;
#define LCD_DataPort P0
```

### 3.1 三个控制引脚的分工

```text
  RS = 0：D0~D7 上是"命令"（如清屏、设光标）
  RS = 1：D0~D7 上是"数据"（要显示的字符 ASCII 码）

  RW = 0：写（单片机 → LCD）  ← 本课只用写
  RW = 1：读（LCD → 单片机，读忙标志等，本课不用）

  E  ：使能脉冲，每次读写数据/命令时给一个脉冲触发
```

- 本课只用**写**（RW 恒为 0），所以 LCD 是"只写不读"的简单用法。
- 每次操作：设置 RS → 把数据放 D0~D7 → E 给一个脉冲 → 完成一次写入。

## 4 常用函数

课程把 LCD1602 封装成模块（`LCD1602.c/h`），常用函数：

| 函数 | 作用 |
| --- | --- |
| `LCD_Init()` | 初始化（写 0x38/0x0C/0x06/0x01 四条命令） |
| `LCD_ShowChar(Line,Column,Char)` | 在指定位置显示一个字符 |
| `LCD_ShowString(Line,Column,"str")` | 显示字符串 |
| `LCD_ShowNum(Line,Column,Num,Length)` | 显示十进制数字（Length 位） |
| `LCD_ShowHexNum(...)` | 显示十六进制数 |
| `LCD_ShowBinNum(...)` | 显示二进制数 |

- **坐标从 1 开始**：`Line` 是行（1 或 2），`Column` 是列（1~16）。
- `LCD_ShowNum(1,1,Result,3)`：在第 1 行第 1 列显示 Result，占 3 位宽度。

## 5 初始化命令（底层）

`LCD_Init()` 内部写了 4 条命令：

```c
void LCD_Init(void)
{
	LCD_WriteCommand(0x38);  // 8 位数据、2 行、5×7 点阵
	LCD_WriteCommand(0x0C);  // 显示开、光标关
	LCD_WriteCommand(0x06);  // 写后地址自动加 1
	LCD_WriteCommand(0x01);  // 清屏
}
```

## 6 完整代码（main.c）

```c
#include <REGX52.H>
#include "LCD1602.h"	//包含LCD1602头文件
#include "Delay.h"		//包含Delay头文件

int Result=0;

void main()
{
	LCD_Init();
	while(1)
	{
		Result++;					//Result自增
		Delay(1000);				//延时1秒
		LCD_ShowNum(1,1,Result,3);	//在LCD的1行1列显示Result，长度为3位
	}
}
```

- 效果：LCD 第一行显示从 0 开始每秒加 1 的数字，直观看到程序在跑、变量在变。

## 7 易错点

- [ ] 坐标从 0 开始 → LCD1602 的坐标是**从 1 开始**（行 1~2、列 1~16）。
- [ ] 忘了 `LCD_Init()` → 屏幕乱码或不显示。
- [ ] `LCD_ShowNum` 的 Length 参数理解错 → 是"显示宽度"，不足会补空格或 0。
- [ ] 引脚接错 → RS/RW/E 对应 P2_6/P2_5/P2_7。

## 8 自测

1. LCD1602 能显示多少字符？坐标从几开始？
2. `LCD_ShowNum(2,1,Result,3)` 各参数含义？
3. LCD_Init 初始化写了哪几条命令？

> [!success]- 参考答案
> 1. 16 列 × 2 行 = 32 个字符；坐标从 1 开始（行 1~2、列 1~16）。
> 2. 第 2 行第 1 列开始，显示十进制变量 Result，占 3 位宽度。
> 3. 0x38（8 位数据、2 行、5×7 点阵）、0x0C（显示开、光标关）、0x06（写后地址自增）、0x01（清屏）。
