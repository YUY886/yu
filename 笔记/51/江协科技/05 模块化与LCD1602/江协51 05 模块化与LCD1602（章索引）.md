## 本章速查

### 模块化三要素

1. **`.h` 头文件**：放函数声明、宏定义、类型定义（给别的文件看"有哪些接口"）。
2. **`.c` 源文件**：放函数实现（具体怎么干）。
3. **头文件保护**：`#ifndef / #define / #endif` 防止重复包含。

```c
// Delay.h
#ifndef __DELAY_H__
#define __DELAY_H__

void Delay(unsigned int xms);   // 声明

#endif
```

### 引用模块

```c
#include "Delay.h"    // 用自己模块用双引号
#include <REGX52.H>   // 系统头文件用尖括号
```

> [!tip] 记这一章最省力的办法
> 模块化就记住"**声明放 .h、实现放 .c、用 #ifndef 包住 .h**"。LCD1602 记住 `LCD_Init()` 初始化 + `LCD_ShowNum/ShowString` 显示。后面矩阵键盘、串口、时钟全是"先写好模块，再在 main 里调用"。

## 全章统一易错点

- [ ] `.c` 忘了 `#include` 自己的 `.h` → 函数原型不一致，可能警告。
- [ ] 头文件没加 `#ifndef` 保护 → 被多次包含时报"重复定义"。
- [ ] 用 `<>` 包含自己的模块 → 应该用 `""`（当前目录查找）。
- [ ] 只写了 `.c` 没写 `.h` → 别的文件调用不到。
