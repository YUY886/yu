# 13-1 DS18B20 温度传感器

> [!abstract] 这一集只解决一个问题
> **怎么测量温度？**
>
> 答：用 **DS18B20 温度传感器**，通过**单总线（OneWire）**协议——一根数据线（DQ）就能通信。按严格的时序读写，读出 16 位温度值后除以 16 得到摄氏度。
>
> 下一集 [[江协51 13-2 DS18B20温度读取与温度报警器]] ｜ 章索引 [[江协51 13 DS18B20温度传感器（章索引）]]

## 1 单总线（OneWire）

DS18B20 用**单总线**协议：只需一根数据线（DQ），同时传数据和供电（寄生供电）。

```c
sbit OneWire_DQ=P3^7;   // 单总线数据线
```

- 相比 I2C（2 线）、SPI（4 线），单总线**只用 1 根线**，最省 IO。
- 代价：**时序要求严格**，靠精确的延时区分 0 和 1。

## 2 初始化时序

通信前要先"初始化"（复位 + 检测 DS18B20 是否存在）：

```c
unsigned char OneWire_Init(void)
{
	unsigned char i;
	unsigned char AckBit;
	OneWire_DQ=1;
	OneWire_DQ=0;          // 主机拉低 500us
	i = 247;while (--i);
	OneWire_DQ=1;          // 释放
	i = 32;while (--i);    // 等 70us
	AckBit=OneWire_DQ;     // 读应答（DS18B20 拉低表示存在）
	i = 247;while (--i);   // 再等 500us
	return AckBit;         // 0=有响应，1=无响应
}
```

- 主机拉低 500us → 释放 → DS18B20 若存在会拉低 70us 应答 → 返回 0。

## 3 读写时序

单总线通过"拉低时长"区分 0 和 1：

### 发送一位

```c
void OneWire_SendBit(unsigned char Bit)
{
	unsigned char i;
	OneWire_DQ=0;
	i = 4;while (--i);      // 拉低 10us
	OneWire_DQ=Bit;         // 输出要发的位
	i = 24;while (--i);     // 保持 50us
	OneWire_DQ=1;
}
```

### 接收一位

```c
unsigned char OneWire_ReceiveBit(void)
{
	unsigned char i;
	unsigned char Bit;
	OneWire_DQ=0;
	i = 2;while (--i);      // 拉低 5us
	OneWire_DQ=1;
	i = 2;while (--i);      // 等 5us
	Bit=OneWire_DQ;         // 读位
	i = 24;while (--i);     // 保持 50us
	return Bit;
}
```

> [!warning] 单总线时序不能乱
> 单总线对延时极其敏感。`i=247`≈500us、`i=32`≈70us、`i=4`≈10us、`i=2`≈5us 这些值都是按 12MHz 算好的，改晶振或改编译优化都会导致通信失败。

## 4 温度读取流程

1. **初始化**：检测 DS18B20。
2. **发指令**：如 0xCC（跳过 ROM）、0x44（启动温度转换）。
3. **再初始化 + 发读指令**：0xBE（读暂存器）。
4. **读 2 字节**：得到 16 位温度原始值。
5. **换算**：温度 = 原始值 / 16。

## 5 温度换算

DS18B20 的 16 位原始值格式：高 12 位整数（含符号），低 4 位小数。

```c
// 读出两个字节组合成 16 位后：
int Temp = (TempH<<8) | TempL;   // 组合
float T = Temp / 16.0;           // 除以 16 得摄氏度
```

- 正温度：直接 `/16`。
- 负温度：高 12 位是补码，要按有符号数解析。

## 6 易错点

- [ ] 单总线引脚搞错 → DQ=P3^7。
- [ ] 时序延时不对 → 通信失败（单总线时序极敏感）。
- [ ] 温度忘除以 16 → 数值大 16 倍。
- [ ] 负数没按补码处理 → 负温度显示错。

## 7 自测

1. 单总线相比 I2C/SPI 有什么特点？
2. 单总线初始化时怎么判断 DS18B20 是否存在？
3. 读出的 16 位温度值怎么换算成摄氏度？

> [!success]- 参考答案
> 1. 只用一根数据线（最省 IO），但时序要求严格，靠延时区分 0/1。
> 2. 主机拉低 500us 后释放，若 DS18B20 存在会拉低应答（返回 0），否则返回 1。
> 3. 温度 = 原始值 / 16（低 4 位小数，高 12 位整数，负数按补码解析）。
