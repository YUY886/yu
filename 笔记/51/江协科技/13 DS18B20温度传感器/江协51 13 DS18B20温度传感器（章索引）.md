## 本章速查

### DS18B20 引脚

- 单总线数据线 **DQ = P3^7**：`sbit OneWire_DQ=P3^7;`。

### 单总线时序（关键延时 @12MHz）

| 操作 | 说明 |
| --- | --- |
| 初始化 | 主机拉低 500us → 释放 → DS18B20 拉低 70us 应答 |
| 写 0 / 写 1 | 拉低后按不同时长保持 |
| 读位 | 拉低 5us 后读电平 |

### 温度换算

- DS18B20 读出的 16 位原始值，低 4 位是小数，高 12 位是整数（含符号）。
- 温度 = 原始值 / 16（有符号数处理）。

> [!tip] 记这一章最省力的办法
> 单总线就记：**一根 DQ 线（P3^7）+ 严格的时序（延时控制）**。初始化=拉低 500us 等应答；读写靠"拉低多久"区分 0 和 1。温度读出来后除以 16 就是摄氏度。

## 全章统一易错点

- [ ] 单总线引脚搞错 → DQ=P3^7。
- [ ] 时序延时不对 → 单总线对时序极敏感，延时错就通信失败。
- [ ] 温度换算忘除以 16 → 显示的温度大了 16 倍。
- [ ] 负数温度处理 → 要按有符号数（补码）解析。
