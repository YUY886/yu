# 13-2 DS18B20 温度读取 & 温度报警器

> [!abstract] 这一集只解决一个问题
> **怎么读温度并做一个温度报警器？**
>
> 答：用 13-1 的单总线函数读出温度，显示在数码管/LCD 上；设置阈值，温度超标就触发报警（蜂鸣器响、LED 亮）。
>
> 上一集 [[江协51 13-1 DS18B20温度传感器]] ｜ 章索引 [[江协51 13 DS18B20温度传感器（章索引）]]

## 1 温度读取（完整流程）

把 13-1 的底层时序封装成"读温度"函数：

```c
float DS18B20_ReadTemp(void)
{
	unsigned char TLSB, TMSB;
	int Temp;
	
	OneWire_Init();                // 初始化
	OneWire_SendByte(0xCC);        // 跳过 ROM
	OneWire_SendByte(0x44);        // 启动温度转换
	
	OneWire_Init();                // 再初始化
	OneWire_SendByte(0xCC);        // 跳过 ROM
	OneWire_SendByte(0xBE);        // 读暂存器
	
	TLSB = OneWire_ReceiveByte();  // 低字节
	TMSB = OneWire_ReceiveByte();  // 高字节
	
	Temp = (TMSB<<8) | TLSB;       // 组合成 16 位
	return Temp / 16.0;            // 换算成摄氏度
}
```

> [!note] 关键指令
> - `0xCC`：跳过 ROM（只接一个 DS18B20 时用）。
> - `0x44`：启动温度转换。
> - `0xBE`：读暂存器（温度数据）。

## 2 温度显示

读到的温度显示在数码管或 LCD 上：

```c
float Temp;
Temp = DS18B20_ReadTemp();
// 显示：整数部分 + 小数部分
```

- 温度有小数，显示时需要拆分整数和小数部分。
- 或用整数运算（温度 × 10 后取整），避免浮点开销。

## 3 温度报警器

设置一个阈值，超温报警：

```c
unsigned char TempLimit = 30;   // 阈值 30℃

if(Temp > TempLimit)   // 超温
{
	Buzzer=1;    // 蜂鸣器响
	// 或 LED 亮
}
else
{
	Buzzer=0;    // 关报警
}
```

## 4 完整代码（思路骨架）

```c
#include <REGX52.H>
#include "Delay.h"
#include "LCD1602.h"
#include "OneWire.h"
#include "Buzzer.h"

void main()
{
	float Temp;
	LCD_Init();
	LCD_ShowString(1,1,"Temp:");
	
	while(1)
	{
		Temp = DS18B20_ReadTemp();   // 读温度
		LCD_ShowNum(2,1,(unsigned int)Temp,3);  // 显示整数
		LCD_ShowChar(2,4,'.');                  // 小数点
		// 显示小数部分
		
		if(Temp > 30)   // 超 30℃ 报警
		{
			Buzzer_Time(100);   // 蜂鸣器响
		}
	}
}
```

## 5 易错点

- [ ] 温度换算错 → 忘除以 16 或小数点位置错。
- [ ] 指令顺序错 → 要先 0xCC 跳过 ROM，再 0x44/0xBE。
- [ ] 报警阈值设错 → 阈值单位是摄氏度，不是原始值。
- [ ] 浮点显示处理 → 51 用浮点要小心，可改用整数（×10）。

## 6 自测

1. 读温度要发哪几条指令？分别什么作用？
2. 温度报警器的核心逻辑是什么？
3. 为什么 51 上常避免用浮点？

> [!success]- 参考答案
> 1. 0xCC（跳过 ROM）、0x44（启动转换）、0xBE（读暂存器）。
> 2. 读温度 → 和阈值比较 → 超阈值触发报警（蜂鸣器/LED），否则关闭。
> 3. 51 的 CPU 没有硬件浮点单元，浮点运算慢且占资源；常改用整数（温度×10）处理。
