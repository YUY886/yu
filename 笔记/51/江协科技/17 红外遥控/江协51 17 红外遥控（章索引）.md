## 本章速查

### NEC 协议要点

- 红外用 38kHz 载波调制，NEC 协议一帧 = 引导码 + 地址码 + 地址反码 + 命令码 + 命令反码。
- 逻辑 0/1 由**脉冲间隔**区分。

### 关键模块

| 模块 | 作用 |
| --- | --- |
| Int0（外部中断） | 红外接收头信号跳变触发 |
| Timer0 | 计时测量脉冲宽度 |
| IR（状态机） | 解析引导码、地址、命令 |

> [!tip] 记这一章最省力的办法
> 红外遥控 = **外部中断检测跳变 + 定时器计时 + 状态机解析 NEC 协议**。先解出引导码，再按"地址码/命令码"逐步收数据。命令码匹配后执行对应动作（如 VOL+ 加速、VOL- 减速）。

## 全章统一易错点

- [ ] 晶振影响时序 → 红外有时序敏感，注意 11.0592MHz vs 12MHz 版本。
- [ ] 状态机顺序错 → 引导码 → 地址 → 命令，顺序不能乱。
- [ ] 地址码/命令码混淆 → 两者都要读，别搞反。
- [ ] 外部中断没配置 → Int0 要正确配置（IT0/EX0/EA）。
