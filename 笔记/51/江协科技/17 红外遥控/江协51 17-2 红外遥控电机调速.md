## 2 调速逻辑

收到遥控命令码，匹配后改变 `Compare`（占空比）：

```c
if(Command==IR_VOL_MINUS)   // VOL- 减速
{
	Speed--;
	if(Speed==255)Speed=0;   // 下限保护
	Compare = Speed * 25;     // 映射到占空比
}
if(Command==IR_VOL_ADD)     // VOL+ 加速
{
	Speed++;
	if(Speed>=4)Speed=3;      // 上限保护
	Compare = Speed * 25;
}
```

- `Speed` 是档位（0~3），`Compare = Speed*25` 映射成占空比 0%/25%/50%/75%。
- 上下限保护防止越界。

## 3 完整代码（思路骨架）

```c
#include <REGX52.H>
#include "Delay.h"
#include "LCD1602.h"
#include "IR.h"
#include "Timer0.h"

sbit Motor=P1^0;

unsigned char Counter,Compare;
unsigned char Speed;

void main()
{
	LCD_Init();
	IR_Init();
	Timer0_Init();
	
	while(1)
	{
		if(IR_GetDataFlag() || IR_GetRepeatFlag())
		{
			Command = IR_GetCommand();
			
			if(Command==IR_VOL_MINUS)   // 减速
			{
				Speed--;
				if(Speed==255)Speed=0;
				Compare = Speed*25;
			}
			if(Command==IR_VOL_ADD)     // 加速
			{
				Speed++;
				if(Speed>=4)Speed=3;
				Compare = Speed*25;
			}
			LCD_ShowNum(2,1,Speed,2);   // 显示档位
		}
	}
}

void Timer0_Routine() interrupt 1
{
	// PWM：Counter 0~99，小于 Compare 输出高
	TL0 = 0x9C;
	TH0 = 0xFF;
	Counter++;
	Counter%=100;
	if(Counter<Compare) Motor=1;
	else Motor=0;
}
```

## 4 易错点

- [ ] 上下限没保护 → Speed 越界（减速减到 255、加速加到 4）。
- [ ] 命令码匹配错 → 用 `IR_VOL_MINUS`/`IR_VOL_ADD` 等宏，别写死数值。
- [ ] Compare 没更新 → 改了 Speed 但没同步 `Compare`，转速不变。
- [ ] 晶振版本 → 红外有 12MHz/11.0592MHz 两个版本，用对版本。
