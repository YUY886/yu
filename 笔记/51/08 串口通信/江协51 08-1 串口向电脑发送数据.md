# 江协51 08-1 串口向电脑发送数据

> [!abstract] 一句话核心
> 配置方式 1 和定时器 1 重装值，单片机就能向电脑持续发送字节。

## 原理讲解

`SCON=0x40` 选择串口方式 1 并允许发送；`PCON |= 0x80` 使用 SMOD 倍频。

定时器 1 方式 2 作为波特率发生器，`TH1=TL1=0xF3` 在 12 MHz 下得到 4800 bps。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| 波特率 | 4800 bps @12 MHz |
| SCON | 0x40 |
| PCON | SMOD=1 |
| Timer1 | 方式 2，TH1=TL1=0xF3 |
| TXD/RXD | P3.1/P3.0 |

## 完整代码

### `Delay.c`

```c
void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

### `main.c`

```c
#include <REGX52.H>
#include "Delay.h"
#include "UART.h"

unsigned char Sec;

void main()
{
	UART_Init();			//串口初始化
	while(1)
	{
		UART_SendByte(Sec);	//串口发送一个字节
		Sec++;				//Sec自增
		Delay(1000);		//延时1秒
	}
}
```

### `UART.c`

```c
#include <REGX52.H>

/**
  * @brief  串口初始化，4800bps@12.000MHz
  * @param  无
  * @retval 无
  */
void UART_Init()
{
	SCON=0x40;
	PCON |= 0x80;
	TMOD &= 0x0F;		//设置定时器模式
	TMOD |= 0x20;		//设置定时器模式
	TL1 = 0xF3;		//设定定时初值
	TH1 = 0xF3;		//设定定时器重装值
	ET1 = 0;		//禁止定时器1中断
	TR1 = 1;		//启动定时器1
}

/**
  * @brief  串口发送一个字节数据
  * @param  Byte 要发送的一个字节数据
  * @retval 无
  */
void UART_SendByte(unsigned char Byte)
{
	SBUF=Byte;
	while(TI==0);
	TI=0;
}
```

### `UART.h`

```c
#ifndef __UART_H__
#define __UART_H__

void UART_Init();
void UART_SendByte(unsigned char Byte);

#endif
```

## 易错点

- 发送后必须等待 TI=1，并手动清零 TI。
- 上位机波特率、数据位、停止位要匹配。
