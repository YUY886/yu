# 江协51 03-2 独立按键控制LED状态

> [!abstract] 一句话核心
> 用延时消抖和松手检测，把一次按下手势变成一次状态翻转。

## 原理讲解

检测到低电平后先延时 20 ms 跨过机械抖动，再等待按键释放。

释放后再延时 20 ms 稳定释放抖动，随后执行一次 `P2_0=~P2_0`。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| K1 | P3.1 |
| 消抖延时 | 20 ms |
| 释放检测 | while(P3_1==0) |

## 完整代码

### `main.c`

```c
#include <REGX52.H>

void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
		xms--;
	}
}

void main()
{
	while(1)
	{
		if(P3_1==0)			//如果K1按键按下
		{
			Delay(20);		//延时消抖
			while(P3_1==0);	//松手检测
			Delay(20);		//延时消抖
			
			P2_0=~P2_0;		//LED1取反
		}
	}
}
```

## 易错点

- 没有消抖会连续误判多次。
- 没有松手检测会在长按期间反复翻转。
