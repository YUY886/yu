# 江协51 03-4 独立按键控制LED移位

> [!abstract] 一句话核心
> K1 增加点亮位置，K2 减少点亮位置，用循环边界实现双向移动。

## 原理讲解

`LEDNum` 表示当前点亮位置，P2 用 `~(0x01<<LEDNum)` 输出。

加到 7 后回 0，减到 0 后回 7，形成 8 颗 LED 的循环移动。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| K1 | P3.1 |
| K2 | P3.0 |
| 位置范围 | 0~7 |

## 完整代码

### `main.c`

```c
#include <REGX52.H>
void Delay(unsigned int xms);

unsigned char LEDNum;

void main()
{
	P2=~0x01;				//上电默认LED1点亮
	while(1)
	{
		if(P3_1==0)			//如果K1按键按下
		{
			Delay(20);
			while(P3_1==0);
			Delay(20);
			
			LEDNum++;		//LEDNum自增
			if(LEDNum>=8)	//限制LEDNum自增范围
				LEDNum=0;
			P2=~(0x01<<LEDNum);	//LED的第LEDNum位点亮
		}
		if(P3_0==0)			//如果K2按键按下
		{
			Delay(20);
			while(P3_0==0);
			Delay(20);
			
			if(LEDNum==0)	//LEDNum减到0后变为7
				LEDNum=7;
			else			//LEDNum未减到0，自减
				LEDNum--;
			P2=~(0x01<<LEDNum);	//LED的第LEDNum位点亮
		}
	}
}

void Delay(unsigned int xms)
{
	unsigned char i, j;
	while(xms--)
	{
		i = 2;
		j = 239;
		do
		{
			while (--j);
		} while (--i);
	}
}
```

## 易错点

- 全局变量可跨按键逻辑保持状态。
- 不要让移位数量达到 8，避免超出 unsigned char 的位范围。
