# 江协51 03-1 独立按键控制LED亮灭

> [!abstract] 一句话核心
> 按键输入是读取低电平，只要电平持续为 0 就持续执行按下状态。

## 原理讲解

K1 接 P3.1，K2 接 P3.0，未按下被上拉为 1，按下接地为 0。

程序在主循环里持续判断按键电平，把 LED1 保持在点亮或熄灭状态。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| K1 | P3.1 |
| K2 | P3.0 |
| 按下电平 | 0 |
| LED1 | P2.0 |

## 完整代码

### `main.c`

```c
#include <REGX52.H>

void main()
{
	while(1)
	{
		if(P3_1==0 || P3_0==0)	//如果K1按键或K2按键按下
		{
			P2_0=0;		//LED1输出0，点亮
		}
		else
		{
			P2_0=1;		//LED1输出1，熄灭
		}
	}
}
```

## 易错点

- 不要把输入和输出的高低电平语义混为一谈。
- 这类写法只反映当前电平，不具备次数记忆。
