# 江协51 15-1 LED呼吸灯

> [!abstract] 一句话核心
> 快速改变一个周期内亮灭时间比例，人眼就看到 LED 亮度渐变。

## 原理讲解

`Time` 从 0 到 100 变化，一个 100 级周期中 LED 亮 `Time`、灭 `100-Time`。

重复 20 个 PWM 周期后改变占空比，亮度逐步上升或下降。

## 参数与引脚

| 项目 | 值 |
| --- | --- |
| LED | P2.0 |
| PWM 级数 | 100 |
| 每级重复 | 20 个周期 |

## 完整代码

### `main.c`

```c
#include <REGX52.H>

sbit LED=P2^0;

void Delay(unsigned int t)
{
	while(t--);
}

void main()
{
	unsigned char Time,i;
	while(1)
	{
		for(Time=0;Time<100;Time++)		//改变亮灭时间，由暗到亮
		{
			for(i=0;i<20;i++)			//计次延时
			{
				LED=0;					//LED亮
				Delay(Time);			//延时Time
				LED=1;					//LED灭
				Delay(100-Time);		//延时100-Time
			}
		}
		for(Time=100;Time>0;Time--)		//改变亮灭时间，由亮到暗
		{
			for(i=0;i<20;i++)			//计次延时
			{
				LED=0;					//LED亮
				Delay(Time);			//延时Time
				LED=1;					//LED灭
				Delay(100-Time);		//延时100-Time
			}
		}
	}
}
```

## 易错点

- 软件 PWM 期间不能执行长任务。
- 占空比越大 LED 越亮。
